AGENTS.md 준수. 대표 실제 복구 실행 후 상태: 적합한 Commons 자료 부족 또는 범위 종료. 기존 검색 재시도 금지. 운영의 실제 마지막 검색·Gemini 결과/원장/부족 장면 확인. 승인 대본 v2, 4 WAV, 840프레임, 평가, 기존 검색 및 편집 도구 보존. 
## 이번 목표
새로운 실제 자산 경로를 연결한다. 대표에게 직접 게임 설치/녹화/파일 찾기를 기본 업무로 주지 않는다. 범용 공식 제작사 미디어·보도 자료 도구를 구축하고 AI 직원이 장면별 출처·자료 확보 경로를 선택하도록 한다. 기존 official_media.py, asset_editing.py, production_sources.py, commons_discovery.py, ClipJob 및 정책 원장 재사용. 
- 실재 자료 확인의 출발점(개발 조사 단서이며 운영 후보 하드코딩 금지): Klei 공식 https://www.klei.com/games/dont-starve-together/ 에 Press Kit 및 assets.klei.com의 농사/전투 등 이미지가 링크됨. Klei https://support.klei.com/hc/en-us/articles/360029557192-Can-I-stream-or-make-videos-of-Don-t-Starve-Together 및 홈페이지 YouTube & Mod Policy는 정확한 적용 범위 확인 필요. Blizzard 공식 https://blizzard.gamespress.com/WoW-Forever-Launch-Press-Kit (2026-11-04) 및 https://blizzard.gamespress.com/en-US/Kit/Details/wowforeverreveal 에 개별 보도 이미지 등. Games Press https://www.gamespress.com/en-US/FAQ---Use-of-Assets 및 https://www.gamespress.com/en-US/Site/TermsAndConditions 은 편집용 보도 자료 사용과 트레일러 재게시 허가를 구분하므로 자동 수락 금지. WB Games https://warnerbrosgames.com/article/hogwarts-legacy 및 공식 미디어 사이트에 자료 경로가 있으나 계정 등록 필요할 수 있음. 공개 접근만으로 사용권 부여되지 않음. 별도 확인된 Commons 호그와트 공식 트레일러 원본이 361MB/546MB/1.69GB 등으로 기존 64MiB 상한을 초과한다는 실제 관측(https://commons.wikimedia.org/wiki/File:Hogwarts_Legacy_Official_4K_Reveal_Trailer.webm 등)도 기록. 기존 Commons 무한 재검색 대신 적법한 제공처의 작은 개별 이미지/영상/공식 제공 저해상도 버전을 우선. Commons 특정 대형 자료는 새로운 검색 작업으로 자동 호출하지 않으며 공식 허용 파생파일과 권리/해시 검증 가능한 경로가 있다면 후속 후보 설계만 검토.
- AI가 기존 장면·게임명/주제·실제 이전 실패·공식 사이트 단서에 따라 공식 자료 검색/공식 페이지 탐색 계획을 생성하고 실제 자료 링크·개별 파일·권리 문서 후보를 추출할 수 있는 실행 어댑터 최소 1개 구현. 일반화된 허용 공식 도메인/출처 목록 및 공개 페이지 fetch/안전 HTML 텍스트/링크 추출, JSON/직접 이미지/영상 후보 지원을 검토; 제공처 규정/robots/자동 접근 허용 확인, 로그인·등록·CAPTCHA/유료·접근제한 우회 금지. 제3자 링크를 무조건 신뢰하지 말고 허용 호스트, HTTPS/TLS 고정 공개 IP, 리다이렉트·악성 입력·파일 크기·시간 검증 유지. 대형 zip 전체를 내려받지 말고 공식 개별 파일 우선. 실제 제공처 접근 허용이 확인되지 않으면 해당 어댑터는 차단. 자료 발견과 다운로드 승인/권리 판단 분리. 정책 문서의 정확한 인용·출처·범위 기록, 명시적 로컬 편집 검토 허가 및 게시 권한 별도. AI가 정책을 추측/발명하지 않도록 하고 불명확 후보는 별도 검토. 대표에게 수동 JSON 작성 요구 금지. 
- 공식 이미지도 기존 이미지 모션 편집 경로에 실제 연결(현재 official 어댑터는 MP4 중심이므로 확인). 필요한 경우 기존 이미지 인수/검증 계약 일반화. 출처·실제 의미·권리·적합성 기록 유지. 도입 장면은 기존 목표에 합당한 설명용 자산을 일반화하여 선택; 다른 게임 화면이나 생성된 이미지를 실제 플레이로 위장 금지. 승인 대본·음성·시간 변경 없음. 무료 생성 실행기 미연결 유지하되 무료 로컬 생성/모션 도구가 실제 설치 가능하고 비용·권리·품질 측정 가능한 경우 별도 대안으로 보고(이번 설치/대형 다운로드 및 실제 생성 금지). 
- 새 경로 한 번의 개인 정책 범위 승인(예: 공개 페이지 GET 최대 8회, 신규 AI 판단 최대 1회, 실제 미디어 다운로드 0회, 비용 0)으로 탐색 실행 준비. 실제 허용 범위/상한은 구현 근거에 따라 더 작게 설정. 자동 재시도·유료 전환 금지. 기존 완료 기록 조작 금지. 후보 충분시 기존 권리 일괄 검토/편집 범위로 인계. 이번 개발 중 실제 미션 API/자료 다운로드 및 운영 승인 생성 0회, 공식 문서 개발 조사와 구분. 
- 복제본의 모의 공식 페이지/자료·권리 문서/로그인 제한/미허가/위험 URL/관련성/크기 초과/빈 결과 및 적법한 이미지·영상 혼합 기존 WAV 렌더 인계 검증. 실제 게임 영상 확보 성공 또는 품질로 과장하지 않는다. 운영 환경/루트 보존 서버 재시작 및 localhost 상태 확인. reports/mission01_publisher_media_acquisition_result.md에 실제 마지막 Commons 결과, 출처별 실제 발견 가능 경로 및 권리/접근 한계, 신규 실행기와 미지원, 다음 대표 최소 조작/상한, 테스트·실제 호출 0회, 운영 무결성 보고. 검증된 코드/보고서만 main commit/push 및 원격 확인. 사용자 명시 push 승인 범위 준수; 운영 데이터·키·미디어 제외.
