# 컷룸 미션 01 · 기획·대본 대표 검토 연결 — 2026-11-11 KST

**외부 호출 전 준비 완료. 실제 AI 호출 0회.** 실제 기획안·대본은 아직 생성되지 않았다. 대표의 실제 기획 승인, TTS, 영상 렌더, 최종 영상 승인과 게시도 수행하지 않았다.

## 연결한 흐름

컷룸에서 목표를 저장하고 **미션 01 준비**를 누르면 기존 대표 프로젝트가 별도 `QualityProviderStore` 작업을 연결한다. 브라우저에는 외부 전송 승인·실행 버튼이 없다. 승인 전에는 `research_planning`에서 실행 권한 대기를 표시하며 보고서나 승인 버튼이 생기지 않는다.

실행 경로는 기존 Gemini 3.5 서명 동의, 역할별 요청 검증, 시도 원장과 재실행 차단을 재사용한다. 기존 범용 품질 provider의 기본 전송 비활성 설정은 유지된다. 별도 서명 범위가 있는 미션에서만 관리자 계획 → 조사·후보 비교 → 대본 초안 → 내부 검토·필요시 수정 → 편집 인수 → 관리자 최종 검토를 실행할 수 있다. 실행 중 새 웹 검색은 하지 않으며 한국 게임 쇼츠 조회 성과는 `unverified`로 유지하고, 기존 보류 후보를 자동 인수하지 않는다.

대표 제출은 조사·대본·편집 인수의 수락, 목표 길이와 대본·장면 계약, 요청 및 응답 증거를 검증한 뒤 이뤄진다. 이 단계에서 렌더 사양과 미디어 파일은 필요 없다. 컷룸에서 보고서 버전/SHA, 후보와 선택 이유, 전체 한국어 대본·스토리보드, 내부 반려와 수정 이력, HTTP 상태·KST 시각·토큰·요청/응답 해시를 확인할 수 있다. 권리와 최신성은 확인 대기로 표시한다. 요청 입력과 산출물은 로컬 프로젝트에 저장하며 요청·응답 원문 전체 대신 기존 컨텍스트·검증된 역할 결과와 해시를 보존한다.

## 검증

오프라인 테스트 19개 통과. 격리된 네이티브 HTTP 모의 경로에서 조사→대본 반려→수정본 수락→편집 인수→대표 승인 대기까지 10회 응답을 검증했다. 별도 동의 누락, 키 변경, HTTP 429 소모 후 재개, 가짜 실 AI 결과 제출은 차단됐다. 기존 음성·영상·동의·시도 원장은 변경하지 않았다.

Chromium에서 신규 프로젝트와 호출 0건의 권한 대기, 격리 모의 보고서와 전체 대본, 새로고침 후 상태 복원, 피드백 저장을 확인했다. 격리 화면에는 **오프라인 HTTP 검증**을 표시했고 실제 AI 배지나 영상 플레이어가 나타나지 않았다. 화면 캡처는 `data/video_representative_workflow/20261111_mission01_evidence/`의 `mission-review.png`, `mission-permission.png`에 있다.

## 대표 지시 변경 · 인기 게임 쇼츠

새 목표는 **“요즘 인기있는 게임에 대한 흥미있는 쇼츠 영상을 만들어봐. 기본적으로 인기있는 쇼츠는 몇초인지도 확인해보고.”**다. 이전 AI 활용 쇼츠 예시는 이번 실행 범위에서 제외했다. 컷룸의 새 프로젝트 `company-3866df23fc9f4d50a7600bcde3ecf504`에 정확한 목표와 공개 근거를 연결했다. 상태는 `research_planning`, 승인과 호출 기록은 0건이다. 특정 게임·주제·길이는 아직 선택되지 않았다.

- **게임 관심 근거.** 11/11 10:58 KST 전후 공식 차트 열람에서 Counter-Strike 2 43.1만, Dota 2 33.1만, PUBG 10.1만의 동시 접속 스냅샷을 확인했다. Steam 글로벌 PC 데이터이며 한국 게임 쇼츠의 조회·증가·채널 규모 보정 성과는 `unverified`다. [Steam Most Played](https://store.steampowered.com/charts/mostplayed)
- **길이 근거.** 한국 인기 차트 한국어 쇼츠 4,452편의 중앙값은 43초, 60초 이하는 71.7%였다. 별도 게임 YouTube 클립 241,353편의 15~30초 비중은 40.5%, 30~60초는 37.2%였다. 모집단이 다르며 길이가 성과를 만든다는 인과 근거는 없다. 세로·정사각형 최대 3분은 Shorts 분류 규정이다. [한국 차트 표본](https://serastudio.app/insights/shorts-length) · [게임 클립 표본](https://www.opus.pro/research/best-time-gaming-youtube) · [YouTube 분류 기준](https://support.google.com/youtube/answer/15424877?hl=en)
- **길이 계약 변경.** 게임 미션 준비 시 60초를 채우던 경로를 제거했다. 관리자에게 15~60초 범위에서 소재별 길이 2개 이상을 비교하고 관측 분포 2개 이상을 근거로 제안하게 했다. 조사 직원은 게임별 Steam 근거·시청자 적합성·권리 취득 계획을 비교한다. 관리자의 조사 수락 기록에 선택 소재·다른 후보 제외 이유·길이 근거를 남긴다. 대본의 목표 초 수와 장면 종료 시각을 이 결정에 대조하고 편집 인수까지 연결한다. 대표 화면에 예상 글자 수·초당 글자 수·근거를 표시한다. 실제 낭독, 게임 화면 확보와 권리 검증은 대기 상태다. 일반 60초 대본 경로는 기존 기본값을 사용한다.
- **이번 변경 검증.** 오프라인 20개 통과. 모의 HTTP에서 관리자가 22·34·45초를 비교해 선택한 34초가 내부 수정 및 대표 보고서까지 유지됐다. 대본 직원이 60초로 되돌리면 보고가 차단됐다. 플랫폼 규정을 길이 분포 근거로 사용하는 것도 거부했다. 실제 게임 기획·대본, AI POST, 게임 녹화, TTS, MP4는 0이다.

## 별도 승인 제안 1건

대상은 위 새 프로젝트의 정확한 대표 목표와 그에 연결된 공개 스냅샷·한국어 9:16 YouTube Shorts 제약이다. 대본 작성 전에 게임 소재와 15~60초 길이를 관리자에게 맡긴다. 실제 개인·회사 자료, 보류 후보, 이전 음성 입력은 전송 범위에 포함하지 않는다. 정확한 목표·입력 계약·해시를 검토한 뒤 승인한다.

- 모델은 Gemini Developer API `gemini-3.5-flash-lite`, 고정 텍스트 `generateContent` 엔드포인트. 기본 8회(관리자 계획 1, 조사·대본·편집 각각 작성 및 검토 6, 최종 검토 1), 수정 1회가 필요하면 2회 추가해 **실패 포함 최대 10회**. 회당 최대 출력 4,096토큰. 자동 재시도·fallback·검색·미디어·게시 없음.
- **기존 Free Tier, Billing 비활성, 비용 상한 $0**만 허용한다. 환경에서 키 존재와 과거 서명된 프로젝트의 키 일치를 로컬로 확인했다. 과거 증거는 만료됐고, 현재 프로젝트의 해당 텍스트 모델 접근, Billing과 모델별 잔여 10회 및 RPM/TPM은 확인되지 않았다. 고정 모델·엔드포인트·실행 플래그도 현재 미설정이다. 공급자의 무료 단가는 이 계정의 할당량이나 실제 청구 확인과 별개다. [공식 가격](https://ai.google.dev/gemini-api/docs/pricing#gemini-3.5-flash-lite) · [할당량](https://ai.google.dev/gemini-api/docs/rate-limits)
- 무료 서비스 입력·출력이 Google 제품 개선과 인적 검토에 쓰일 수 있다는 점에 별도 동의가 필요하다. 전송 대상은 검토한 목표·제약·역할 지시 및 해당 실행의 선행 작업 결과·수정 피드백이다. 비밀키는 인증 헤더에서만 사용한다. [무료 서비스 약관](https://ai.google.dev/gemini-api/terms)

컷룸 실행은 `PYTHONPATH=core:companies/video python -B -m studio_server --host 0.0.0.0 --port 8000`이며 Ports에서 8000을 Private으로 유지한다. 승인 범위가 확인되면 동일한 PYTHONPATH에서 `python -B -m video_mission_one prepare <컷룸 프로젝트 ID>`에 `--confirm-free-account --account-project --remaining-requests --quota-note`를 지정해 제안을 검토한다. 대표 동의 후 `approve <ID> --proposal <로컬 제안 파일> --review-hash <해시> --confirm-free-data-policy`로 기존 서명 승인을 저장하고, `run <ID>`를 한 번 실행한다. 이 명령은 이미 수락된 결과가 있다면 재호출 없이 대표 제출만 마칠 수 있다. 다음 단계는 **이 한 건의 입력과 무료 계정·쿼터를 확인하고 별도 전송 승인을 받는 것**이다.
