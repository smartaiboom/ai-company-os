## 이미 승인된 단일 실외부 호출 범위
대표는 이번 첫 게임 쇼츠 미션에 한하여 다음을 명시적으로 승인했다.
- Gemini 텍스트 고정 모델 `gemini-3.5-flash-lite` 최대 10회 (실패·시간초과 포함).

- 실제 기획안과 대본을 컷룸의 대표 **기획 승인 대기**까지 제출하는 것만 허용. 대표 승인 클릭·TTS/WAV·MP4·게시 금지.

## 실행 절차
1. `AGENTS.md`, 기존 관련 실행 보고서, `companies/video/video_mission_one.py`의 `prepare/approve/run` 계약을 읽고 최신 GitHub 코드를 안전하게 가져온다. 로컬 수정·미추적 파일을 보존한다.
2. 지난번 이미 해결한 잔여 쿼터 확인과 API 키 존재/결제 여부 확인을 다시 감사하지 않는다. **현재 키 프로젝트와 결제 미등록이 동일하다는 사용자 확인**을 승인 제안의 근거로 분명히 기록한다. 기존 모델·무료 모드·엔드포인트를 임의 변경하지 않는다.
3. 기존 서명 승인·제안 해시·키 바인딩·모델 고정·시도 원장을 **우회하지 말고** 적용한다. `prepare` 단계에서 잔여량이 확인되지 않으면 허용된 `unknown` 계약을 사용한다. 프로젝트 식별자가 CLI에 꼭 필요한 경우 실제 기존 설정에서 확인 가능한 프로젝트 식별자를 사용하며, 임의 값을 만들지 않는다. 승인 범위와 제안 내용이 다르면 실행하지 않는다.
4. 이 사용자 확인에 근거해 허용된 무료 실행 조건을 충족한다면 `approve`로 승인 범위를 서명 저장하고 `run`은 **한 번만** 호출한다. 공급자가 무료 모델 접근을 거절하거나 청구 가능성·키/프로젝트 불일치 등 새 구체적 위험이 확인되면 **첫 요청 전에 중단**, 또는 요청했다면 실패로 횟수 소비 후 즉시 중단한다. 자동 재시도하지 않는다. 계정별 잔여량 입증을 다시 요구하며 중단하지 않는다.
5. 실제 조사 직원이 YouTube 검색어와 조사 범위, 후보를 자율적으로 결정하고 공개 메타데이터를 수집한다. AI 관리자가 근거에 따라 게임·쇼츠 소재·길이를 결정한다. 대본 직원이 전체 한국어 대본과 장면 구성 작성, 내부 검토/수정·편집 인수 후 실증된 결과만 `awaiting_plan_approval`에 올린다. 사전에 Codex/ChatGPT가 게임과 길이 답안을 주입하지 않는다.
6. 실제 응답·조사 근거·역할별 검토·SHA·KST 시간·호출 횟수·실패 횟수를 기존 기록에 저장한다. 본 미션의 YouTube 공개 메타데이터는 30일 처리 조건을 유지한다. 이전 데이터, 음성 샘플, 승인/시도 원장, 백업 훼손 금지.
