# Codex 작업 지시 파일 관리 체계 준비 보고서

## 확인한 자료

- 기존 `AGENTS.md`의 데이터 보존, API 비용 제한, 테스트·보고서·Git 규칙을 읽었다. 해당 파일은 수정하지 않았다.
- `codex_tasks/`는 기존 작업 폴더에 없음을 확인했다. 새 파일을 덮어쓰지 않고 새 폴더와 요청한 지시 파일 3개를 만들었다.
- 기존 업무 연결 감사, 명시적 업무 연결 개선, 품질 검토 흐름 보고서를 읽었다.
- `origin/main`을 가져와 당시 원격 커밋 `33c00a2221f92f5548e83c9bc64b594047c8c5ef`와 로컬 기준이 일치하는지 확인했다. 원격 커밋 트리의 보고서와 `git log`도 대조했다.

## 새 파일

- `codex_tasks/README.md`: 지시 파일 사용법, 공통 데이터/API/테스트/보고서/Git 원칙.
- `codex_tasks/next_step.md`: AI 직원 업무 검토 승인 게이트의 요구 동작, 수정 요청·재검토 흐름, 필수 테스트 및 완료 조건.
- `codex_tasks/task_history.md`: 원격 보고서·커밋으로 확인한 최근 작업과 테스트 결과, 다음 단계.

`next_step.md`에 적힌 개발 기능은 이번 작업에서 실행하지 않았다.

## 이력에 기록한 원격 근거

- `33c00a2` — 명시적 작업 ID 연결, 관련 테스트 51개 통과와 보고서 `explicit_workflow_links_report.md`.
- `1e0eded` — 업무 연결 조사, 모의 테스트 10개 통과와 보고서 `employee_workflow_connection_audit.md`.
- `576eeea` — 품질 검토·재검토 흐름 테스트, 해당 보고서에 집중 테스트 1개·전체 유닛 테스트 33개·HTTP 스모크 테스트 통과로 기록.

작업 이력에는 확인한 날짜, 커밋, 보고서 및 테스트 결과만 기록했으며 기존 업무 결과 본문이나 비밀 정보는 넣지 않았다.

## 검증과 제한

- 새 지시 파일과 보고서를 저장한 뒤 모두 다시 읽어 내용과 경로를 확인했다.
- 이번 변경은 문서 파일만 대상으로 해 애플리케이션 테스트는 실행하지 않았다. `git diff --cached --check`가 통과했다.
- 코드, 프로젝트 JSON, 업무 결과, 백업은 변경하지 않았다. 실제 AI API도 호출하지 않았다.
- 변경 및 커밋 대상은 새 지시 파일 3개와 이 보고서뿐이다. 기존 미추적 파일은 포함하지 않는다.
