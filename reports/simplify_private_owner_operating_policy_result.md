# 개인용 컷룸 운영 승인 통합 · 2026-11-19 KST

## 운영 정책과 적용 범위

대표가 현재 제작에 대해 공급자·프로젝트·모델·데이터 유형·호출 상한·무료 전용 및 비용 상한 $0을 한 번 검토하고 승인한다. 정책은 승인 대본·기존 관리자 계획·영상 수정 범위에 묶이고 24시간 유효하다. 제작 상세에서 철회할 수 있다. `AGENTS.md`에 대표 확정 원칙을 반영했다. 앞선 잔량 입력 간소화 지시는 작업 파일만 있었으며 동일 변경을 중복 구현하지 않았다.

현재 컷룸에서 가능한 범위는 기존 scene-1을 제외한 **장면 음성 최대 3회**, 실측 초과 시 **관리자 시간 조정 최대 1회**, 소스 미확보 시 **자산 직원 최대 1회**다. 승인 자체는 호출하지 않는다. **제작 실행** 한 번으로 각 요청의 정확한 본문에 맞는 내부 서명·실행 원장 기록을 생성하고 가능한 단계까지 진행한다. 예전 단계별 승인 화면은 기존 준비 기록이 있는 진단 경로에서 유지된다. 일반 제작 화면의 잔여 요청·토큰 수치 입력은 제거했다.

시스템 상한은 장면별 처리 예산이며 공급자 잔여량이 아니다. 현행 무료 적용, 결제 미연결 및 충분한 한도는 대표가 정책을 승인할 때 한 번 확인한다. 공급자 잔량·청구의 독립 확인값은 `unknown`이며 기존 소유자 확인이나 내부 숫자를 실측으로 저장하지 않는다. 공급자 설정이 바뀌면 철회해야 하며, 변경을 자동 감지할 공식 계정 조회 기능은 연결하지 않았다. 키 대조, 고정 모델·엔드포인트, 무료 실행 플래그, 정책 서명과 유효기간을 함께 확인한다. 실패·미확정도 차감하며 후속 호출을 막는다. 철회 이후에는 새 예약을 차단하고 이미 전송된 요청 기록을 보존한다.

시간 조정안 승인, 실제 사용권이 필요한 영상 인수와 최종 영상 승인은 기존 대표 검토를 유지한다. 조정안과 소스가 준비되면 **제작 실행**으로 로컬 합성과 영상 검토 제출까지 진행할 수 있다. 운영에는 권리가 확인된 영상 소스가 아직 없다. 기획·재작업·별도 예산 화면은 기존 방식이며 새 공급자, 민감 데이터, 추가 비용, 신규 YouTube 검색·다운로드·영상 생성은 이 정책 범위에 포함되지 않는다. 만료·철회·중단 정책의 갱신이나 범위 증액은 이 화면에 구현하지 않았다.

## 운영 확인과 대표 다음 조작

운영 프로젝트는 영상 수정 요청 상태다. 승인 v2, 기술 시안 v1, 실제 관리자 계획 1회, scene-1의 3.68초 WAV와 저장된 청취 의견, 기존 동의·시도 원장을 확인했다. 제작 키 대조와 장면 TTS 실환경 설정은 유지됐다. 이번 작업에서 운영 정책 승인이나 실행을 생성하지 않았다.

컷룸을 새로고침한 뒤 **현재 상태 / 다음 작업 → 개인 운영 정책 검토·승인**에서 표시된 조건을 한 번 확인한다. 이어 **제작 실행**을 선택한다. 요청 결과에 따라 **대표 시간 조정안 검토·승인** 또는 권리를 확인한 **로컬 클립 인수**가 필요하다. 철회는 **관련 상세 보기 → 개인 운영 설정 → 운영 정책 철회**에 있다.

## 검증

- 운영 서버를 기존 환경과 루트로 재시작했다. localhost 상세 API·최신 JS/CSS, 정책 승인 전 상태·호출 상한, WAV 해시·청취 의견 및 선정 운영 JSON·미디어 해시 일치를 확인했다. 브라우저 실조작은 미검증이다.
- 복제본에서 정책 승인 시 호출 0회, 대표 실행 한 번으로 모의 TTS 3회·관리자 텍스트 1회·자산 직원 텍스트 1회, 기존 scene-1 미재호출을 확인했다. 조정안 승인과 테스트 소스 인수 후 실제 FFmpeg로 합성해 대표 영상 검토까지 제출했고 추가 모의 호출은 없었다. 동의 해시·범위 밖 모델/비용·소진·서명 키 변경·만료·철회·실패/미확정·중복·개별 우회를 차단했다. 실제 청구·공급자 잔량은 검증되지 않았다.
- Python 39건 중 38건 통과, 1건 건너뜀. JavaScript 상태·구문 및 Git diff 검사 통과. 이번 실제 Gemini 텍스트·TTS·YouTube·다운로드·영상 생성 호출은 각각 **0회**다.
