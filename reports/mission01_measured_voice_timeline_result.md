# 미션 01 실측 음성 기반 타임라인 · 2026-11-19 KST

## 운영 상태

영상 수정 요청 단계다. 승인 대본 v2, 무음 시안 v1, 기존 제작 관리자 텍스트 1회와 scene-1 Gemini/Puck 음성 1회의 승인 및 호출 원장을 보존했다. 실제 scene-1 WAV는 3.68초이며 기존 3초 장면보다 길다. 로컬 WAV 샘플 수, 제공자 응답의 실측 기록, SHA-256 및 서명된 동의 연결을 확인했다. 유효한 음성 파일과 승인 타임라인 조정 필요 상태를 별도로 표시한다. 운영에는 영상 소스가 없으며 scene-2~4는 미실행 상태다.

대표가 전달한 “음성은 괜찮아”는 컷룸의 청취 의견 경로에서 해당 음성 SHA-256, 승인 기획 해시, 장면과 시청자에 연결할 수 있다. 의견은 해당 장면 범위로 저장되며 임의 점수를 만들지 않는다. 이번에는 운영 상태 보존 조건에 따라 실제 의견 기록을 추가하지 않았다.

## 연결한 경로와 승인 범위

- 기존 `SceneVoice`와 `TTSExecution`을 재사용한다. 완료된 scene-1의 동일 모델·계정·키에 대한 확인 이력을 사용하고 대표가 현재 무료 조건, 결제 미연결, 지역과 묶음 전체 잔량을 다시 확인한다. 일괄 동의 한 번에 미준비 scene-2~4의 정확한 요청 본문과 해시를 묶고 서버는 기존 장면별 서명·검증·원장 경계를 적용한다. 실행은 최대 **TTS 3회**, 실패·미확정도 해당 시도를 차감하고 후속 요청을 중단한다. 묶음에 들어간 장면은 독립 버튼으로 재실행할 수 없다. 이미 개별 준비한 장면은 기존 단건 경로에서 처리한다. 중단 묶음의 새 승인·재개는 이번 범위에 포함되지 않았다.
- 모든 장면의 원본 WAV와 영수증이 검증되면 시스템이 24fps 실측 하한, 승인 경계·길이, 자막 글자 수와 노출 기준, 인수한 소스가 있을 때 그 길이를 계산한다. 원래 경계에 모두 들어가면 추가 호출 없이 기존 타임라인을 사용한다. 초과가 있을 때만 별도 동의로 **Gemini 관리자 텍스트 최대 1회**를 요청해 같은 총 길이의 재배분, 전체 길이 변경 제안 또는 보류를 받는다. 모델 입력은 승인 원문·실측·소스 상태와 범위가 명시된 청취 의견이다. 실제 WAV는 텍스트 요청에 첨부하지 않는다.
- 변경은 조정안 버전·해시에 대한 별도 대표 승인이 있어야 적용된다. 원본 대본·자막 원문·기존 계획과 클립 작업의 원본은 보존된다. `ClipJob`에 승인된 시간과 자막 노출 범위만 별도 인계하며 최종 렌더 영수증에 승인 조정안 해시를 남긴다. 소스가 부족하거나 짧으면 합성이 차단된다. 음성을 자르거나 가속하거나 재합성하지 않는다. 실제 AI 조정 판단과 게임 영상 품질은 미검증이다.
- 팝업의 긴 요청 본문과 해시를 줄바꿈하고 버튼 영역이 좁은 화면에서 접히도록 조정했다. 일괄 음성, 청취 의견, 타임라인 조정, 영상 자산은 같은 다음 작업 영역에서 선택할 수 있다.

## 대표 다음 조작

1. 컷룸을 새로고침하고 필요하면 **제작 작업 선택 → 청취 의견 · scene-1 → 청취 의견 저장**에서 전달한 의견을 남긴다.
2. **현재 상태 / 다음 작업 → 남은 장면 음성 일괄 준비 → 남은 장면 음성 일괄 동의 → 남은 장면 음성 일괄 실행** 순서로 진행한다. 운영 키 대조와 TTS 실행 설정은 현재 활성 상태다. 실행 전 현재 무료 조건과 잔여량을 확인한다.
3. 모든 음성 실측 후 **실측 시간 조정 → 실측 시간 조정안 준비 → 시간 조정안 전송 동의 → 관리자 시간 조정 판단 실행**으로 진행한다. 제안이 도착하면 **대표 시간 조정안 검토·승인**에서 총 길이·장면별 시간·자막 노출을 확인한다. 권리를 확인한 영상 소스를 인수하고 시간이 맞아야 로컬 합성을 시작할 수 있다. 신규 검색·다운로드·영상 생성의 호출 범위는 이 작업에서 각각 0회다.

## 검증

- 운영 서버를 기존 환경·루트로 재시작했다. 제작 키 대조와 TTS 플래그, 상세 API, 최신 JS/CSS, localhost WAV 응답과 저장 해시 일치를 확인했다. 운영 JSON·미디어 해시와 기존 관리자 계획을 보존했다. 실제 브라우저 클릭 및 좁은 화면의 시각 검증은 미수행이다.
- 운영 승인본 복제에서 3.68초 모의 원본 음성을 보존하고 나머지 3건을 모의 일괄 실행했다. 잘못된 청취 음성 해시·동의 해시·타임라인 조정안 해시·승인 전 렌더를 차단했다. 타임아웃 사례에서 후속 음성 요청 및 개별 우회를 차단했다. 별도 승인된 3.75초 첫 장면과 총 35초 타임라인으로 로컬 클립·음성·자막을 실제 FFmpeg로 합성해 영상 검토에 제출했다.
- Python 테스트 38건 중 37건 통과, 1건 건너뜀. JavaScript 상태·구문 및 Git diff 검사 통과. 이번 실제 Gemini 텍스트·TTS·YouTube·다운로드·영상 생성 호출은 모두 **0회**다.
