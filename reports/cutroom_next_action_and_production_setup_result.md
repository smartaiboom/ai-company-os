# 컷룸 다음 작업 및 제작 준비 설정 · 2026-11-19 KST

## 화면 변경과 현재 상태

프로젝트 제목 바로 아래의 **현재 상태 / 다음 작업** 영역에 상태에 맞는 주 행동을 표시하고 스크롤할 때 상단에 유지한다. 기획·재작업·제작·음성·자산 인수·대표 검토의 기존 조건과 요청 경로를 사용한다. 최신 보고서 검토에는 승인과 수정 요청을 함께 표시하고, 기술 카드 시안은 영상 수정으로 이어진다. 상단으로 옮긴 버튼의 중복을 제거했다. 다른 작업 옵션, 상세 이력과 이전 보고서는 해당 영역에 남겼다.

운영 프로젝트는 **영상 수정 요청** 단계다. 승인된 35초 기획·대본 v2와 무음 기술 시안 v1, 대표의 영상 수정 요청을 보존했다. 관리자 제작 계획은 미준비 상태이며 새 제작 요청 시도는 0회다. 기존에는 `productionPanel`의 `!key_ready` 분기가 준비 버튼을 숨겼다. 현재 화면은 **관리자 제작 계획 준비**를 비활성으로 표시하고 서버의 대조용 키 설정 누락을 안내한다. 장면 TTS 설정은 서명된 장면 음성을 실행할 때만 안내한다.

## 키 대조와 대표의 다음 조작

`production_keys()`는 `GEMINI_API_KEY`와 `GEMINI_PRODUCTION_PROJECT_API_KEY`가 모두 설정되어 있고 값이 같은지 대조한다. 기존 미션과 제작 계획이 같은 고정 프로젝트 경계를 사용한다. 현재 서버에는 실행용 키가 있고 대조용 설정만 누락됐다. 기존 승인 무료 프로젝트의 현재 키가 실행용 키와 일치한다면 그 **같은 키**를 대조용으로 사용할 수 있다. 새 키 발급, 새 프로젝트 생성, 결제 연결은 전제 조건이 아니다. 이 대조는 로컬이며 공급자가 키 소속, 무료 적용 또는 쿼터를 실시간으로 확인한 결과가 아니다.

1. AI Studio에서 기존 미션에 사용한 프로젝트와 키의 소속, 결제 미연결, 해당 모델 무료 적용, 잔여 쿼터 및 현행 공급자 문서를 확인한다.
2. 기존 런처가 사용할 Bash 환경에서 아래 명령을 실행하고, 입력 대기 시 확인한 **같은 프로젝트의 키**를 붙여넣은 후 Enter를 누른다. 환경 변수를 내보낸 동일 셸에서 기존 컷룸 실행 명령으로 서버를 다시 시작한다. 기존 실행용 키, 모델 및 엔드포인트 설정과 데이터 경로를 유지한다. 비밀값은 채팅, 명령 인수, 셸 이력, 저장소에 남기지 않는다.

   ```bash
   IFS= read -rs -p '확인한 프로젝트 키: ' GEMINI_PRODUCTION_PROJECT_API_KEY && export GEMINI_PRODUCTION_PROJECT_API_KEY
   printf '\n'
   ```

3. 컷룸에서 운영 프로젝트를 새로고침하고 제목 아래 **현재 상태 / 다음 작업 → 관리자 제작 계획 준비**를 누른다. 무료 조건·쿼터·문서 확인을 선택해 제안을 준비한다. 이 조작의 외부 호출은 0회다. 이어지는 **제작 계획 외부 전송 동의**에서 전송 범위를 검토한다. 실제 전송은 별도 **관리자 제작 계획 실행**을 누를 때만 가능하며 상한은 텍스트 1회다.
4. 관리자가 Gemini 장면 음성을 선택하고 해당 장면의 서명과 동의가 완료된 경우에만 서버의 `GEMINI_PRODUCTION_TTS_ENABLED=1` 설정 안내가 나온다. 실제 음성 요청은 별도의 장면별 실행으로 한 번씩 처리한다. 이 작업 중 키 설정 추가, 실행 플래그 변경, 신규 동의 생성은 없었다.
