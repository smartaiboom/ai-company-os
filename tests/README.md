# 현재 핵심 오프라인 테스트

저장소 루트에서:

```bash
PYTHONPATH=core:companies/video python -B -m unittest discover -s tests -p 'test_*.py' -v
```

기존 회사 엔진을 모의 AI 관리자/직원으로 구동하여 두 분야의 계획→실행→검토/수정→파일 산출, 실패/한도 처리, 자동 재시도 방지, 미승인 생성 차단을 확인하는 테스트 4개다. 외부 모델 호출은 하지 않는다.

**현재 디렉터리 이동 뒤에는 재실행하지 않았으며, 4개 테스트가 모든 실제 영상/모델/API 기능의 품질을 입증하지는 않는다.** 실사용 품질 평가·경험 재사용은 앞으로 기능 단위 개발 후 통합 검증한다.
