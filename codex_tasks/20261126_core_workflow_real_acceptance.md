## 목표
기존 조사→관리자 기획→직원 대본→영상→대표 검토/재작업→경험 재사용을 실제 사용 가능한 하나의 흐름으로 검증하고 확인된 결함을 기능 단위로 수정한다. 경험 관리 확장이나 공급자 추가, 새 승인 UI 확장은 범위 밖이다.
## 실행
1. 기존 결과 보고서 reports/20261125_feedback_reuse_integration_result.md와 기존 승인/실행 경로를 확인한다. 기존 데이터, 백업, 원장 보존. 격리 테스트 프로젝트 사용.
2. 기존 컷룸 브라우저 자동화 환경을 점검하고 가능하면 무료 로컬 Playwright/Chromium 환경을 복구한다. 기존 실패 3건의 원인을 확인하여 핵심 흐름에 영향을 주는 결함만 수정한다. 대표에게 반복 클릭을 요구하지 않는다.
3. 기존 승인된 공급자 경로의 준비 상태를 읽기 전용 확인한다. 기존 503/403/권한 거부를 자동 재전송하거나 우회하지 않는다. 정상 허용 경로 및 유효한 승인(공급자/모델/프로젝트/데이터/목적/유효기간/무료 비용0/기존 예산)이 확인된 경우에만 새 서명·예약으로 신규 실제 업무를 실행한다. 부족하면 필요한 승인 범위를 한 번 정리하고 외부 실행만 보류한다. 임의 소량 호출 상한을 새로 만들지 않는다. 기존 서명은 유지한다.
4. 실제 업무 예시: 기존 모바일 게임 쇼츠 목표 또는 권리 확인 가능한 실제 시연 소재. 조사 근거와 시청자 가치, 구체적인 장면/소스 확보 가능성, 대본의 사실성·흥미·길이·자막·음성 적합성을 검증한다. 확보하지 못한 게임 화면이나 권리를 확보했다고 주장하지 않는다. 관리자/직원 결과가 실제 생성되었는지 출처와 실행 기록으로 구분한다. 사용자 승인 게이트를 유지하고 테스트용 결정은 격리·명시한다.
5. 실제 AI가 막히면 오프라인 통합 검증을 계속한다. 기존 경험 선택/전달/제외 및 수정본 연결을 실제 브라우저에서 확인하고, 기존 무료 로컬 음성 경로로 한국어 음성 포함 영상 제작 가능 여부를 확인한다. 음성 길이, 무음 여부, 영상 디코딩, 장면·자막 일치 등 객관적 검증과 사람이 평가해야 하는 품질을 구분한다. 모의 결과를 실제 AI 성과로 표시하지 않는다.
