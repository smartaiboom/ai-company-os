## 환경과 실제 실행 차단 조건

`companies/video/local_research_config.py` 및 `studio_server.py`에 기존 서버 진입점의 환경 파일 로딩과 읽기 전용 진단을 추가했다. `AGENTS.md`에 실행 절차를 기록했다. 환경 파일은 셸로 실행하지 않으며 기존 프로세스 설정을 우선한다. 기존 모델과 주소만 기본값으로 설정하고 무료 실행 플래그나 독립 대조 키를 생성하지 않는다.

```sh
PYTHONPATH=core:companies/video .venv/bin/python -m studio_server --env-file .env --research-readiness
```

현재 `GEMINI35_AUTONOMOUS_FREE_ENABLED`가 활성화돼 있지 않고, 독립 확인에 필요한 `GEMINI_PRODUCTION_PROJECT_API_KEY`가 없다. Gemini 요청 키와 Tavily 키의 등록 여부, Tavily 무료 전용 플래그는 확인했다. 키 값이나 요청 본문은 출력하지 않았다. 공급자 계정의 무료 자격, 결제 비활성, 실제 잔여 한도는 로컬 설정으로 확인할 수 없다. 이전 키 일치나 운영 승인은 이번 요청의 계정 확인 또는 새 서명을 대신할 수 없다. 공급자 계정 조회도 실행하지 않았다.

최소 대표 조치는 지정 Gemini 프로젝트와 Tavily 무료 계정의 결제 비활성·잔량을 한 번 확인하고, 독립 확인한 제작 프로젝트 키와 무료 실행 플래그를 기존 보안 설정 경로에 넣어 그 확인을 전달하는 것이다. 그다음 Codex가 같은 진단과 새 서명 승인 경로로 진행할 수 있다. 현재 조건부 승인의 Gemini 5회, Tavily 1회, Klei GET 3회 상한은 그대로다. 조건이 충족되지 않아 운영 승인과 실제 실행을 만들지 않았다.

## 공통 계약과 영상 적용

- `core/web_research.py`, `research_workflow.py`, `research_supervision.py`에서 기존 보존 자료를 관측 카탈로그에 읽기 전용으로 제공한다. Commons·제작사는 서명된 기존 승인·완료와 자료 해시, YouTube는 과거 승인 서명·비철회·수신 기록 및 보존 유효 시점과 발췌 해시를 확인한다. 적격 행의 내용·URL·출처·관측 시점·식별자를 유지한다. 30일 제한이나 출처 유형·12개 전송 상한을 넘는 행은 제외하고 화면에 수를 표시한다. 상충 여부와 목표 관련성은 직원·독립 관리자 판단에 맡긴다. 현 운영 제안은 Commons 메타데이터 8건과 YouTube 지표 4건을 제공한다. YouTube 2건은 전송 한도로 제외했다. 이 자료들은 이번 업무의 조회 실적으로 계산하거나 편집 권리 근거로 승격하지 않는다.
- `core/staff_supervision.py`에 도구 선택 최대 2회, 최종 직원 보고 전용 슬롯 1회, 독립 관리자 최종 검토 슬롯 1회를 보장하는 흐름을 적용했다. 앞선 직원 판단에서 보고가 나오면 즉시 독립 검토를 할 수 있다. 관리자가 한 차례 보완을 지시하면 마지막 직원 호출과 최종 검토를 사용한다. 앞선 두 판단이 모두 수집이었다면 보존한 직원 호출로 보고를 작성한 뒤 독립 관리자가 검토한다. 최종 직원 보고와 관리자 검토가 없으면 달성으로 기록할 수 없다. 새 도구나 추가 호출이 필요한 보완은 별도 제안이다.
- 직원은 독립적으로 선택 가능한 승인 도구를 한 판단에서 최대 2개 제안할 수 있다. 각 선택의 이유를 받고, 같은 도구 반복과 공통 robots 전제에 의존하는 두 공식 페이지의 일괄 선택을 거부한다. 한 결과가 다음 경로를 결정해야 할 때는 별도 판단을 사용한다. 허용 묶음은 순차 실행하며 각 요청의 기존 서명·차감과 정확한 URL을 유지한다. 후행 실패 후 선행 관측을 보존하고 남은 실행과 자동 재시도를 차단한다.
- 새 감독 v3 제안에 보존 카탈로그 해시, 첫 실제 요청 해시, 현재 키, 기존 원장, 24시간 만료와 $0 조건을 결합했다. Gemini 직원 3회·관리자 2회, Tavily 1회, Klei robots 포함 GET 3회 이내다. 이전 범위와 승인·원장은 재사용하지 않는다. `studio/studio.js`에서 환경 차단, 보존 자료, 최종 보고·검토 몫과 승인 대기를 구분한다.

## 현재 공식 범위와 다음 검토

장면 2의 Don't Starve Together만 기존 Klei 공식 페이지 2개와 robots 1개를 조회할 수 있다. 장면 3의 World of Warcraft Forever는 제작사 공식 뉴스룸이나 프레스 채널, 장면 4의 Hogwarts Legacy는 공식 배급사 미디어·라이선스 채널이 후속 검토 후보이다. 로컬에서 승인된 장면명만 확인했다. 정확한 URL, 호스트·경로, 클립 편집 범위·표시 의무·제3자 권리는 미확인이고 두 장면에 대한 새 조회도 실행하지 않았다. 대상별 정확한 원문 경로와 접근 정책을 확인한 뒤 별도 범위로 검토한다. 보존 지표나 검색 단서로 이 권리를 대체할 수 없다.

## 구현·검증과 누적 사용량

- 관련 Python 40건과 Node 컷룸 시나리오를 통과했다. 외부 연결과 DNS를 차단한 모의 HTTP로 보존 자료 사전 제공, 오래됐거나 단서인 자료 제외, 비영상 재사용, 최종 보고 몫과 한 번의 보완, 묶음 상한·의존성·부분 실패, 악성 URL, 기존 실행 및 미승인·키·만료·철회·서명 오류·중복 실행·전송 실패 차단, 근거 부족 보류를 확인했다. 변경한 테스트는 `tests/test_research_replanning.py`, `tests/test_studio_server.py`다.
- 같은 모의 자료에서 공개 검색과 공식 페이지를 별도 판단으로 선택할 때는 Gemini 4회(직원 3회, 관리자 1회), 승인된 독립 묶음으로 선택할 때는 3회(직원 2회, 관리자 1회)였다. 두 경우 모두 Tavily 1회와 모의 GET 2회(robots와 HTML)를 차감하고 최종 직원 보고·독립 검토를 거쳤다. 이는 모의 효율 비교이며 실제 모델의 성능이나 비용 측정값이 아니다.
- 실제 Chromium을 임시 localhost에 연결해 보존 자료 12건, 최종 보고와 독립 검토 몫, Klei 경로 3개, 승인 전 실행 차단을 확인했다. 운영 서버를 중단하거나 재시작하지 않았다. 브라우저 요청은 localhost GET으로만 허용했다.
- 이전 누적 Gemini 예약 5회·완료 3회·기록 4,903토큰, Tavily 예약 0회와 이전 독립 관리자 보류를 확인했다. 신규 승인·예약·요청·응답·완료·운영 관측은 0건이다. 실제 Gemini·Tavily·공식 페이지 GET·YouTube·TTS·외부 미디어·다운로드·게시도 각각 0회다. 실제 권리 근거와 업무 목표 달성은 미검증이다.
- 기존 운영 파일 227개의 SHA-256이 전후 동일했다. 키·잠금은 비교 목록에서 제외했다. 기존 승인과 원장, 대본 v2, WAV 4개, MP4 1개, 대표 평가, 제작사·Commons 상태를 보존했다. 추가 백업은 만들지 않았다.

한 발행사의 여러 페이지는 독립 원출처로 계산하지 않는다. 현재 범위로 장면 3·4의 권리 목표를 충족할 수 없거나 직원이 순차 의존성 때문에 추가 결정을 요구하면, 목표와 필요한 출처, 최소 별도 요청 수를 독립 설계 검토로 넘긴다. 모델·무료 정책과 이번 한도를 그대로 유지했다.
