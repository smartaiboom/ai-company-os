# 공통 웹 조사·전문 API 교차 검증 능력 (2026-11-19 KST)
대표 확정 방향: 지금까지 사용한 전문 API 유지, 범용 웹 검색/페이지 탐색으로 다양한 자료 발굴, 전문 API 및 공식 출처로 교차 검증하여 주제와 산출물 품질 향상. 모든 조사에서 무조건 두 도구를 호출하지 않고 AI가 업무 특성에 맞게 선택. AGENTS.md에 이 원칙과 출처 독립성/신뢰도, 실제 검증, 무료 우선, 기획 시 제작 가능성 검토를 반영. 기존 전체 목표·구조 유지. 현행 공식 제작사 탐색 e8990467은 재사용하며 특정 제공처만 계속 추가하는 방식은 기본 전략으로 삼지 않는다.

core/autonomous_company.py, autonomous_gemini.py, autonomous_gemini35.py, ai_provider_adapter.py, owner_operating_policy.py, project_budget/ledger, quality_feedback.py, video employee_web_research.py, topic_research.py, publisher_discovery.py, commons_discovery.py, production_sources.py, asset_editing.py, 현재 컷룸 흐름 확인. AI가 실제 도구를 결정하는 지점 vs 코드가 미리 결정하는 지점, 결과를 AI에게 다시 전달하는 지점, 관리자 검토/경험 사용, 현재 실행 가능한 공통 도구 및 한계를 구분. 중복 구현/기존 기능 폐기 금지.
## 2. 공통 실행 가능한 범용 도구
현재 Gemini 3.5 Flash-Lite 무료 API 모델/프로젝트와 호환되는 실제 범용 웹 검색 수단을 공식 최신 문서로 확인. Google Search grounding 및 URL Context의 현재 모델 지원/무료 조건을 확인하되 무료라고 추정하지 않는다. 무료 범용 검색 API 후보(예: Brave Search 등)의 현재 가입/결제/크레딧/쿼터·약관, 현재 실제 접근 가능한지 조사. HTML 검색엔진 무단 스크래핑/차단 우회, 유료 전환, 브라우저 자동화가 곧 검색 서비스라는 혼동 금지. 무료·실행 가능 경로를 하나 이상 연결하는 것을 목표로 하되 검증 불가라면 정확한 차단 이유와 필요한 최소 설정/대안 제시. 신규 키는 환경 변수/비밀로, 실제 키 조회·발급·비용 승인 생성 금지. 기존 구독이 외부 API 무료 사용을 보장한다고 주장 금지.
공개 페이지 읽기/링크 탐색은 기존 publisher의 공개 IP/TLS/SSRF/robots/허용 호스트·경로/리다이렉트 제한, HTML/텍스트 추출 및 출처 표준화 재사용해 core 공통 도구로 분리/확장 검토. 링크·검색 응답은 비신뢰 데이터, 프롬프트 인젝션을 명령으로 취급 금지. 로그인/등록/접근 제한/robots 금지 우회 금지. 공개 페이지의 사실 조사와 미디어 다운로드/사용권 구분. 기존 YouTube·Commons·공식 제공처 어댑터는 전문 기능으로 유지.
## 3. AI 자율 도구 선택과 검증
core에 공통 tool registry/설명·실제 capability, 역할별 허용 범위, 구조화된 요청/결과/출처/시간/근거, 고정된 예산·타임아웃·원장, AI의 도구 선택→실행→결과 관찰→다음 선택/종료→관리자 검토를 연결. 기존 엔진 및 모델의 _tool_spec 등 활용, 기존 nested 도구와 중복 프레임워크 금지. 모델 네이티브 function calling이 가능한지 확인하되 기존 JSON 계약과 함께 사용 가능 여부 검증. 정형 검색/API와 공개 웹을 상황별 선택/조합하게 하며 모든 경우 미리 정해 둔 순서 강제 금지. 신뢰 출처 간 일치/상충/독립성/최신성/미확인 구분, 같은 정보 재게시를 독립 검증으로 계산 금지. API 수치가 검증할 수 있는 주장과 불가능한 주장 구분. 실제 소스와 인용 연결, 모델 허위 증거 차단. 근거 부족은 불확실 기록. 검색 실패와 호출 실패 구분, 완료된 이전 요청 재사용, 새 경로의 승인된 정상 후속 판단과 자동 재시도/유료 대체 구분. 실패/미확정 시 현 정책 준수. 관리자·직원에게 필요한 맥락과 결과/검증된 경험 전달. 공통 설계 및 실제 연결 하나 이상을 종단 검증하고 나머지 범위 명시.
## 4. 첫 미션 적용
현재 영상 미션과 차기 기획의 공통 사용 경로 연결. 기획에서는 전문 API 통계/웹 출처/실제 자료 확보 가능성을 종합해 주제·대본 선택. 기존 미션에서는 승인 대본 v2, WAV 4개, 840프레임, 기존 관리자/검색/권리 원장 보존, 재기획·재생성 금지. 기존 Commons 종료 상태에서 무한 검색 금지. 공식 제작사 탐색 경로를 새 공통 실행 구조의 전문 도구로 활용하고 새 범용 검색이 실제 연결 가능하면 승인 장면에 필요한 공식 미디어 출처와 허가 근거 발견/교차 확인에 활용하도록 준비. 현재 공식 탐색(Klei GET 최대4 및 Gemini 최대1) 미실행 상태 보존. 실제 웹 공개 검색 결과만으로 다운로드/편집권 확정 금지. 후보 충분 시 기존 권리 검토 및 편집·합성에 인계. 대표는 한 번의 신규 범위 승인과 실행으로 진행 가능하게 하고 기존 반복 수치 입력 및 장면별 승인 부활 금지. 기존 작업과 중복 호출 금지.
