# 처리 중 모달 UI 적용 보고서

## 변경 내용

- `app.py`의 공통 페이지 렌더링에 접근성 대화상자 역할을 가진 중앙 처리 모달을 추가했다. 표시 문구는 `작업 처리 중입니다. 잠시만 기다려 주세요.`이다.
- 모달 표시 중 페이지 본문을 `inert` 및 `aria-busy` 상태로 전환하고 스크롤을 막는다. 반투명 어두운 배경으로 뒤쪽 화면을 가린다.
- 기존 `data-processing-form` 공통 처리기에 전역 중복 제출 방지를 추가했다. 모달은 프로젝트 생성, 계획 승인·반려, 작업 실행·상태 저장, 프로젝트 변경 등 해당 공통 폼을 사용하는 화면에서 함께 적용된다.
- 정상 응답, 서버 오류, 네트워크 예외, 리다이렉트 모두 `finally`에서 모달과 화면 잠금 및 폼 상태를 복구한다. 버튼 문구 변경은 기존 기능으로 유지하며 모달을 대체하지 않는다.
- 기존 서버 업무 처리, 저장 형식, 프로젝트 데이터는 변경하지 않았다.

## 변경 파일

- `app.py`
- `tests/test_project_ui.py`
- `reports/modal_processing_ui_report.md`

## 확인 및 테스트

- 명령: `python -m unittest tests.test_project_ui tests.test_company_workflow_e2e tests.test_manager_plan_persistence tests.test_task_execution_persistence`
- 결과: 16개 테스트 통과 (`OK`).
- UI 회귀 테스트에서 모달 문구·대화상자 속성·어두운 배경·화면 잠금 및 복구·전역 중복 제출 방지·finally 해제를 확인했다.
- 실제 AI API 호출은 하지 않았다.
- 브라우저를 구동하는 자동화 테스트는 이 검사에 포함되지 않았다. 실제 브라우저별 표시와 키보드 포커스 동작은 별도 확인되지 않았다.

## 미해결 사항

- 테스트는 서버 렌더링 HTML과 공통 JavaScript의 주요 코드 경로를 정적으로 확인한다. 실제 브라우저에서의 시각적 표시 및 네트워크 단절을 포함한 엔드투엔드 인터랙션은 검증하지 않았다.
