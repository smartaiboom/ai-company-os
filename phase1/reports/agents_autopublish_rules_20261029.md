## 변경 내용

- 기존 `AGENTS.md`를 확인하고 Git 작업 섹션의 “별도 요청 없이는 commit/push하지 않는다” 규칙을 일반 개발·테스트 작업에서 검증 통과 후 자동으로 변경 범위를 확인해 스테이징·커밋·푸시하도록 수정했다.
- 필요한 경우 전용 브랜치에서 안전하게 main에 통합하고 force push하지 않도록 규정했다.
