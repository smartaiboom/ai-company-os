# 공통 개발 규칙 설정 결과

## 확인한 프로젝트 구조

작업 폴더의 주요 파일과 디렉터리는 다음과 같다.

- `app.py`: 로컬 웹 애플리케이션과 프로젝트·업무 흐름
- `execution_engine.py`: 모의 및 OpenAI 호환 업무 실행기
- `manager_plan.py`: 관리자 작업 계획 생성
- `tests/`: 실행기, 계획, 후속 검토 및 스모크 테스트
- `data/`: 저장된 프로젝트 데이터와 결과물 디렉터리
- `backups/`: 기존 백업

작업 폴더와 `/workspaces` 아래에서 기존 `AGENTS.md`는 발견되지 않았다. 기존 지침 파일의 내용은 없었으며, 기존 파일은 수정하지 않았다.

## 변경 파일

- `AGENTS.md` — 프로젝트 루트 공통 개발 규칙을 새로 작성했다.
- `reports/development_rules_setup.md` — 이번 설정 작업 결과를 저장했다.

애플리케이션 코드와 기존 업무 데이터는 변경하지 않았다.

## 포함한 규칙

- 변경 전 구조·코드·테스트·지침 확인 및 기존 기능 보존
- `openrouter/free`만 허용하고 실제 API 요청 전 모델 ID를 검사
- 유료 모델 fallback, 결제 및 비용 우회 금지
- 관련 테스트 실행과 실제 결과 기록
- 작업 보고서에 변경 파일·테스트·오류·API 호출 여부를 기록하고 다시 읽어 검증
- 비밀 정보 비기록, 무단 Git commit/push 및 기존 데이터 삭제 금지
- 보고서 접근이 불가능할 때 확인했다고 주장하지 않고 제한을 알림

## 검증 결과

- 지침 파일과 보고서를 다시 읽어 필수 규칙과 기록 항목을 확인했다.
- 애플리케이션 코드 변경이 없는 문서 설정 작업이므로 테스트는 실행하지 않았다.
- 오류: 없음.
- API 호출: 없음.
- Git commit/push: 없음.
