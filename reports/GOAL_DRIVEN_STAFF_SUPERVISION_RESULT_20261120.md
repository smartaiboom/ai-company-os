## 구현과 승인

- `core/staff_supervision.py`는 직원 업무와 관리자 재검토를 분리해 최대 한 번의 보완을 실행한다. 기존 회사 엔진의 기준별 관리자 점검과 역할 스키마를 재사용한다. 응답 형식 통과, 실행 관측과 출처 같은 객관적 조건, 관리자 의미 판단에 따른 목표 달성을 구분한다.
- `core/web_research.py`는 근거가 없고 가용 도구가 있으면 일반 종료를 거부한다. 사용할 수 없는 도구마다 이유를 남기는 보류는 허용하고 검토에서 미충족 조건을 확인한다. 승인 도구를 직원이 자율 선택하며 같은 옵션을 반복 예약하지 않는다. 관측 없음, 실행 후 빈 결과, 출처 부족, 공급자 실패·미확정을 구분한다. 근거 ID와 코드가 연결한 실제 발췌, 독립 출처와 검색 단서 제한은 기존 계약을 유지한다.
- `companies/video/research_supervision.py`는 기존 두 실패, 재계획, 독립 보류의 서명된 기록을 참조하는 새 업무를 생성한다. 직원에게 실제 관리자 지시와 장면별 성공 기준, 현재 도구와 범위, 보존 관측, 남은 예산을 전달한다. 관리자에게 사용한 도구·관측·카탈로그·직원 보류 이유·남은 호출을 전달하고 달성 확인, 보완, 대안, 대표 질문, 보류를 선택하게 한다. 근거가 없는 보고는 달성으로 처리할 수 없으며, 영상 권리 업무는 적격한 직접 확인 페이지를 참조한 지지 근거와 장면별 관리자 의미 검토를 요구한다. 증거·주장 내용에 진전이 없거나 마지막 검토에 도달하면 추가 자동 보완을 열지 않는다. 후속 제안은 별도 대표 검토 대상으로 기록한다.
- 신규 상한은 **직원 3회 + 관리자 2회 = Gemini 최대 5회**, Tavily 기본 검색 최대 1크레딧, 다운로드 0회, 비용 $0이다. 첫 검토 전 직원 결정은 최대 2회다. 관리자가 보완하면 남은 직원 실행 1회와 최종 독립 검토 1회를 쓴다. 마지막 직원이 도구 수집을 선택한 경우 최종 관리자에게 그 관측이 전달되며, 최신 직원 보고가 없으면 달성을 선언할 수 없다. 도구 고갈·예산 부족 시 별도 검토 제안만 남긴다. 새 서명에 이력·범위·계약·현재 키·24시간 만료·첫 실제 요청 해시를 결합하며 나머지 호출은 예약 시 본문 해시를 기록한다.
