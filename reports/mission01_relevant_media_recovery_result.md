# 미션 01 Commons 검색 복구 및 장면 적합성 · 2026-11-19 KST

## 운영 진단

기존 단일 진단 GET 1회가 완료됐다. `Don't Starve Together` 이미지 조회에서 5건 모두 원본 경로 검증을 통과했고 세 가지 출처 추적 값이 제거됐다. 1건은 크기 상한으로 기술 제외됐으며 나머지 4건은 기술을 통과했다. 이 가운데 코스프레 1건에 권리 제한이 기록됐고 포로 교환 사진 2건은 라이선스가 확인되지 않았다. `Acsscscs.png` 1건의 기존 권리 검토 기록은 보존했다. 제목만으로 해당 장면의 화면 근거를 확인할 수 없어 새 제작 후보에서는 적합성 대기로 처리했다. 현재 자동 편집에 사용할 적합 후보와 인수 자산은 각각 0건이다.

이번 진단은 추적 값 제거 후 실제 운영 응답을 정상 분류할 수 있음을 보여 준다. 원본이 보존되지 않은 개선 검색 30건의 개별 제외 사유를 복원할 수는 없다. 초기 검색 4회와 기존 Gemini 대안 1회, 개선 검색 8회, 단일 진단 GET 1회의 완료 기록은 보존했다.

## 새 승인 범위와 판단 기준

- 과거 확정 요청 해시를 확인해 이미 소비한 요청은 제외한다. 장면의 고유명이나 구체 주제에서 첫 단계의 `intitle:"정확한 구문"`과 후속 구문 검색을 구성한다. 파일 이름공간에서 영상·이미지 유형을 지정하고 기존 수정 파서로 원본 URL을 처리한다. 제한된 파일 설명·카테고리도 정제해 수집한다. 이미 다른 장면과 중복되지 않는 근거 있는 후보가 충분하면 후속 검색을 건너뛴다. 고유명 검색, 카테고리, 제목과 설명은 적합성을 높이는 검색 단서다. [CirrusSearch 구문](https://www.mediawiki.org/wiki/Help:CirrusSearch#Intitle_and_incategory), [MediaWiki 카테고리 API](https://www.mediawiki.org/wiki/API:Categories), [Imageinfo 공식 문서](https://www.mediawiki.org/wiki/API:Imageinfo/en)
- 미확인 권리, 명백한 무관 화면의 메타데이터, 검토 상한으로 제외한 항목과 사유를 기록한다. 장면당 최대 4개 적격 후보에서 승인 장면 목적, 후보 ID, 제목·설명·카테고리, 기존 대안·도구 한계만 무료 Gemini에 보낸다. 장면·후보별 **적합 후보 / 불명확 / 무관**과 **플레이 / 설명 이미지 / 유형 미확인**, 인용 근거가 남는다. 파일 제목이 모호하거나 실제 인용·주제 근거가 없으면 적합 판정을 수락하지 않는다. 영상·WAV·키 및 다운로드 주소 필드는 Gemini에 보내지 않는다. 자동 평가한 내용은 메타데이터이며 실제 영상·이미지와 권리는 직접 확인되지 않았다.
- 운영자는 한 번 승인한 뒤 검색과 적합성 검토를 한 번 실행한다. 이 작업은 **GET 최대 8회, 적합성 텍스트 최대 1회, 다운로드 0회, 비용 $0**이다. 적격 후보가 없으면 Gemini 호출을 생략한다. 실패·미확정, 완료와 예산 소진 후 재실행은 차단된다. 가용 무료 조건은 운영 승인 시 확인하며 공급자 요금·잔량을 독립 측정하지 않았다.
- 적합 후보는 기존 대표 권리·장면 일괄 검토 뒤 자산·편집 승인에 인계한다. 설명 이미지는 기존 표시가 붙는 합성 경로를 사용한다. `ClipJob`의 파일 확인 및 합성 결과의 샘플 프레임 검토는 유지된다. `audience_visual_review.py`는 검증된 로컬 60초 연구 결과의 계약이므로 다운로드 전 실제 장면 확인에 사용하지 않았다. 자동 시청 및 다운로드 전 자동 프레임 판정은 미연결이며 별도 취득 없이 시청 품질을 판정하지 않는다.
- 후보가 부족하면 이 Commons 범위에서 계속 검색하지 않는다. 명시적 직접 제공·다운로드·편집 허가가 있는 게임사 파일을 기존 공식 어댑터로 인수할 수 있다. 자체 캡처는 게임과 음원 등 사용권을 확인한 담당자가 로컬 자산으로 제공한다. 무료 생성 실행기는 권리·비용·실행 가능성이 확인되지 않아 미지원이다.

## 대표 조작과 검증

**현재 상태 / 다음 작업 → 관련 영상·이미지 복구 검토·승인 → 관련 자료 검색·적합성 검토 실행**을 선택한다. 통과 후보가 있으면 **적합 후보 권리·장면 검토**에서 원본과 권리를 확인한다. 모든 장면의 자료가 확보되어야 기존 **자산·편집 범위 검토·승인**으로 진행할 수 있다. 운영의 복구 승인은 아직 생성되지 않았다.

- 복제본에서 운영의 개선 검색·진단 결과와 WAV 4건의 바이트를 재사용했다. 정상 추적 URL, 무관 사진, 제목 불명확, 권리 제한, 관련 후보를 적용했다. 모의 검색 4회에서 후보가 충분해 추가 4회를 생략하고 모의 Gemini 1회로 판단했다. `Acsscscs.png`는 적합 후보에서 제외됐으며 근거 있는 모의 후보 4건만 권리 확인 후 기존 편집 경로로 인계했다. 검색 무결과 시 모델 생략, 조사 실패·모델 근거 위조·후보 ID 중복과 재실행 차단을 검증했다.
- 기존 환경과 루트로 운영 서버를 재시작했다. localhost 상세·JS/CSS·WAV 해시와 새 복구 승인 대기 상태를 확인했다. 승인 대본 v2, 네 WAV(3.68 / 7.36 / 5.16 / 6.40초), 840프레임 승인 타임라인, 진단과 기존 원장·대표 청취 기록 및 선택한 운영 JSON·미디어 해시를 보존했다.
- Python 회귀 36건 중 35건 통과, 1건 건너뜀. JavaScript 구문·상태 및 Git diff 검사 통과. 브라우저 실조작과 실제 게임 영상 품질은 미검증이다. 이번 실제 미션 Gemini·TTS·검색·다운로드·영상 생성 요청은 각각 **0회**다.
