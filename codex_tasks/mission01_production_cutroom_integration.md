# 미션 01 승인 기획과 제작·음성 연결 (2026-11-19 KST)
AGENTS.md 준수. 대표는 기존 35초 v2를 테스트 제작용으로 승인했고 실제 컷룸 production 단계에서 버튼이 없다. 기존 방향 유지: 대표의 간단한 목표/피드백, 관리자와 직원의 자율적인 업무, AI 호출 품질과 효율, 경험 재사용. 대본 재작업이나 새로운 기획은 하지 않는다.
## 진단 및 구현
- 실제 운영 프로젝트의 승인된 v2, 단계, 해시와 승인 결합을 읽기 전용 확인. studio.js production 분기에서 mission 프로젝트에 제작 사양 등록 대기만 표시되고 render_spec=null인 이유를 확인한다.
- 기존 production_video.py, video_production_company.py, representative_workflow.py, voice_quality.py, tts_job 및 기존 실제 Gemini TTS 청취 평가/실행/승인 경로, 로컬 렌더 모듈, 경험 저장소를 먼저 조사. 중복 개발 금지. 실제 음성 생성과 영상 제작을 승인된 대본/스토리보드로 연결하는 최소 범위를 구현한다. 기존 청취 평가에서 Gemini/Puck 자연스러움 7/10은 해당 표본에 대한 대표 평가이며 이번 게임 대상에 대한 품질 보증은 아니다. 관리자가 기존 경험 및 현재 대상/목표를 활용해 음성/장면 제작 지시를 결정할 수 있도록 관련 자료와 도구 능력/한계를 전달한다. 기계적 데이터 변환은 시스템 처리, 창작/판단은 AI 담당. 사용자가 상세 프롬프트나 장면 자료를 수동 복사하지 않도록 컷룸 연결.
- 이번 목표는 세로 9:16 게임 쇼츠 실제 영상 테스트. 기존 production_video_v2는 16:9 벡터 전용/espeak 참고 음성만 지원하므로 그 자체를 완성된 게임 영상 또는 자연스러운 한국어 음성으로 주장하지 않는다. 승인된 내레이션/장면/출처 상태 보존. 기존 도구로 9:16, 실제 음성 및 자막 싱크 결합 가능 여부 확인 후 필요한 최소 어댑터/렌더 변경. 화면 소스는 사용권 확인된 자료나 자체 생성 시안으로 제한; 외부 영상 무단 다운로드/재사용 금지. 미확보 게임 화면/실제 TTS/이미지 등은 정직하게 표시하며 검증되지 않은 소스는 자동 승인하지 않는다. 실제 제작 기능의 부족한 점을 명시.
- 실제 Gemini 텍스트/TTS/YouTube 등 외부 요청 0회, 유료 전환/자동 재시도 금지. 기존 무료 모델 및 기존 음성 후보의 사용 가능/무료 여부는 이전 기록을 검토하되 실제 추가 호출은 별도 대표 승인 없이는 금지. 텍스트/TTS 등 호출 범위/모델/예상 상한/전송 자료 및 요금 미확인 상태를 구분해 명확히 표시하는 준비/동의/실행 버튼을 연결한다. 이번에는 동의 생성 또는 실제 제작 자동 실행 금지. 시스템 렌더는 외부 비용 없음과 품질 한계 구분. 실제 승인된 프로젝트/원장/과거 보고서 보존. 기존 20회 Gemini 텍스트/YouTube 4회 보존.
- 실제 운영 복제본과 모의 응답/로컬 합성 테스트 자료로 승인 v2 → 제작 준비 → 승인 경로 → 음성/스토리보드 인계 → 세로 렌더 및 자막/음성 검증 → 대표 2차 검토까지 가능한 범위를 통합 검증. 실제 음성/영상 품질 미검증은 명시. 환경 FFmpeg, ffprobe, 폰트, espeak 등 실제 필요 도구 점검, 불필요한 설치 금지. 이전 espeak 미설치 이슈가 해당 경로에 필요한 경우에만 해결. 실제 외부 자료 없이 완전한 테스트가 불가능하면 미검증 범위 및 다음 최소 작업 명확히 보고. 큰 전면 재설계보다 기존 기능 재사용, 이번 단계에서 필요한 연결만.
- 운영 서버 변경 시 진행 중 작업 없는지 확인하고 기존 환경/루트 그대로 재시작하여 실제 localhost 상세 API 및 제작 버튼 조건 검증. 브라우저 실제 클릭은 미검증이면 명시.
