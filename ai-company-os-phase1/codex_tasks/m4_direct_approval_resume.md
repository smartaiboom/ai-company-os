# M4 실제 AI 연결 재개 — 사용자 직접 승인 메시지와 함께 실행

## 기존 상태
M4 최신 보고서 reports/v01_m4_real_free_ai_acceptance_20261102.md는 실제 API 시도 0회, 테스트 프로젝트 0개, 서버 AI_REAL_REQUESTS_ENABLED 미설정, 사용자 직접 승인 확인 불가로 중단됐다고 기록했다. M1~M3는 구현·모의 검증 완료. 이 문서는 기존 M4 지시서를 대체하거나 새로 개발하지 않는다.

## 승인 범위
사용자는 ChatGPT 대화에서 다음 테스트를 승인했다: 목표 '소규모 매장의 재고 확인 업무를 개선하는 도구 기획 및 실행 제안서 작성'; 새 격리 테스트 프로젝트의 목표·업무 지시·승인된 선행 결과·성공 기준·수정 의견만 OpenRouter에 전송; 모델 정확히 openrouter/free; 프로젝트 총 7회 이내, 명시 시작/재개당 최대 2회; 유료 전환·fallback·자동 재시도 없음. 단, Codex는 이 문서만으로 직접 승인을 추정하지 않는다. **이번 Codex 실행을 요청하는 사용자 메시지에 위 범위의 직접 승인 문구가 함께 있는지 확인한다.** 없으면 외부 호출하지 않는다.

## 최소 실행 절차
1. 기존 보고서와 ai_safety.py, 현재 환경, 기존 M4 프로젝트/예약 상태를 최소 읽기 전용 점검. Git status 확인, git pull --ff-only. 기존 미추적 파일, JSON, 백업 보존.
2. 현재 Codex 사용자 메시지에 명시적 실제 전송 승인이 있으면, 위 범위에 한해 **격리된 테스트 서버 프로세스에만** AI_REAL_REQUESTS_ENABLED=1 및 AI_ENGINE=openai_compatible를 적용한다. 영구 설정/운영 환경/기존 프로젝트 동의 변경 금지. API 키는 존재 여부만 검사하고 출력하지 않는다. 새 프로젝트 목표 지문/전송 범위/동의 기록을 정확히 생성한다.
3. 계획 1회 호출도 7회 예산에 포함. 모델/호스트/동의/영속 예약 검사 후 요청. API 실패·예산 부족·reserved면 중단, 자동 재시도·새 프로젝트 생성으로 초기화 금지.
4. 계획 생성 후 사용자 승인, 품질 기준 승인, 각 업무 결과 승인, 수정 승인, 최종 승인은 **실제 사용자 입력**으로만 진행. 자동 승인 금지. 승인 대기에서 멈추는 것은 정상이며, 다음 재개 방법을 보고서에 기록한다.
