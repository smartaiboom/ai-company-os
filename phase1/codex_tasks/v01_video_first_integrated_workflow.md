# v0.1 첫 실전 영상 제작: 실제 AI 협업 연결 통합 작업

## 고정 목표
AI Company OS는 범용 가상회사다. 사용자가 임의 목표를 입력하면 AI 관리자가 목표별 가변 작업·역할·선행 관계를 만들고, AI 직원들이 승인된 선행 결과를 받아 협업·의미 검토·수정 후 사용자가 최종 결과물을 확정한다. 첫 실전 사례만 영상 제작이며 영상 전용 하드코딩 금지. 기존 M1~M3 구현을 재사용하고 전체 재설계 금지. codex_tasks/README_KOREAN_LANGUAGE_RULE.md 준수: 진행/보고/최종 답변 한국어, 일본어 금지. KST.

## 이번 한 번의 통합 작업
1. 현재 main 및 최신 M4 보고서, 실제 엔진/계획/협업/검토/다운로드 경로의 관련 코드만 확인한다. 광범위한 재조사·문서 재작성 금지.
2. 영상 목표 예시 'AI 초보자에게 유용한 ChatGPT 활용법을 소개하는 1분 영상 제작'을 사용해 기존 모의 실행 경로로 계획→가변 직원 역할→선행 승인 결과 전달→검토→수정 1회→재검토→최종 대본·장면 구성표·편집 지시서 Markdown/JSON 산출물을 **하나의 통합 테스트**로 완주한다. 실제 MP4 생성/업로드는 현재 연결 도구가 없으면 완료 주장하지 말고 분리 표시. 목표별 역할은 관리자 계획에 따르며 고정 영상 역할을 코어에 강제하지 않는다.
3. 모의 통합에서 확인된 실제 연결 결함만 최소 수정한다. 영상 목표를 다른 프로젝트 기획으로 바꾸는 프롬프트 잔재, 승인 없는 자동 진행, 선행 결과 누락, 검토/재승인 경계, 다운로드 불일치 등을 우선. 필요한 집중 테스트만 실행. 이미 통과하는 경로를 재구현하지 않는다.
4. 실제 무료 AI 검증 준비: 기존 M4 재고 목표 프로젝트 c85d9853906a의 reserved 1/7과 보존 JSON을 절대 수정·리셋·재전송하지 않는다. 새 실제 영상 프로젝트 생성이나 외부 OpenRouter 호출은 **이번 작업에서 금지**. 이전 미확정 예약의 신뢰할 수 있는 종료 증거가 없으면 우회하지 않는다. 실제 영상 목표의 새 프로젝트/별도 전송 승인·예산은 후속 사용자 명시 동의 후 결정한다. 외부 호출은 승인 없이 절대 하지 않는다.
5. 다음 실전 실행이 한 번의 작업으로 가능하도록, 기존 안전 API를 이용한 실제 영상 프로젝트 생성/계획 실행의 구체적인 단일 절차와 현재 차단 요인을 보고서에 적는다. 필요하면 실제 API 실행기의 종료 관측을 작은 범위로 통합하되 mock만으로 검증하고 불확정 호출을 성공으로 간주하지 않는다. 별도 진단 작업을 계속 파생시키지 않는다.

## 완료 증거
- 영상 목표 모의 E2E에서 관리자 계획, 서로 다른 최소 3개 역할, 승인된 입력 전달, 의미 검토 및 수정·재검토, 최종 Markdown/JSON 내용 일치의 실제 테스트 결과. 불가능한 단계는 정확히 미완료 표기.
- 보고서 reports/v01_video_first_integrated_progress_20261102.md 새로 작성: 실제로 동작한 기능, 실패/수정, 집중 테스트 수, 실제 AI 호출 0, MP4/업로드 미구현 여부, 다음 단 하나의 실제 무료 AI 실행 단계와 필요 승인 조건. 이 보고서로 기존 로드맵을 대체하지 않는다.
- 프로젝트 JSON/백업/미추적 파일 보존, 선택적 git add, git diff --check, 커밋·푸시. 과도한 전체 회귀·브라우저 설치·코드 대량 재구성 금지.

## 시간·토큰 절약
먼저 기존 테스트/함수 재사용. 의미 있는 수정과 관련 검증을 한 번의 Codex 실행으로 묶고, 반복 분석보다 영상 목표의 완주 증거를 우선한다. 실패 시 핵심 원인과 다음 해결책을 하나만 보고한다.
