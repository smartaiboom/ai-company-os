# 미션 01 콘텐츠 품질 재작업 준비 결과 (2026-11-18 KST)

## 변경 내용

- 실제 컷룸의 게임 쇼츠 프로젝트가 **기획 승인 대기**, 보고서 **v1**, 제출 시각 **2026-11-18 12:47:23 KST**인 것을 확인하고 작업 지시의 초안을 로컬 작업 저장소에 저장했다. 초안은 프로젝트 ID, 최신 보고서 버전과 보고서 해시에 결합된다. 초안 자체의 체크섬도 검사한다. 다른 프로젝트, 변경된 보고서, 불일치한 체크섬 또는 이미 결정된 단계에서는 불러오지 않는다.
- 기존 **수정 요청**을 열면 해당 초안이 편집 가능한 피드백 칸에 표시된다. 조회만으로 대표 결정이나 재작업은 생성되지 않는다. 원본 프로젝트 파일이 바이트 단위로 동일함을 확인했다. 기존 v1과 저장된 Gemini 8회·YouTube 4회 기록을 보존했다.
- 재작업 입력은 승인 요청에 결합된 기존 대본·스토리보드와 관측 자료에 더해, 이전 관리자의 주제·길이 선정 기록 및 조사 한계를 전달한다. 추가 웹 조사 사용 불가를 명시한다. 기존 재작업 엔진과 동의·호출 한도를 사용한다.
- **대표 검토 Markdown 내려받기**는 현재 선택한 보고서 버전의 목표, 주제·길이 근거, 공개 출처와 한계, 내레이션·장면, 관리자 검토 및 호출 집계를 로컬 파일로 내려받는다. 이전 버전과 새 버전을 각각 내려받아 비교할 수 있다. 원장과 서명, 인증 필드를 포함하지 않으며, 내보내기 항목을 제한하고 자유문에 포함된 일반적인 키·연락처·식별자 패턴을 마스킹한다. 이름 등 문맥에 따라 개인 정보가 되는 문구는 외부 공유 전에 사람이 확인해야 한다. 자동 업로드나 외부 전송은 없다.

## 기존 프로젝트에서 진행하는 순서

1. 기존 작업 경로와 환경 설정으로 **컷룸 서버를 재시작**한 뒤 화면을 새로고침한다. 이번 작업에서 운영 서버를 재시작하지 않았다.
2. 기존 프로젝트의 **기획·대본 v1 → 수정 요청**을 연다. 표시된 로컬 초안을 읽고 필요하면 편집한다. 모달의 **수정 요청**을 눌러야 대표 결정이 저장된다.
3. **AI 재작업 동의 준비**에서 기존 무료 프로젝트와 키 소속·결제 조건을 확인한다. 이어서 **새 외부 전송 동의**에서 전송 범위를 검토하고 동의하는 경우 **이 범위에 동의**를 누른다.
4. **AI 재작업 시작**을 별도로 누르면 Gemini 호출을 시작한다. 새 서명 동의는 해당 재작업 한 건에만 적용된다. 고정 무료 Gemini 요청 상한은 7회, 전체 수정 상한은 1회다. 기존 조사 자료를 활용하며 YouTube 재조회, 자동 재시도, 유료 전환, 렌더 및 게시를 포함하지 않는다.
5. 다음 기획이 제출되면 **기획 버전**에서 v1과 후속 버전을 골라 **대표 검토 Markdown 내려받기**로 각각 저장한다.

## 검증과 남은 범위

- Python 3.14.4에서 지정된 핵심 통합 테스트 **86개**, 컷룸 서버 테스트 **5개**가 통과했다. 실패·오류는 0개였다. JavaScript 문법 검사와 `git diff --check`도 통과했다.
- 임시 저장소에서 초안의 프로젝트·버전·보고서 해시·체크섬 불일치 차단, 조회만으로 원본과 대표 결정이 바뀌지 않는 점, 명시적 수정 요청 경로를 확인했다. Markdown 테스트에서 보고서 버전 선택, 공개 링크, 호출 집계, 민감 필드 제외와 비공개 URL 제거를 확인했다.
- 실제 v1을 읽기 전용으로 확인하고, 임시 복제본에서 기존 대본과 관측 자료 10건, 관리자 선정 근거를 그대로 재사용하는지 확인했다. 별도 모의 동의와 기존 7회 실행 사전 검사를 통과했다. 실제 프로젝트에서는 동의·결정·실행을 생성하지 않았다.
- 임시 localhost 서버에서 초안 조회 HTTP 200, 토큰 없는 내보내기 HTTP 403, 토큰을 포함한 내보내기 HTTP 200을 확인했다. 브라우저 조작과 실제 AI 재작업 결과는 미검증이다. 이전 `espeak-ng` 미설치 렌더 테스트는 이번 범위에서 재실행하지 않았다.
- 이번 작업의 실제 Gemini·YouTube 요청과 유료 실행은 **0회**다. 새 대본을 대신 작성하지 않았다.
