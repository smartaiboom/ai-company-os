## 이번에 확인된 마지막 입력
대표가 Google Cloud Console 「사용자 인증 정보」 화면을 제공했다. 화면 상단 선택 프로젝트는 `Default Gemini Project`이며, **같은 프로젝트의 API 키 목록에 `youtube data`(YouTube Data API v3로 제한)와 `Default Gemini API Key`(Gemini API로 제한)가 함께 존재**한다.
대표가 이전에 제공한 이 프로젝트의 실제 프로젝트 ID는 **`gen-lang-client-0938732315`**이다.
따라서 현재 작업의 `--account-project`와 `--youtube-project`에는 동일하게 `gen-lang-client-0938732315`를 사용할 수 있다. 사용자 제공 화면과 URL로 확인한 사실이며 Codex가 공급자 콘솔에서 독립 검증했다고 주장하지 말 것. **API 키 원문·서비스 계정 주소는 GitHub에 기록하지 말 것.**

사용자는 이 프로젝트에 결제 계정이 연결되어 있지 않다고 확인했다. 잔여 호출량이 불명인 경우 기존 `unknown` 경로를 사용하며, 이전에 완료한 키·쿼터·Billing 감사와 코드 수정 및 20개 회귀 테스트를 반복하지 않는다.

## 작업 절차
1. GitHub를 안전하게 fast-forward 동기화하고 `AGENTS.md` 및 최근 `reports/VIDEO_MISSION_01_QUOTA_GATE_FIX_AND_EXECUTION_RESULT_20261111.md`, `reports/VIDEO_MISSION_01_FINAL_REAL_RUN_RESULT_20261111.md`를 참조한다. 소스·데이터·기존 원장 변경 없이 최신 한 번 실행 가능한지 중복 시도만 확인한다.
2. 위 확인된 **두 CLI 프로젝트 ID를 동일하게 적용**한다. 숫자 잔여량은 임의 생성하지 않고 `unknown`을 사용한다. 모델·엔드포인트·무료 실행 가드를 우회하지 않는다.
3. 기존 `video_mission_one prepare`로 검토 가능한 제안 JSON과 해시를 얻고, 서명 동의 범위가 실제 승인과 정확히 같은지 확인한 뒤 `approve`하여 원장에 저장한다. 키 바인딩·제안 만료·사용자 승인 상한·무료 전용 조건은 기존 로직에 맡긴다.
4. 조건이 충족되면 `run`을 한 번만 실행한다. 별도 API 시험 호출 금지. 첫 실제 모델 요청도 최대 10회 안에서 차감하고 실패/불명 요청은 소비 처리한다. 공급자가 무료 모델을 제공하지 않거나 청구 위험/키 제한 오류가 드러나면 재시도·fallback 없이 중단하고 오류를 기록한다.
5. 성공하면 실제 AI 조사 직원이 YouTube 질의를 스스로 만들고 게임 후보와 실제 영상 길이를 조사한다. 관리자가 게임 소재와 길이를 독립적으로 결정하고 대본 직원이 한국어 전체 대본·장면 기획을 작성한다. 내부 검토 완료 후 컷룸 `awaiting_plan_approval`까지 올린다. Codex가 임의로 게임·길이 근거를 공급하거나 mock을 실제 결과로 위장하지 않는다.
6. 모든 KST 기록 및 기존 파일·키·음성/영상·데이터/백업/시도 원장 보존. 사용자가 검토하기 전에 다음 단계 진행 금지.
