# 미션 01 편집 인계 오류 및 호출 효율 개선 (2026-11-18 KST)
AGENTS.md 준수. 실제 16:05 KST 관리자 재검토 통과, 편집 execute HTTP200/json_parsed 후 script_editor_handoff_mismatch. 누적 Gemini 19회, YouTube 4회 보존. 실제 API 0회.
1. 운영 중단 작업의 승인 대본, 편집 호출 context, 기대 script_editor_handoff와 실제 응답 저장 유무를 확인. 원문이 없다면 정확한 불일치 필드 단정 금지. 요청 재구성 시 원장 해시 일치 여부 명시. writer_ref.result_hash를 실제 모델에게 전달했는지, editor가 어떤 창의적 업무를 요청받았는지 확인.
2. 현재 script_quality.py의 validate_script_editor는 script_editor_handoff(writer)와 전체 객체가 동일한지 검사한다. 기계적으로 복사/해시 생성만 요구하는 일은 AI 호출할 이유가 없음. 정확한 인계 메타데이터 및 대본에서 손실 없는 스토리보드 투영은 시스템 책임으로 분리하는 방안을 우선 검토. 기존 설계/승인/출처/대본 보존 조건을 유지하고 AI 편집자의 실제 창의적 연출 업무와 구분. 이번 범위에서 새 편집 계약을 크게 재설계하지 말고, 안전하다면 기존 계약상 결정론적 투영을 시스템 산출물로 명시적으로 생성하고 관리자 검토로 전달하는 최소 공통 개선. AI 편집 결과로 위장 금지, 검증 완화나 미저장 응답 재구성 금지. 기존 원장 및 승인 서명과 호환, 기계적 투영을 기존 AI 호출로 허위 기록하지 않는다. 안전한 구현이 불가능하면 진단 및 대안만 보고.
3. 현재 중단 작업에서 이미 수락한 대본과 관리자 검토를 보존하고 편집/스토리보드 검토부터 이어갈 수 있는 기존 복구 또는 최소 새 경로 확인. 전송 불확실 상태 제외, 기존 작업 덮어쓰기 금지, 새 명시적 대표 승인/동의 전 호출 금지. 무료 고정/자동 재시도 금지. 기계적 인계 생성으로 실제 AI 호출 절약 가능 여부와 예상 호출 순서 보고. 실제 품질 검토를 우회하지 않는다.
4. 오프라인 회귀 및 실제 운영 복제본에서 인계 동일성/메타데이터/승인/과거 호환/호출 차감/관리자 검토 단계 확인. 운영 서버 변경 필요 시 진행 중 작업 확인 후 기존 환경 재시작 및 localhost 검증. 대표 결정 및 동의 생성 금지. reports/mission01_editor_handoff_diagnosis_result.md에 원인, 변경 전후 AI 호출, 실제 모델에게 맡기는 판단 업무와 시스템 업무 구분, 테스트, 다음 대표 조작, 실제 API 0회 명시. 검증된 코드/보고서만 commit/push origin main, 원격 보고서 존재 확인. 운영 데이터/키/서명 제외. 사용자 직접 push 승인 범위 내 진행.
