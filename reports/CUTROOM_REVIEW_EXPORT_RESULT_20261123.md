2026-11-23 KST. feb1218에서 기준 e038684로 fast-forward했다. 저장된 운영 보고서 v1~v4와 대표 결정·호출 원장을 읽기 전용으로 확인했다. v4는 15:34:33 KST 공급자 모델 결과이며 대표 검토 대기와 관리자 보류 상태를 유지한다.

## 구현과 공개 범위

컷룸에서 보고서가 있는 프로젝트를 열면 검토 요약을 Git 제외 로컬 경로의 고정 latest.md로 생성한다. 동일한 바이트는 다시 쓰지 않으며 다음 보고서가 나오면 같은 파일을 원자적으로 교체한다. 컷룸에 요약 생성 상태, 공개 내용 미리보기와 마지막으로 동기화한 GitHub main 파일의 일치 여부가 표시된다. 비교는 로컬 원격 추적 브랜치로만 수행하며 서버는 GitHub로 접속하거나 푸시하지 않는다. 불일치나 확인 실패 시 공유 상태를 표시하지 않는다.

프로젝트는 비식별 이름과 분야로 나타낸다. 서명된 최신 보고서에서 실제 관측 그룹의 YouTube 공개 URL·제목·수치·시각만 허용하고 후보 출처는 공개용 S 번호로 바꾼다. 시각은 KST로 변환한다. 후보명은 인용 공개 제목에 근거해 제한적으로 표시한다. 요약과 판단 사유는 구조화된 증거 개수, 보류 여부와 한계에서 파생했다. 모델의 자유형 설명, 도입부 추측, 원래 목표, 제약·대표 의견 전문, 원문 발췌, 자격증명, 서명·내부 식별자, 운영 원장과 경로는 내보내지 않는다. 공개 영상 제목에도 민감 패턴 검사와 문법 정리를 적용했다. 자동 공개 기능은 연결하지 않았다.

이번에 검토할 단일 v4 요약만 고정 공개 파일로 생성했다. 공개 표본은 5개, 인용 후보는 모두 마인크래프트다. 다른 모바일 게임 3종 비교, Shorts 분류, 실제 영상 시청 및 편집권은 확인되지 않았다. 과거 v1~v3는 버전·결정·관측 건수만 표기한다.

## 검증과 다음 사용 방법

Python 7건, 컷룸 Node 시나리오 및 실제 로컬 v4를 읽는 임시 localhost HTTP 200을 검증했다. 민감 패턴과 자유형 필드 제외, 공개 호스트 제한, KST 변환, 비공개 상태, 고정 파일 교체, 옛 원격 내용과 새 요약 불일치, 실제 영상 링크 5건과 관리자 보류 표시를 확인했다. 운영 및 시범 파일 606개 체크섬이 일치했다(키·잠금 제외). 실제 Gemini·YouTube·Tavily 호출, 운영 승인 소비 및 대본·영상 제작 0회다.

현재 공개 검토의 정확한 경로는 [reports/review_exports/mobile_game_latest.md](https://github.com/smartaiboom/ai-company-os/blob/main/reports/review_exports/mobile_game_latest.md)다. 대표는 **“결과 나왔어”라고 알려** 이 파일로 검토를 요청하면 된다. 이후 새 버전의 공개는 미리보기와 별도 공개 허용이 필요하다. Codex는 프로젝트 루트에서 다음 명령으로 확인한 버전 한 건의 고정 게시 파일을 준비할 수 있다. git 푸시는 별도로 명시 승인된 게시에서 수행한다.

    PYTHONPATH=core:companies/video .venv/bin/python -m review_export --project <프로젝트ID> --confirmed-public-version <검토한버전>
