# 사용자 결과 검토·수정 경험의 다음 업무 재사용 통합
2026-11-25 KST · 기준 14e5f29. DEVELOPMENT_WORKFLOW.md, AGENTS.md 준수.
## 목표와 우선순위
사용자와 AI가 협업하여 결과물을 개선하는 v1.0 핵심 흐름. Groq 403 및 자동 권한 심사 거절, Gemini 503은 별도 미해결 장애로 보존하고 추가 외부 통신 진단/공급자 변경은 이번 범위에서 하지 않는다. 실제 AI 종단간 완료는 정상 허용 연결 확보 후 별도 검증해야 한다. 기존 영상 제작 및 검토 기능을 재개발하지 않는다.
## 확인된 연결 공백
core/quality_feedback.py ExperienceJournal/ROLE_CONTRACTS/select_experiences, companies/video/representative_workflow.py decide/create, companies/video/collaboration_handoff.py execute/publish_plan, quality_workflow.py 및 studio API/UI의 실제 소비 경로 확인. 현재 execute inputs.experiences=[] 고정, 대표 decide 최종 승인 시 flow.experiences에 단일 일반 승인 경험 추가. 구체적 수정 의견의 적용 결과 및 다음 프로젝트 연결이 실질적으로 검증되지 않았다. 기존 경험 저장소/선택/프로젝트 바인딩을 우선 재사용하고 별도 중복 시스템 구축 금지.
## 작업
- 기존 대본/영상 검토 화면에서 대표가 버전·해시를 기준으로 자연어 의견 및 수정 방향을 기록하고, 실제 수정본 비교 후 유지할 선호/검증된 교훈을 선택하거나 직접 정리할 수 있게 한다. 불필요한 중간 승인 화면 추가 금지. 사용자 확인한 선호와 객관적 개선 검증을 분리; 기술 시안은 최종 승인으로 승격 금지. 실제 사람이 보거나 듣지 않은 품질을 검증으로 표시 금지. 기존 원문/버전/수정 결과 연결, 출처/유효 범위/철회·대체/중복 방지.
- 같은 분야/대상 및 적합한 업무 조건에만 경험을 선택하여 다음 프로젝트의 관리자 기획과 직원 업무 컨텍스트에 실제 연결한다. 선택/제외 근거와 기록 해시/적용 여부를 컷룸에서 확인 가능하게 한다. 서로 다른 대상, 철회 경험, 상충 또는 미검증 경험의 무조건 적용 금지. 모의 경험과 실제 사용자 선호 분리. 기존 프로젝트 생성 시 경험 연결 및 core 기존 선택 정책을 조사해 필요한 최소 변경. 모든 외부 요청은 기존 승인 데이터 범위를 준수해야 하며 경험이 포함되는 경우 승인된 전송 범위와 정확히 일치하지 않으면 외부 전송하지 않는다. 새 민감 데이터/전송 범위 자동 확대 금지.
- 사용자 수정 의견→관리자/직원 역할 작업 컨텍스트→수정된 대본/영상→대표 검토→경험 저장→다음 신규 프로젝트의 실제 선택·업무 입력까지 격리 컷룸에서 기능 단위 통합 검증. 기존 실제 Heami 음성/MP4 렌더러가 사용 가능하면 활용하고, 가상 대본/AI fixture임을 명시한다. 예시: 가상 안내 영상의 말투/자막 길이 수정 및 다음 동일 대상 업무 재사용, 다른 대상에는 제외. 실제 파일 재생 가능 여부와 기술 지표를 확인하고 실제 시청자 선호는 미검증으로 남긴다. 사용자에게 개발 중 반복 실행을 요구하지 않는다.
- 공급자 장애 중에도 사용자 검토/저장/다음 작업 준비가 가능한지 확인. AI 실행 실패 상태를 성공 처리하거나 mock을 실제 AI로 대체 표시 금지. 기존 정책/원장/데이터 보존. 이번 외부 호출은 장애·승인 문제로 실행하지 않으며, 실제 AI 적용 검증은 미완료로 표시. 연결 복구 후 어느 정상 실행 경로에서 검증할지 명시.
