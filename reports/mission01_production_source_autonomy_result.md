# 미션 01 제작 자산 확보 · 2026-11-19 KST

## 운영 상태와 변경

운영은 **영상 수정 요청 → 자산 확보 대기**다. 승인된 35초 v2, 무음 기술 시안 v1, 대표 수정 요청, 완료된 관리자 계획 1회와 서명·원장을 보존했다. 관리자 원문은 Puck/Gemini 3.8 Flash TTS와 0–3 / 3–14 / 14–24 / 24–35초의 네 장면을 요구한다. 기존 공개 메타데이터 참조는 검색 단서다. 장면별 실제 화면이나 권리는 확인되지 않았다. 운영에는 인수 클립, 등록 라이브러리 자산, 준비된 장면 음성이 각각 0개다. 제작 키 대조 설정은 재시작 후에도 유효하며 TTS 실행 스위치는 꺼져 있다.

기존 관리자 계약은 `operator_clip` 또는 `hold`, 레터박스, 컷만 허용했다. 프롬프트도 자동 획득을 막았으므로 로컬 파일 요청은 도구 제약의 결과였다. 현재 계획 원문과 원문 해시를 보존하고 영어 설명을 원래 언어로 표시한다. 새 관리자/직원 요청에는 한국어 설명, 원본 ID·도구명 유지, 이 프로젝트의 후크, 장면 의미·몰입·움직임·다양성 및 자연스러운 음성 검토 지시를 적용한다. 모델이 시청·청취하지 않은 품질은 미평가 상태다.

## 대표 다음 조작

1. 컷룸에서 프로젝트를 새로고침한다. **현재 상태 / 다음 작업 → 제작 작업 선택 → 장면 음성 · scene-1 → 장면 음성 준비**로 첫 장면부터 시작할 수 있다. 무료·지역·잔량을 확인하고 **장면 음성 동의**에서 승인 원문과 요청을 검토한다. 실제로 실행할 때만 기존 서버 환경에 `GEMINI_PRODUCTION_TTS_ENABLED=1`을 적용해 재시작하고 **장면 음성 실행**을 선택한다. 장면별 1회, 총 최대 4회이며 실패·미확정도 차감한다. 등록 클립은 이 단계의 선행조건이 아니다.
2. **제작 작업 선택 → 자산 확보 업무 → 자산 확보 업무 준비 → 자산 확보 업무 외부 전송 동의 → 자산 확보 직원 실행**으로 별도 요청을 검토한다. 무료·결제 미연결·현행 문서·잔여 쿼터를 확인한다. 재사용할 적법한 자산이 있다면 승인 준비 전에 운영 데이터 루트 `data/video_representative_workflow/studio/production_source_library/`에 MP4와 `inventory.json`을 등록한다. 목록은 최대 24건의 배열이고 각 행에는 `id`, `file`(MP4 파일명), `sha256`, `description`, `origin`(`official_direct_media`, `own_capture`, `rights_cleared_local`), `rights`(출처·허용 용도 근거), `local_review_allowed: true`가 필요하다. 기존 파일별 인수도 선택할 수 있다.
3. **관련 상세 보기 → 제작 상세**에서 직원 제안과 원본 관리자 계획을 확인한다. 등록 소스가 선택되면 **선택된 로컬 자산 인수**로 실제 장면을 확인해 들여온다. 음성은 제작 상세에서 청취할 수 있다. 새 장면 음성의 파일 수락 한도는 20초이며 별도의 장면 길이 제한은 유지된다. 3초 장면의 24자 발화가 시간 안에 들어가는지는 실제 청취·실측이 필요하다. 초과한 WAV는 보존하고 렌더 예약 전에 차단한다. 자동 가속, 자르기, 묵음 대체, 타임라인 변경, 재호출은 없다. 승인 대본이나 타임라인을 바꾸려면 별도 대표 승인이 필요하며 이 화면에서 변경 승인을 시작하는 기능은 이번 범위에 포함되지 않았다.
