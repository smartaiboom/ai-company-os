# 컷룸 · 대표 영상 제작 스튜디오 — 2026-11-11 KST

Stage B를 기존 `RepresentativeVideoWorkflow`에 연결했다. 대시보드는 저장된 승인 대기·제작·수정·완료 건수, 프로젝트 카드, 실제 키프레임과 담당 역할을 표시한다. 기존 검증 사례는 읽기 전용이고 이전 주제 3안은 대표 선택 보류 상태로 표시한다.

## 실행 및 사용

저장소 루트에서 실행한다.

```bash
PYTHONPATH=core:companies/video python -B -m studio_server --host 0.0.0.0 --port 8000
```

Codespaces의 **Ports → 8000 → Open in Browser**로 접속한다. 포트 가시성은 **Private**으로 유지한다. 로컬에서는 기본 바인딩 `127.0.0.1`을 사용한다. 새 작업은 `data/video_representative_workflow/studio/`에 저장된다. 별도 스토어로 실행하려면 `--root`, 읽기 전용 검증 사례를 지정하려면 반복 가능한 `--reference`를 사용한다.

- **대시보드**에서 새 프로젝트를 만들거나 상태 카드로 프로젝트를 거른다. 목표만 입력해도 된다. 기획 작업 열기는 기존 내부 작업을 열어 보고서를 기다린다.
- **기획 검토**에서 주제, 출처·시점·권리, 전체 대본, 장면 스토리보드, 전후 버전을 확인하고 승인 또는 피드백을 저장한다. 보고서가 생기면 새로고침으로 확인할 수 있다.
- **영상 검토**에서 승인된 기획으로 로컬 기술 시안을 명시적으로 렌더하거나 등록된 MP4를 재생한다. 버전별로 영상과 승인 기획 SHA, 음성·자막·QA·소스 권리를 확인한다. 영상 반려 시 대본 변경을 표시하면 기획 재승인으로 돌아간다. 최종 완료는 현재 영상의 대표 승인과 파일 검증이 끝나야 표시된다.

표준 라이브러리 HTTP 서버와 로컬 HTML/CSS/JS를 사용한다. 변경 요청은 세션 토큰을 확인하고, 단계·버전·SHA·파일 검증은 기존 워크플로가 처리한다. 생성 요청 키는 프로젝트에 저장되므로 같은 요청이 다시 들어와도 프로젝트가 늘어나지 않는다. MP4는 프로젝트·버전과 영수증 해시가 일치하는 경로만 동일 출처에서 Range로 전송한다.

## 실행 검증

- Chromium 1440×1000과 390px 폭에서 실제 렌더 화면을 열어 카드 정렬, 상태 배지, 본문 가독성, 실물 썸네일, 플레이어, 좁은 화면 오버플로를 확인했다. 390px 페이지의 스크롤 폭은 390px이었다. 기존 60.023초 H.264/AAC MP4가 실제로 재생됐다.
- 원본을 복제한 별도 테스트 스토어에서 브라우저로 프로젝트 생성→새로고침→기획 대기, 기획 승인·반려와 원문 피드백, 영상 반려→로컬 v2 렌더→버전 비교→최종 승인·재접속을 실행했다. 별도 사례로 대본 변경 요청에 따른 기획 재승인 복귀를 확인했다. 실제 재렌더는 격리 스토어에서 1회였다.
- HTTP에서 기획 승인 전 제작, 오래된 SHA, 중복 승인(409), 토큰 없는 변경(403), 변조 경로(404), 영상 부분 요청(206)을 확인했다. 버전 선택의 접근성 이름을 수정한 뒤 이전 버전에서 승인 동작이 나타나지 않고 최신 버전으로 돌아와 완료되는 것을 확인했다.
- Python 관련 테스트 **17개 통과**, JavaScript 문법 검사 통과. 화면 캡처는 로컬 `data/video_representative_workflow/20261111_ui_evidence/`의 `studio-dashboard.png`, `studio-project.png`, `studio-mobile.png`, `studio-plan-review.png`, `studio-video-review.png`에 보존했다.

기획 및 관리자·직원 판단은 오프라인 검증 입력이다. 실제 모델 호출은 0회다. 현재 기술 시안은 16:9 벡터·장면 단위 자막·eSpeak 참조 음성이고, 사용자 평가를 받은 Gemini 음원은 기존 자료로 보존했다. 외부 API·유료 사용·업로드·게시 없이 진행했다. C단계는 대표가 UI를 사용한 뒤 조사·기획·대본 품질에 대한 피드백을 받아 진행할 수 있다.
