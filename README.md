# AI Company OS

**현재 제품 개발 목표: AI Company OS v1.0**

사용자의 목표를 구체화하고, 분야별 전문 AI 협업으로 산출물을 만들며, 실제 품질 평가·사용자 피드백·경험 재사용을 통해 다음 프로젝트에서 품질과 효율이 개선되는 AI 회사 시스템.

## 저장소 정리 상태 — 2026-11-09 (KST)

- `phase1/` — **기존 Phase 1 Git 추적 파일 전체의 변경 없는 보관본**. 과거 개발 코드, 회귀 테스트, 개발 지시서, 보고서, 실험 기록을 보존한다.
- `ai-company-os-phase1/` — **기존 Codespaces 실행 경로와 데이터의 호환성을 위해 임시 유지하는 원본 개발 폴더**. 당장은 삭제하거나 이 폴더의 실사용 프로젝트를 재실행하지 않는다.
- **저장소 최상위** — 단계별 이관 검증을 거쳐 v1.0의 운영 코드·핵심 테스트·문서만 배치할 작업 영역. 아직 v1.0 실행 코드의 이전은 완료되지 않았다.

> `phase1/`은 Git에 추적된 파일을 보관한 것이다. Codespaces의 `data/`, `backups/`, `artifacts/`, 비추적 파일과 비밀키는 Git으로 복제되지 않는다. 해당 자료를 삭제·이동하거나 `git clean`·`reset --hard`를 실행하지 않는다.

## 정리와 개발 원칙

1. v1.0 운영 루트에는 **실제로 필요한 코드, 계속 사용할 핵심 테스트와 현재 문서만** 둔다.
2. 기존 AI 관리자/직원, 모델 연결, 안전·비용 원장 기능은 의존성과 실제 실행을 확인한 뒤 재사용한다. 처음부터 같은 기능을 재개발하지 않는다.
3. 기존 원본을 바로 제거하지 않고, 핵심 코드 분리 → 테스트·실제 실행 확인 → Codespaces 비추적 자료 보호 확인 → 오래된 추적 파일 정리 순서로 진행한다.
4. 일회성 진단과 이전 개발 보고서는 제품 실행 루트가 아니라 보관 영역에서 관리한다. 테스트 전체를 무조건 삭제하지 않는다.
5. **Codex는 코드 구현·실행 검증에 집중**, GitHub 조사·정리 계획·문서와 안전한 파일 구성은 ChatGPT가 가능한 만큼 직접 처리한다.
6. 모든 실제 외부 AI 호출·데이터 전송·유료 비용은 프로젝트별 권한과 원장 정책을 지킨다. 시간은 KST.

## 제품 v1.0의 첫 검증

목표 구체화 문답 → AI 관리자/직원 제작·내부 검토 → 사용자 결과 평가와 수정 → 평가·개선 근거 저장 → 다음 프로젝트에서 관련 경험 검색·반영. 단순히 데이터를 저장하는 것이 아니라 **실제 품질 향상 여부**를 비교한다.

장기 목표는 분야별 전문 역량과 경험 축적에 기반한 자율 운영이다. 이후 **AI Company OS vs ChatGPT** 동일 조건·시간 경과 비교로 차별점을 검증한다.
