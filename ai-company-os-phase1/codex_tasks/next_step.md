# 다음 작업: 브라우저 검증 환경 준비 및 미완료 결과 원격 반영

**상태:** 완료 — 2026-10-30 Playwright/Chromium 환경을 준비하고 실제 브라우저 UI 회귀 검증 및 전체 테스트를 통과했다. 결과는 [`review_approval_browser_ui_report.md`](../reports/review_approval_browser_ui_report.md)에 기록했다.

## 배경
검토 승인 게이트의 HTTP 통합 검증은 완료됐지만, 실제 브라우저 자동화 도구와 브라우저 실행 파일이 없어 브라우저 UI 검증은 미완료 상태다. 직전 Codex 실행에서는 이 제한과 대체 테스트 결과를 보고서에 기록하고 작업 이력 및 이 파일을 수정했으나, 브라우저 검증 미완료를 이유로 커밋·푸시하지 않았다.

이번 작업의 목표는 브라우저 자동화 환경을 안전하게 준비할 수 있는지 확인하고, 가능하면 브라우저 UI 검증까지 완료하는 것이다. 또한 직전 실행에서 생성·수정했지만 아직 원격에 반영되지 않은 보고서와 작업 이력을 보존하여, 검증된 변경을 원격 저장소에 반영한다.

## 시작 전 필수 확인
- `ai-company-os-phase1/AGENTS.md`, `codex_tasks/README.md`, `codex_tasks/task_history.md`, 기존 `reports/review_approval_http_integration_report.md`를 읽는다.
- 원격 `origin/main`, 현재 브랜치, 최근 커밋, `git status`, `git diff`, `git diff --cached`를 확인한다.
- 직전 실행에서 생성·수정한 `reports/review_approval_browser_ui_report.md`, `codex_tasks/task_history.md`, 이 파일의 로컬 변경을 찾아 확인한다. 이미 존재하는 내용을 덮어쓰거나 버리지 않는다.
- 기존 미커밋 변경, 미추적 파일, 프로젝트 JSON, 업무 결과, 백업을 보존한다. `reset`, `clean`, 대량 삭제를 하지 않는다.
- 원격 변경이 있으면 먼저 fetch 후 차이를 확인한다. 무리하게 덮어쓰거나 강제 push하지 않는다.

## 목표 및 작업 범위
1. 현재 Codespaces 환경의 OS, Python 버전, 설치된 브라우저 자동화 패키지 및 브라우저 실행 파일 유무를 확인한다.
2. Playwright 및 Chromium을 무료로 사용할 수 있는지, 설치 크기·시간·시스템 의존성·Codespaces 제한을 확인한다. 기존 환경을 크게 변경하거나 유료 서비스/유료 의존성을 추가하지 않는다.
3. 설치가 안전하고 현실적이면 프로젝트의 기존 의존성 관리 방식에 맞춰 최소한으로 설치한다. 설치 전 변경 범위를 확인하고, 프로젝트 설정 파일 변경이 필요하면 이유를 기록한다. 불필요하거나 실패 위험이 크면 설치를 강행하지 말고 대안을 기록한다.
4. 브라우저 테스트는 임시 디렉터리, 격리된 프로젝트/아티팩트 저장 경로, 모의 실행기를 사용한다. 실제 사용자 데이터 및 실제 AI API에 접근하지 않는다.
5. 브라우저 환경이 준비되면 검토 승인/수정 UI의 업무 ID와 상태, 처리 모달/진행 표시, 중복 제출 방지, 스크롤 복원, 서버 저장 상태와 화면 일치 여부를 검증한다. 자동화가 어려운 항목은 미검증으로 명확히 표시한다.
6. 기존 HTTP 통합 테스트 및 관련 회귀 테스트를 실행한다. 실제 사용자 데이터 경로를 사용하는 테스트는 격리가 입증되지 않으면 실행하지 않는다.
7. 실패·빈 결과 보존, 업무 결과 연결, 검토 승인 게이트, `openrouter/free` 제한 등 기존 동작을 유지한다. 무관한 리팩터링은 하지 않는다.

## 원격 저장소 반영 필수 조건
- 직전 실행에서 남긴 브라우저 UI 보고서와 작업 이력 변경을 반드시 검토하고 보존한다.
- `reports/review_approval_browser_ui_report.md`에 환경 점검, 설치 여부/이유, 실제 브라우저 테스트 명령과 결과, 대체 테스트, 미확인 항목, 데이터 격리 및 API 호출 여부를 기록한다.
- `codex_tasks/task_history.md`에 이번 작업과 직전 미커밋 작업 결과를 사실대로 정리하고 보고서 링크 및 커밋을 기록한다.
- `codex_tasks/next_step.md`의 상태와 다음 작업 안내를 최신 결과에 맞게 갱신한다.
- 보고서와 작업 이력은 작성 후 다시 읽어 확인한다.
- 관련 회귀 테스트, HTTP 통합 테스트 및 `git diff --check` 결과를 확인한다.
- **검증된 의도한 변경만 커밋하고 `origin/main`에 push한다.** 브라우저 자동화가 여전히 불가능하더라도 대체 테스트와 환경 점검이 통과하고 변경이 안전하면, 미완료 항목을 명시한 보고서·이력·필요한 테스트/설정 변경을 원격에 반영한다.
- 사용자 변경이 섞였거나 충돌·테스트 실패·데이터 손상 위험이 있으면 해당 변경을 포함하지 말고 push를 중단한다. 강제 push 금지.
- push 후 `git status`, 원격 최신 커밋 및 보고서 파일을 확인해 실제 원격 반영을 검증한다.
- 실제 AI API 호출은 하지 않는다.

## 완료 후 보고
