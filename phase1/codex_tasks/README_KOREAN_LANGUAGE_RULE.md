# AI Company OS — Codex 한국어 출력 고정 규칙

이 규칙은 모든 Codex 작업 지시서 작성 및 실행 시 공통으로 적용한다.

- 작업 진행 상황, 사용자에게 표시되는 설명, 오류 설명, 최종 답변은 한국어로 작성한다.
- GitHub codex_tasks 작업 지시서 및 reports 결과 보고서의 설명은 한국어로 작성한다.
- 일본어로 설명하거나 보고하지 않는다.
- 코드 문법, 파일명, 변수명, 함수명, API·모델 명칭, 명령어, 라이브러리 고유명사는 원래 표기를 유지한다.
- 기존 작업 중에는 언어 설정만을 이유로 작업을 중단하거나 처음부터 재실행하지 않는다.
- 모든 시간 표기와 로그의 시간대는 KST(UTC+9)를 사용한다.
- 다른 작업 지시서에 언어 규칙이 빠져 있더라도 본 규칙을 기본값으로 적용한다.
