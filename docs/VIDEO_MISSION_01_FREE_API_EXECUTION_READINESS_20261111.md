# 미션 01 — 무료 API 실행 조건 최종 확인 및 대표 승인 제안
작성일: 2026-11-11 KST
프로젝트: smartaiboom/ai-company-os

## 목적
이미 구현된 첫 번째 게임 쇼츠 미션의 AI 관리자·조사 직원·대본 직원·컷룸 연계를 재개발하지 않는다. 최근 사용자 확인 사항(YouTube Data API 키 등록 및 할당량 확인, Google Cloud 결제 미등록)을 현재 Codespaces 실행 환경과 기존 승인/사용량 원장에 대조하고, 첫 실제 실행에 필요한 **정확하고 최소한의 외부 호출 승인안 하나**를 작성한다.

이번 단계는 **실제 API 호출 전 준비·점검과 보고**만 수행한다. 실제 Gemini 텍스트 호출, 실제 YouTube API GET, 실조사, 대본 생성, 대표 승인 대기 상태로의 전환, 영상/음성/게시를 하지 않는다.

## 이번 작업 순서
1. 작업 전 `git status`, 현재 HEAD, 브랜치 및 `origin/main` 관계 확인. 안전하게 최신 변경을 읽되, 로컬 미커밋/미추적 파일 보존. 충돌 시 중단.
2. 실행 환경에서 `GEMINI_API_KEY`, `YOUTUBE_DATA_API_KEY` 등 필요한 설정은 **존재 여부만** 검사한다. 키 원문, 일부 글자, 해시, 헤더, 인증 토큰을 로그·보고서·터미널 출력·GitHub에 기록하지 않는다. 실제 외부 요청은 하지 않는다.
3. 현재 프로젝트 ID/업무 ID, 호출 예약/소모 이력, 동일 미션 중복 실행 여부, 기존 Gemini/Puck 음성 호출 원장과의 독립성을 읽기 전용으로 확인한다. 실행 시도나 서명 승인 기록을 생성하지 않는다.
4. 공식 공급자 계정 화면 또는 확인 가능한 로컬 증거 범위에서 **결제 미등록 여부, 무료 요금제 적용 여부, 모델 사용 가능 여부, 일일 잔여 요청·분당 제한, YouTube search·videos 할당량**을 항목별로 구분한다. 콘솔에 직접 접근할 수 없으면 '사용자 확인/독립 검증 불가'로 표시하고 검증됐다고 주장하지 않는다. 외부 네트워크 요청, CLI 인증, API 프로브를 이번 작업에서 수행하지 않는다.
5. 기존 CLI `video_mission_one connect-web`, `prepare`, `approve`, `run` 및 가드 조건을 **코드 읽기 기준**으로 점검하여 재승인/중복 호출 위험이 없는지 확인한다. 실제 `prepare`도 서명/예약 등 상태 변화를 일으킬 가능성이 있으면 실행하지 않는다. 코드를 새로 개발하지 않는다.
6. 원래 제안했던 범위인 **Gemini 텍스트 최대 10회(실패 포함)와 YouTube search 최대 4회 + videos 최대 4회(합계 8회)**가 현재 실제 코드/무료 조건과 호환되는지 점검한다. 숫자를 기계적으로 승인하지 않고 모델명·모델 가용성·요청당 쿼터·키 소속 프로젝트와 일치 여부, 예상 외부 전송 데이터, 데이터 사용·보관 조건을 확인한다.
7. 무료 요금제·실제 모델 접근성·할당량·데이터 정책 중 확인되지 않은 요소는 명시적으로 '확인 필요' 처리한다. **$0 보장** 또는 결제 미등록만으로 요금 위험 0이라고 단정하지 않는다. 유료 결제 연결·요금제 변경·자동 유료 대체·재시도는 금지한다.
8. **대표에게 승인 요청할 범위 한 건**을 작성한다: 모델/엔드포인트, 각 API별 호출 상한(실패 포함), 예상 데이터 전송과 저장, 무료 이용 및 데이터 처리 관련 유의사항, 검사에서 확인된 항목, 사용자가 추가 확인할 항목, 대표 승인 시에만 가능한 실행 명령, 중단 기준. 현재 확인이 부족하면 '승인 보류 및 추가 확인 항목'으로 작성한다.

## 금지사항
- 이번 단계 실제 외부 AI·YouTube API 호출 0회. 외부 검색, 검증용 호출, 호출 실패 유도, 자동 재시도 모두 금지.
- 기존 구현 재작성, 새로운 조사 엔진/오케스트레이터/UI 개발, 컷룸 디자인 변경 금지.
- 실제 AI 작업 결과·대표 승인 대기 상태를 mock이나 Codex 작성 샘플로 대체 금지.
- 임의 게임/쇼츠 길이 확정 금지. 대표 승인, TTS/WAV, MP4, 업로드/게시 금지.
- `data/`, `backups/`, `artifacts/`, `.env`, 비밀정보, 이전 승인/시도 원장 수정·삭제 금지. `git clean`, `git reset --hard`, 강제 push 금지.
- 사용자 승인 없는 유료 전환, 외부 전송, 스크립트 실행 금지. 시간은 KST 기록.

## 완료 기준
현재 무료 환경에서 실제 실행을 **승인 요청할 수 있는지, 아니면 어떤 사실 확인이 남았는지** 사용자가 판단할 수 있는 보고서 하나가 GitHub에 저장되어 있어야 한다. 실제 API와 새 미션 실행은 0회이며, 대표 승인 없이 다음 단계로 진행하지 않는다. Codex의 대화 완료 보고는 새 보고서 경로·GitHub commit·핵심 결론 3개만 알린다.
