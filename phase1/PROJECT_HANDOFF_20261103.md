**1단계(현재): 실제 AI 관리자가 여러 AI 직원과 한 사이클을 사용자 중간 업무 승인 없이 끝까지 완주해 실제 결과물(이번에는 재생 가능한 MP4)을 제출하는 시스템 완성·실증.**
**2단계(이후):** 대시보드/사용자 화면. 현황판은 필수 최종 요구사항이지만 한 사이클이 실제로 완성된 후에 개발한다. 1단계에서 업무 담당/상태/선행 결과/수정 이력/실행 로그/산출물/KST 시각을 저장하고 나중에 시각화한다.

## 3. 사용자가 최종 결정한 무료 AI 운영 정책
- `openrouter/free`는 인위적인 호출 수 제한/매 2회 사용자 재개 요구 없이 합리적인 횟수로 프로젝트 한 사이클 완주. 공급자 자체 무료 쿼터/속도 제한·가용성은 준수.
- 무료와 무한 반복은 다르다. 영속 시도 예약, 중복 송신/오류/불확실한 예약 무재송신, 수정 반복·시간/자원 상한, 임의 과금/유료 모델 fallback 차단.
- 실제 외부 데이터 전송 전에는 새 프로젝트별 **최초 운영 범위 동의 한 번**이 필요하다. 이 동의는 업무별 승인과 다르다. 추후 유료 전환 시 명시 예산·금액 상한/별도 승인 추가. 기존 프로젝트 동의/한도는 소급 변경하지 않음.
- 실제 공급자 응답의 `usage.cost`, 가격 0 요청 옵션, 엄격 JSON 지원/품질은 승인된 실송신 후 검증해야 한다.

## 4. 첫 실제 자율 운영 실험 목표 — 안내문에서 영상 제작으로 변경
**사용자 선택: 간단한 영상 제작.**
목표 문장:
“ChatGPT 초보자를 위한 ‘좋은 질문을 하는 방법’ 한국어 20~30초 설명 영상을 제작하라. 이해하기 쉬운 화면 구성과 자막을 포함하고, 가능하면 한국어 음성도 넣어라. 최종적으로 재생 가능한 MP4 영상 파일과 간단한 제작 결과 보고서를 제출하라. 검증되지 않은 기능을 사실처럼 단정하지 마라.”

**진짜 MP4가 있어야 성공.** 대본·스토리보드·제작 지시서만 만들고 성공이라고 하지 않는다. AI 관리자/직원 생성 내용 → 검증된 무료 로컬 영상 제작 도구(FFmpeg 등) → 실제 파일 렌더/재생 가능성 검사/품질 평가 → 최종 제출. 영상 제작 도구를 AI 작업 실행의 범용 기능으로 연결해야 한다. 화면/영상 내용은 Codex가 회사 대신 결정/고정하지 않는다.

- 설치 후 MP4 렌더링 도구/실제 파일 출력 오프라인 개발·검증 → 새 free-v2 실전 영상 프로젝트 1건 생성 → 외부 전송 운영 동의안 `prepare`까지 진행.
