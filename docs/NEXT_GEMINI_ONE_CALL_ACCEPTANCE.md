# Gemini 3.5 Flash Lite — 무료 계정 기반 실제 질문 1회 인수 테스트
작성: 2026-11-09 KST. 상태: Codex 실행 지시. **최대 실제 API 요청 1회**. 자동 재시도·유료 전환·기존 프로젝트 재실행 금지.

## 사용자 확인 사항
사용자가 Google AI Studio 스크린샷으로 Default Gemini Project가 무료 등급임을 확인했다. 해당 프로젝트의 Gemini 3.5 Flash Lite 한도 화면에는 RPM 15, TPM 250K, RPD 500이 표시된다. 스크린샷에는 최근 28일의 피크 사용량도 표시되지만 남은 실시간 쿼터가 보장되지는 않는다. 프로젝트의 해당 API 키가 현재 Codespaces GEMINI_API_KEY와 일치하는지 GitHub에서 검증할 수 없다. 실제 키 출력/로그/전송 금지.

## 목적
단 하나의 가상 목표로 실제 Gemini AI 관리자가 적응형 질문을 생성하는지 검증한다. 테스트 목표: 'AI 초보자를 대상으로 ChatGPT 활용법을 소개하는 1분짜리 영상을 제작하고 싶어.' 개인정보·회사 자료·기존 작업물·과거 프로젝트 이력은 입력에 포함하지 않는다. 실제 영상 생성·출판·영상 제작 프로젝트 실행은 하지 않는다.

## 현재 코드에서 확인된 차단점
- core/goal_dialogue_live.py의 LIVE_TRANSPORT_ENABLED=False 및 POLICY.account_quota_verified=False가 정적 차단이다. 현재 CLI는 --live create/prepare-consent/approve-consent/ask-ai 명령을 가진다.
- core/goal_dialogue_live.py는 동의 시 목표+payload+상태 해시 결합, 1시간 만료, 실행당 1회 동의, 호출 전 디스크 예약, 결과 불확실 시 재시도 차단을 구현했다.
- Gemini35Adapter의 모델/endpoint는 gemini-3.5-flash-lite로 고정되며 기존 실행/영상 제작 계약과 독립적이다.

## 수행
1. Codex는 원본 AGENTS.md, core/goal_dialogue_live.py, core/gemini_provider.py, companies/video/goal_dialogue_cli.py, 테스트를 읽고 기존 계약을 보존한다. GitHub main 동기화 시 git status를 확인하고 로컬 미추적 데이터/백업·/workspaces 로컬 보관본 절대 삭제 금지.
2. 공식 Gemini 정책에서 현재 모델 ID, 0원 무료 등급, 호출 요건을 확인한다. 스크린샷의 무료 프로젝트와 API 키 연결 여부는 Codespaces에서 API 키 내용을 출력하지 않고 점검한다. 계정 연결이 불명확하거나 결제 전환이 필요하면 **실제 전송 전에 중단**. AI Studio 한도 화면은 사용자 제공 근거이며 0원 사용을 절대 보장하는 증거가 아님.
3. 기존 차단을 단순 전역 True로 영구 해제하지 말 것. 실제 프로젝트 확인에 근거한 명시적 사용자 동의, scope hash, 단일 요청 예산·사용량 기록, 무료 설정 검증을 통과한 경우에만 좁은 인수 테스트 범위에서 활성화되는 안전 경로를 구현한다. 배포 기본값은 다시 비활성(실제 실행 완료 후에도 독립 승인 없는 요청 금지). 스크린샷만으로 인증/동의/키 결합을 통과한 것으로 가정하지 않는다.
4. 준비 단계는 네트워크 AI 호출 0회로: 가상 목표로 **새 격리된 live dialogue 초안** 생성(max_rounds=1 또는 전용 최대 1회 제한), 전송할 전체 내용과 모델/endpoint/예상 사용·비용 정책/기한/승인 해시를 명령 출력으로 사용자에게 표시한다. 기존 저장된 동의나 프로젝트를 재사용하지 않는다.
5. 기존 서명 승인 절차를 실제로 수행하되 사용자가 직접 확인한 초안과 전송 내용에만 한정한다. 사용자 확인이 없는 경우 '진행하자'를 임의 승인 서명으로 변조하지 않는다. Codex가 전송하기 전 확인이 필요한 정확한 전송 내용/호출 1회/무료 등급/Google 데이터 이용 방침은 출력하고 **실행 승인 대기**한다. 비밀 API 키/환경 변수는 표시하지 않는다.
6. 사용자가 그 전송 내용에 승인한 이후에만 'ask-ai'를 딱 1회 실행한다. timeout/실패/유효하지 않은 JSON도 모두 1회로 계산하고 자동 재전송·다른 모델 fallback 금지. 요청 직전 1회 상한과 디스크 원장 예약을 점검한다. 이전 'reserved/uncertain'이 있으면 별도 중단. 성공하면 질문 1~3개 혹은 질문이 필요 없다는 판단과 요약 명세를 확인한다.
7. 인수 테스트 이후 재호출 허용 환경 설정/임시 토글을 제거 또는 재차 차단한 상태로 둔다. 실패해도 안전/진단 결과만 기록하고 반복 디버깅 호출로 소모하지 않는다. 외부 코드 변경은 초기 준비에 필요한 최소 변경만. mock 회귀 통합 테스트는 실제 API와 분리해 마지막에 한 번만 수행한다.
