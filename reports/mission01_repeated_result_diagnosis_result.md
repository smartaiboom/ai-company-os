# 미션 01 재수정 중복 중단 진단 (2026-11-18 KST)

## 결론

이전 대본이나 대표 지시가 재수정 요청에서 빠지지 않았다. 관리자 검토는 첫 대본을 수락했지만, 한 검토 인용이 대본의 줄바꿈을 공백으로 바꿔 엄격한 인용 검사에 걸렸다. 시스템은 이를 수정 요청으로 바꿨으나 작가에게 대본의 어느 문장을 왜 바꿔야 하는지 특정하지 못했다. 후속 응답은 기존 대본과 중복으로 판정됐다. 전달량이나 형식 지시가 모델 반복을 일으켰다는 인과관계, 후속 응답의 정확한 원문은 확인할 수 없다.

마지막 요청은 15:22:26에 종료됐고 `repeated_employee_result`로 중단됐다. 첫 대본 1건과 리뷰 1건, 마지막 호출의 해시·진단은 남아 있다. 후속 대본과 응답 원문은 저장되지 않았다. 마지막 작업 표식은 원장에 남아 있으나 실행 중인 요청으로 해석하거나 제거하지 않았다.

35초 첫 대본 원문은 다음과 같다.

> 요즘 이 대세 게임들, 진짜 매력이 뭘까요?<br>
> 먼저 친구와 밤을 버티며 자원을 모으는 돈 스타브 투게더는 협동 생존의 재미를 선사합니다.<br>
> 와우 포에버의 주술사들은 버프 이후 디스코드를 잠그며 치열한 전략을 나누고,<br>
> 호그와트 레거시는 최신 DLSS 기술로 마법 세계의 몰입감을 더해줍니다.

세 게임이 내레이션에 등장하고 실시간 동접자 수는 삭제됐다. 저장된 대본의 형식 검사에서 결함이 검출되지 않았다. 다만 일반적인 ‘대세’ 표현, 디스코드 일화의 맥락과 전략 설명, 최신 기술과 몰입감 사이의 인과는 공개 영상 제목과 누적 조회수만으로 입증되지 않는다. 실제 흥미, 낭독 호흡, 제작 가능성은 별도 검토가 남았다.

## 관리자 판단과 시스템 처리

- 관리자의 원래 선택은 `accept`, 피드백 원문은 “모든 기준이 충족되었습니다.”였다. 관리자 근거는 위 내레이션 네 문장을 한 줄로 연결해 제시했다. 관리자는 복수 게임, 구체적인 특징, 미검증 동접 수치 삭제, 35초 분량, 자막 규격을 이유로 수락했다.
- `goal_review` 다섯 항목은 모두 `met=true`였다. `subject_story`에는 와우와 호그와트 문장을 공백으로 이어 붙인 인용을 넣었다. 실제 대본에서는 두 문장이 줄바꿈으로 나뉜다. 이 인용은 줄을 공백으로 이어 붙이면 일치하지만, 저장 원문의 연속 문자열이나 개별 장면 문자열에는 없다. 시스템은 이 한 항목만 `evidence_not_found`로 기록해 `accept`를 `revise`로 바꿨다.
- 실제로 작가에게 전달된 피드백은 “대표 피드백과 원래 게임 이야기 목표를 재확인하고 다음 항목을 수정하세요: subject_story: evidence_not_found. 근거 없는 성과 단정은 삭제하거나 미확인으로 표시하세요. 수정 후 실제 대본 문장을 근거로 다시 검토받으세요.”였다. 별도로 붙은 형식 결함은 없었다. 관리자 인용의 형식 문제였다는 설명과 구체적인 내용 수정 목표는 이 피드백에 없었다.

## 호출 재구성과 중복 판정

전송 직전 요청 생성 경로를 운영 상태의 메모리 복제본에서 실행했다. 네트워크와 저장을 차단했고, 실제 호출 경로에는 진입하지 않았다. 캡처한 **재구성 요청**의 컨텍스트 해시, JSON 요청 해시, 60,115바이트 입력 크기가 원장과 일치했다. 요청 원문 파일을 조회한 결과는 아니다.

| 재구성 영역 | 확인 결과 |
| --- | --- |
| `version_history` | 동일 작업에서 검증된 첫 대본 전문과 버전 정보 |
| `quality`, 작가 배정, 계약 | 원 목표, 대표 지시, 세 게임을 예로 든 복수 게임 소개 지시, 이전 관측 10건 및 한계, 새 웹 조사 불가, 주제와 35초 계약 |
| `revision_feedback` | 위 시스템 생성 지시. 관리자의 원래 수락 판단과 구체적인 대본 수정 기준은 이 차수의 별도 필드로 전달되지 않았다. 앞선 재작업에서 가져온 피드백은 재사용 컨텍스트에 있었다. |

중복 검사는 `core/autonomous_free.py`의 `FreeCompany._call`에서 수행된다. 모델 응답을 파싱하고 콘텐츠 필드의 기본 검사를 마친 뒤, 같은 작업의 기존 버전 각각과 새 응답의 **content**를 비교한다. 각 문자열에서 연속 공백 문자를 한 칸으로 바꾸고 양끝을 제거한다. 별도 `evidence`와 `uncertainty`는 비교 대상에 포함되지 않는다. 작성자의 구조화된 JSON content는 비교 전에 텍스트로 직렬화된다. 이 검사는 의미 유사도나 JSON 키 정렬을 사용하지 않는다. 같은 내용 및 바깥 공백·별도 근거 문구만 바꾼 합성 응답이 모두 차단되는 것을 오프라인으로 확인했다.

## 개선 판단과 다음 결정

소스는 변경하지 않았다. 입력 누락을 확인하지 못했고, 작가 지시만 바꿔 실제 품질이 나아지거나 중복이 줄어든다는 근거는 확보하지 못했다. 확인된 문제는 **관리자 인용 불일치가 수정 목표 없이 작가 재수정으로 바뀐 것**이다. 검증이나 중복 조건을 완화하거나 형식만 바꿔 통과시키지 않았다.

현 상태에서는 품질 결정 기반 신규 작업, 계획 실패 기반 재시도, 검토 실패 기반 대본 복구의 자격을 충족하지 않는다. 기존 실행 재개도 금지된다. 다음으로 필요한 대표 결정은 **첫 대본을 보존한 채 별도 승인된 관리자 재검토만 설계할지**다. 진행을 선택하면 관리자에게 한 장면에서 정확히 인용하고 사실·내용 결함이 있으면 문장과 보완 목표를 명시하게 한다. 인용 결함만으로 작가에게 같은 대본을 다시 제출시키지 않는다. 이 후속 경로는 아직 구현·승인되지 않았다.
