# 미션 01 관리자 재검토 복구 (2026-11-18 KST)

## 보존한 작업과 복구 조건

15:22에 중단된 작업은 관리자 계획 → 대본 작성 → 관리자 검토 → 대본 재수정 순으로 Gemini 4회를 사용했다. 네 응답이 모두 HTTP 200이었고, 마지막 응답은 JSON 파싱 후 `repeated_employee_result`로 중단됐다. 35초 첫 대본의 관리자 수락은 줄바꿈이 바뀐 인용 한 건 때문에 시스템 수정 요청으로 전환됐다. 두 번째 대본 원문은 저장되지 않았다.

복구는 중단 표식, 네 요청의 단계·동일 세션·송수신 완료와 해시, 마지막 중복 판정 및 관리자 원래 선택을 모두 대조한다. 확인 가능한 첫 계획·대본·리뷰의 결과 해시와 리뷰 대상 해시를 재계산하고, 기존 동의 서명과 현재 로컬 키 결합을 확인한 뒤에만 별도 작업 제안을 준비할 수 있다. 미확정 전송과 무관한 실패는 대상에서 제외한다.

## 요청 구조와 한도

- 새 작업에는 검증된 기획, 첫 대본, 기존 대표 지시와 조사 자료를 복원한다. 기존 관리자 수락을 새 승인으로 복사하지 않는다. 첫 요청은 보존된 대본을 대상으로 한 **관리자 재검토**다. 재기획이나 최초 대본 작성 호출 없이 시작한다.
- 관리자는 한 장면의 한 줄에서 정확히 인용하고 인용 형식, 내용, 사실 근거를 구별한다. 인용 불일치만 있거나 실제 결함에 연결된 원문과 수정 설명이 없으면 작가를 다시 호출하기 전에 중단한다. 내용·사실 수정은 관리자가 미충족으로 표시한 항목의 정확한 인용과 별도 수정 설명을 제시한 경우에만 허용한다. 인용 일치만으로 내용의 진실성이나 재미를 보증할 수 없다.
- 즉시 수락하면 관리자 재검토 → 편집안 작성 → 편집 검토로 **Gemini 3회**다. 승인된 수정 1회를 사용해 완료하면 **최대 5회**다. 검토에서 중단하면 1회로 끝날 수 있다. 기존 외부 전송 동의의 기술적 상한은 **7회**, 전체 수정 상한은 **1회**로 유지했다. 제공자 무료 잔여량과 실제 품질은 미확인이다. 새 웹 조사, 자동 재시도, 유료 전환, 제작·게시를 포함하지 않는다.
- 기존 Gemini 누적 **17회**, YouTube **4회** 기록은 보존했다. 이번 작업의 실제 Gemini·YouTube 요청, 대표 결정, 재작업 동의 생성 및 실행은 각각 **0회**였다.

## 대표 다음 조작

기존 컷룸 프로젝트를 새로고침한 뒤 **중복 응답 중단 · 기존 대본 재검토 → 기존 대본 관리자 재검토 준비**를 누른다. 범위와 무료 조건을 확인해 제안을 준비한다. 이어 **새 외부 전송 동의 → 이 범위에 동의 → AI 재작업 시작** 순서로 진행한다. 제안 준비나 동의 저장만으로 실행되지 않는다. 실행 완료 시 새 기획·대본은 기존 **기획 승인 대기** 흐름에 들어간다.

## 검증

- 핵심 통합 및 컷룸 테스트 **99개 통과, 실패·오류 0개**였다. JavaScript 문법 검사와 `git diff --check`도 통과했다.
- 운영 35초 대본의 메모리 복제본으로 첫 요청을 전송 직전까지 구성했다. 관리자 `review`, 원문 일치, 기존 대표·조사 입력, 단일 장면 인용 지시를 확인했다. 네트워크와 저장을 막았다.
- 모의 HTTP 통합에서 새 동의 전 실행 및 중복 시작 차단, 이전 작업과 동의 보존, 수락 시 3회 경로, 실제 내용 수정 지시가 있는 경우 5회 경로, 편집 후 대표 승인 대기 전환을 확인했다. 줄을 합친 인용이나 구체적인 수정 근거가 없는 리뷰는 작가 재수정 전에 중단하는 것을 단위 테스트로 확인했다.
- 진행 중 요청이 없는지 점검하고 운영 컷룸을 기존 실행 환경과 작업 루트로 재시작했다. `localhost:8000`의 프로젝트 상세와 JavaScript가 HTTP 200으로 반환됐고, 실제 중단 작업에서 재검토 준비가 가능한 상태를 확인했다. 재시작 전후 운영 프로젝트·원장·동의 JSON의 바이트는 동일했다. 브라우저 클릭과 실제 모델 응답 품질은 검증하지 않았다.
