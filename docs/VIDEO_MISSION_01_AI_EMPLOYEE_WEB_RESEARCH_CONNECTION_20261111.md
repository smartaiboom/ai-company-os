3. 조사 소스는 실제 이용 가능한 **허가된 공개 웹 검색 API/공식 공개 데이터/검증 가능한 결과**여야 한다. 스크래핑 금지/약관/robots 및 유료·자격증명/쿼터를 확인한다. 무료로 가능한 범위를 우선 조사하고, YouTube Data API 등 API 키/쿼터가 필요한 경로는 연결 가능성·요청 단위·무료 한도·허가 범위를 먼저 명확히 한다. 특정 도구가 없어 막히면 현실적으로 가능한 대안을 비교해 보고하고 실행할 수 없는 기능을 가짜 자료로 메우지 않는다. 외부 서비스가 없는 **오프라인 테스트에서는 fixture를 써도 실제 직원 조사로 표시하지 않는다**.
