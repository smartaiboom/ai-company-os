# V1 독립 오프라인 회귀 테스트

저장소 최상위에서 실행:

```bash
PYTHONPATH=src python -B -m unittest discover -s tests -p 'test_*.py' -v
```

외부 AI 호출 없이 가상 관리자/직원 모형으로 목표 → 계획 → 직원 실행 → 검토/수정 → 파일 결과, 오류 및 API 재시도 금지를 확인합니다. 테스트는 임시 폴더에만 쓰고 DNS 및 네트워크 연결을 막습니다. 이전 복합 150개 검증은 과거 `phase1/tests/`에 보관되어 있으며 **새 테스트 4개가 150개를 대체했다는 뜻은 아닙니다.** 실제 서버/사용자 데이터/실서비스 품질 검증은 별도 필요합니다.
