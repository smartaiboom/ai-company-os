## 대표가 승인한 제품 목표
AI Company OS의 AI 관리자/직원이 최근 인기 모바일 게임을 조사하고, **서로 다른 실제 모바일 게임 최소 3종**에 대해 YouTube 영상 표본, 게시일, 조회수, 길이, 영상 링크, 훅의 관측/추정 구분, 게임 화면 확보/권리 상태를 비교하여 대표가 쇼츠 제작 주제를 고르게 한다. 현재 v4에서는 마인크래프트 영상 5건(조회수 약 124~248만, 길이 26~121초)만 확인돼 미달. 보고서 자동 검토 파일은 reports/review_exports/mobile_game_latest.md 에 존재하고 ChatGPT가 GitHub에서 직접 읽는다. **영상 수가 3 이상인 것을 서로 다른 게임 3종 확보로 계산하면 안 된다.**

## 현재 확인된 구조적 문제

- discovery_queries()는 예전 manager 후보 게임명과 일반 '모바일 게임 인기' 등 질의 9개 생성. 검색 결과가 Minecraft 한 게임에 쏠려도 '새 게임 종류 부족'을 조건으로 추가 탐색하게 강제하지 않음.
- research_workflow.py step_worker collection_required는 fresh video URLs >=3이면 false가 되어 하나의 게임에서 영상 3건을 얻은 시점에 조기 finish가 허용된다.
- 최신 v4는 실데이터: 공개 YouTube 5건, 게임명 1종, 관리자 hold. v1~v4 저장 데이터와 승인/호출 원장은 보존.

2. **도구 탐색 정책**: 기존 5개 마인크래프트 영상은 재사용. AI 직원이 서로 다른 모바일 게임의 근거가 부족하다는 사실을 알고, 실제 게임명 후보/짧은 다양화 검색어를 능동적으로 선택할 수 있도록. 고정 일반 키워드 목록에만 갇히지 말고 **검증된 후보/관측 자료에서 발견한 별도 게임명**으로 후속 검색. 같은 게임/유사 검색어만 반복 소비하지 말고 중복 검색 방지. 검색 결과 0건이면 의미가 다른 정상 질의 계속. 기존 승인 범위/총예산/쿼터 단위 안에서 충분히 정상 조사한다. API 호출 수 최소화가 목적 아님.
