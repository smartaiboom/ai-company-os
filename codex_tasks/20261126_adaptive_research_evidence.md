1. 실제 보존 observation-0/1, 검색 질의, 도구 선택, evidence catalog, STEP_RULES, 종료 조건, 개발 승인/원장 및 기존 후속 수집 경로를 먼저 점검. 검색 단서 4건은 검증된 원문이 아니며 YouTube 검색 결과 0건도 증거로 보존. 관측의 원본/해시/시각/출처/검색 범위를 유지. 이전 실패 원장을 수정하거나 실패 본문 재전송하지 않음.
2. 근거 부족은 업무 상태로 취급하고 허용된 도구와 질의 범위 안에서 AI가 대안 검색어, 검색 범위 조정, 원문 검증, 독립 출처, 영상 ID와 videos 메타데이터 조회 등 보완 조사 계획을 선택하게 한다. 기존 도구의 실제 지원 여부와 허용 질의를 확인하고 범위 밖 목적지/도구/데이터는 새 승인 전 호출 금지. 검색 결과 0건을 인기도 없음으로 추론하지 않음. 중복/무진전/무한 반복 방지. 근거 부족 상태에서 supported/conflicting 평가를 허용하지 않고, 검색 단서와 원문/API 관측을 분리. 잘못된 인용/권한/사실 검증 차단 유지.
3. 기존 개발 검증 승인 구조와 수집 후속 경로를 재사용하여 최소 변경. 현재 insufficient_independent_evidence 중단은 기존 보정 범위 밖이므로 차단된 서명/원장을 임의 해제하거나 소급 확대하지 말 것. 보존된 자료와 증거를 바탕으로 안전한 신규 범위를 준비하고 필요 시 새 명시 서명과 정상 실행 권한 심사 후 새 예약으로만 외부 실행. 동일 실패 요청 재전송 금지. 무료 전용 비용0, 기존 공급자/모델/프로젝트/목적지/데이터/목적/유효기간 및 실제 쿼터 준수. 승인 필요 시 정확한 최소 승인 절차를 보고하고 대기. 새 승인 전 외부 호출 금지.
