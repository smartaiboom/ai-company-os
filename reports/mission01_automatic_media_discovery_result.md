# 미션 01 영상 소스 자동 탐색 · 2026-11-19 KST

## 실행 가능한 경로

컷룸에서 **영상 자동 탐색 범위 검토·승인 → 영상 자동 탐색 실행**을 선택하면 Wikimedia Commons에서 자료를 찾고 내부 후보 목록을 만든다. 이미 인수한 장면은 제외하고, 기존 AI 직원의 장면 요구에서 참조 ID와 URL을 제거해 검색어를 만든다. 동일 검색어는 한 번 요청한다. 미션의 현재 상한은 **검색·메타데이터 결합 GET 4회**, 검색당 최대 5건, 비용 $0이다. 이 단계에서 영상 파일 요청은 0회다. 발화·WAV·키는 Commons에 보내지 않는다. 대표는 정확한 검색어를 승인 화면에서 확인할 수 있다. [MediaWiki 파일 검색](https://www.mediawiki.org/wiki/API:Search), [imageinfo 공식 문서](https://www.mediawiki.org/wiki/API:Imageinfo/en), [Commons 라이선스 메타데이터](https://commons.wikimedia.org/wiki/Commons:Machine-readable_data)

기존 개인 운영 위임을 재사용해 프로젝트·승인 기획·제작 계획·검색어와 호출 상한을 24시간 범위에 서명한다. 검색은 호스트를 고정하고 공개 IP의 TLS 인증서를 검사하며 리다이렉트, 사설 IP, 응답 크기·시간 초과를 차단한다. 결과는 HTML을 실행하지 않는 텍스트로 표시하고, 원본 링크는 Commons의 허용 경로만 받아들인다. 실패·미확정은 차감하고 후속 호출을 중단한다. 외부 검색의 자동 재시도와 유료 전환은 없다. [MediaWiki API 요청 지침](https://www.mediawiki.org/wiki/API:Etiquette)

## 권리·다운로드·편집

- 후보에서 명시된 CC BY, CC BY-SA, CC0의 지원되는 표시와 URL 일치, 저작자·출처·표시 의무·원본 체크섬을 확인한다. 누락된 근거, 모순, 제한 조건, 불허 URL이 있는 항목은 인수 후보에서 제외한다. API의 값은 권리 단서다. 대표가 원본 페이지에서 게임 IP·음원·제3자 영상 권리 및 해당 장면 적합성을 확인해 후보를 한 묶음으로 검토한다. 표시·동일조건 의무와 원본 페이지는 최종 검토 자료에 남고 게시 권한은 부여하지 않는다.
- 권리를 확인한 후보는 수동 JSON 등록 없이 기존 자산 목록으로 전달된다. 장면별로 서로 다른 적합 후보가 충분하면 **자산·편집 범위 검토·승인 → 제작 실행**으로 이어진다. 별도 범위는 Gemini 편집 판단 **최대 1회**, 승인된 원본 **최대 4회**다. HTTPS 원본 MP4·WebM을 내려받고 확인한 Commons 체크섬과 로컬 SHA-256을 대조한 뒤 형식·길이·전체 디코딩을 검증한다. WebM은 기존 FFmpeg 렌더에서 720×1280 MP4로 출력한다.
- 후보가 부족하면 검색 승인 범위에 포함된 경우 무료 Gemini **최대 1회**로 적법한 직접 캡처, 설명 영상, 라이선스 확인 정지 이미지의 모션 연출, 생성 도구 권리 검증 또는 보류를 제안한다. 제안을 자동으로 제작하거나 승인 없이 다른 영상을 넣지 않는다. 실제 게임별 결과 가용성은 미검증이다.
- 기존 공식 제작사 직접 제공 자료의 등록·인수 경로도 유지한다. 게임사의 자체 녹화·공개 정책과 제3자 영상의 다운로드·편집 허가는 별도 확인이 필요하다. Klei 안내는 자체 게시 정책 검토에 참고한다. Blizzard 문서는 조회 시 403이어서 근거로 사용하지 않았다. 공식 게임사 파일의 자동 발견과 생성 도구 실행은 이번 범위에 포함되지 않았다. [Klei 촬영·공개 안내](https://support.klei.com/hc/en-us/articles/360029557192-Can-I-stream-or-make-videos-of-Don-t-Starve-Together)

편집 판단에는 승인 장면별 프레임, 실측 음성과 발화 없는 여유, 승인 자막 노출 길이, 장면 의미와 반복 방지 기준을 전달한다. 음성을 가속하거나 자르지 않고 승인 원문·타임라인을 보존한다. 실제 시청 품질은 대표 검토가 필요하다.

## 운영과 검증

- 운영은 영상 수정 요청 단계다. 승인 대본 v2, 기술 시안 v1, 840프레임 승인 조정안, 네 실제 WAV(3.68 / 7.36 / 5.16 / 6.40초), 대표 의견, 기존 제작 관리자·자산 직원 원장과 개인 정책 5회 완료 상태를 보존했다. 기존 환경·루트로 재시작한 뒤 localhost 상세·정적 파일·WAV 해시와 **영상 자동 탐색 범위 검토·승인** 표시를 검증했다. 운영에 새 정책 승인·검색 결과·영상 파일을 생성하지 않았다. 브라우저 실조작은 미검증이다.
- 복제본에서 모의 Commons 자료와 기존 실제 WAV 바이트 복사본을 사용했다. 후보 저장·중복 제거, 권리 미확인·표시 누락·위험 URL·잘못된 승인 해시·검색 실패 및 재요청 차단을 확인했다. 빈 결과는 별도 모의 대안 제안으로 처리했다. 권리 검토 후 WebM 모의 다운로드와 실제 FFmpeg 합성, 35초 영상 검토 제출 및 표시 정보 인계를 검증했다.
- Python 회귀 25건 중 24건 통과·1건 건너뜀. JavaScript 상태·구문 및 Git diff 검사 통과. 실제 미션 Gemini·TTS·Commons 검색·다운로드·YouTube·영상 생성 요청은 각각 **0회**다. 공식 개발 문서만 참고했다.
