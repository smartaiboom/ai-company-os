# AI Company OS — 영상 제작 전문 AI 회사 v0.1: 제작 도구 품질 향상과 실제 샘플 검증

기준: 2026-11-04 KST. 사용자 신규 결정: **당분간 범용 회사 대신 영상 제작 전문 AI 회사를 실제 제품 주제로 삼는다.** 기존 범용 엔진, 역사, 동의·원장은 보존하고 video-production profile/도구를 추가한다. 우선 과제는 **단색 배경+글자+espeak-ng를 벗어나 실제 볼 만한 20~30초 영상 샘플**이다. 사용자의 최종 주제 목표는 '한국어로 ChatGPT 질문을 잘하는 방법' 같은 비밀 없는 실험 주제로 충분. 이 예시만 하드코딩하지 말 것.

## 규정/우선순위
1. `AI_COMPANY_OS_CORE_PRINCIPLES.md`, `AGENTS.md`, 기존 Gemini 3.5 첫 완주 보고서와 `local_artifacts.py`, `autonomous_gemini35.py`, 기존 tool schema/validation/receipts/revision pipeline부터 확인.
2. 현재 첫 실사용 delivered 프로젝트 `data/gemini35-espeak-path-fix-20261104`의 모든 파일·원장·영상·동의·backup **절대 변경 금지**. 신규 기능은 versioned tool, 전용 새 프로젝트/profile 또는 독립 샘플로 격리. 기존 caption_video_v1 계약을 변경해 과거 프로젝트 해시를 깨지 말 것.
3. 사용자 역할: **영상 목표 한 번 입력**, AI 제작 총괄이 콘셉트·기준·업무 계획·배정·검토·수정·최종 승인. 제작 역할 예: 대본/구성, 자료/소스, TTS/편집, QA. 실제 AI 관리자가 필요에 맞게 업무를 배정하며, 고정 스크립트/Codex가 프로젝트별 심미/업무 의사결정을 대행하지 않음.
4. 사용자 무료 우선; 유료 API·카드/결제·새 외부 제공자 자동 이용 금지. 소스 저작권/원문 출처/허용 범위/라이선스 기록 필수. 외부 개인·기업자료, API key, TTS 텍스트 제3자 송신은 공급자와 데이터 범위를 명확히 하여 **신규 별도 운영동의 전 실제 요청 금지**. 최초 Gemini 3.5 영상 프로젝트 동의를 다른 공급자 승인으로 확장 금지.

## 빠른 실무 개발 순서 — 납품 가능 결과물을 먼저
### A. 기술 선택 조사 및 실행 환경 확인
- 실제 Codespaces CPU/RAM/디스크, 설치 패키지, 한국어 폰트, Python 패키지, ffmpeg 확인.
- **한국어 신경망 TTS**를 우선 2~3개 실용 후보로 비교: 무료·라이선스·CPU 실행 가능성·품질·안정성·서비스 약관·외부 텍스트 전송 여부. 예: 공개 로컬 엔진·가중치가 한국어를 지원하는지 실제 증명; edge-tts는 비공식 Microsoft Edge 온라인 음성 호출이며 안정성/상업적 이용/정책 불확실, 무조건 무료 공식 API로 취급 금지. 외부 TTS 호출은 공급자/전송 범위의 별도 허가 전 중단. Gemini TTS 등 유료/키 요구 서비스 자동 활성화 금지. 자연스러운 한국어 음성이 확보되지 않으면 이를 숨기거나 espeak를 '향상 완료'로 표시하지 말 것.
- 시각 소스: **명확한 라이선스의 로컬/공개 자료 또는 프로그램이 자체 생성한 일러스트·화면 그래픽**과 효과를 먼저. Pexels 신규 API 키 발급은 2026-11-04 기준 중단 공지, 키 없는 자동 연동 가정 금지. 이미 키가 존재하는지는 bool만 확인하고 공개하지 말 것. Wikimedia Commons 등은 권리/출처/작품별 라이선스/다운로드 권한 검증 없으면 직접 붙이지 말 것. 무작위 웹 이미지 무단 저장·삽입 금지.

### B. 명확히 개선된 **versioned 영상 제작 도구 v2** (기존 v1 유지)
- 장면마다 시각자료(소스 image/video, 자체 생성 그래픽/도형/그라데이션, 줌/팬/전환), 음성 내레이션, 자막의 시간 동기화, 16:9 또는 세로형 등 기술 스키마 설계. 가능 범위에서 기존 FFmpeg만 재사용하고 안전한 경로 allowlist, URL 차단, ffmpeg 필터·셸 인젝션 방어, 소스 라이선스, 파일 해시·receipt·전체 디코딩 검증.
- 사용자 목표에 따라 AI 총괄/직원이 콘셉트·색·장면·매체·품질 기준 선택; 개발자가 일괄 단색 화면/정해진 자막·효과/컷 길이를 강제하지 말 것. 안전한 기계적 규격만 하드 제한.
- 실제 영상/음성 파일 기반 **검토 입력**을 제공: 장면 keyframe/시각 설명 및 근거, 합성 음성 메타데이터/실측 길이, 자막 싱크/라이선스/툴 성공 정보. 모델이 시각·청각 입력을 실제 보지 못한다면 '실제 영상 감상·음성 품질 검사 완료'라고 허위 주장하지 말 것. 동영상 메타데이터 성공과 감상 품질 성공을 구분.
- 설계는 최소 적정 범위. 범용 편집기, dashboard, 새로운 프레임워크, 다수 provider 동시 추가 금지.

### C. 실제 품질 샘플 확인
- **1개의 개선된 샘플 MP4를 실제 렌더**해서 artifacts(또는 별도 신규 테스트용 폴더)에 남길 것. 기존 실사용 영상 위에 덮어쓰기 금지. ffprobe·full decode/음성 stream 검증 및 keyframe(예시 이미지) 산출. 실제 장면이 단색 텍스트만 아닌지 직접 기술적으로 확인.
- 두 단계 분리: (1) 외부 전송 없이 가능한 로컬 영상 MP4 샘플 먼저 생성 (2) 새 무료 TTS/API·외부 이미지 검색/새 Gemini 실사용 프로젝트는 **별도 명시된 사용자 전송 동의 확보 후**만 실행. 허가받지 못한 네트워크 요청 대신 오프라인 구성요소만으로 할 수 있는 결과물을 최대한 만든다. 자연스러운 한국어 음성이 이번 단계에 기술적으로 불가능하다면 부분 성공을 분명히 알리고, 공식 검증 가능한 서비스/정확한 동의 범위와 다음 한 행동을 기록.
- Codex가 작성한 고정 fixture는 **도구 품질 데모**로만 표시. 실제 AI 관리자/직원이 자동으로 제작한 영상이라고 절대 주장하지 말 것. 실제 AI 회사 전체 E2E는 이후 신규 프로젝트 모델/전송 동의하에 검증.
- 실행 소요/테스트 범위는 합리적으로 한정하며 큰 모델 다운로드·비용 위험 발생 시 중단하고 결과에 명시. 외부 네트워크 없이 제작 가능한 자체 그래픽/B-roll 대체 기술 확인 우선.
