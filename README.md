# AI Company OS

현재 개발: **AI Company OS v1.0**

사용자의 목표를 구체화하고 분야별 전문 AI가 협업하여 결과물을 제작·검토·수정하며, 사용자 피드백과 검증된 경험을 축적해 다음 프로젝트의 품질을 높이는 것을 목표로 한다.

## 폴더 구조

- `src/`: v1.0 제품 코드. Phase 1에서 가져온 협업 엔진 등 Python 모듈 16개.
- `tests/`: v1.0 독립 핵심 모의 회귀 테스트 4개 (기존 폴더 없이 실행 성공).
- `docs/`: 현재 개발·이전·정리 지침.
- `reports/`: 현재 개발 검증 결과. 지난 결과물은 `phase1/reports/`에도 보존.
- `phase1/`: **이전 Phase 1 Git 추적 소스 277개 파일의 원본 그대로인 보관본**. 기존 회귀 테스트와 보고서·지시서도 포함.
- `AGENTS.md`: 현재 v1.0 개발 원칙.

2026-11-09: `ai-company-os-phase1/`의 **Git 추적 파일만 중복 정리**했다. 같은 277개 파일이 `phase1/`에 동일한 Git blob SHA로 보관되었음을 확인했으며, 새 v1 `src/`의 16개 모듈/독립 4개 테스트는 Codex의 오프라인 검증을 통과했다. 이 정리 자체에 추가 실행 테스트는 하지 않았다.

## Codespaces에서 주의할 점

GitHub는 `.gitignore`로 제외된 로컬 `data/`, `backups/`, `artifacts/`, `.env` 파일을 읽거나 정리하지 않았다. 예전 작업 폴더 `ai-company-os-phase1/` 내에도 이러한 비추적 파일이 남아 있을 수 있다. Git의 이번 변경을 `git pull`로 적용하면 **예전 폴더의 추적 코드 파일이 작업 트리에서 제거**되므로, 예전 폴더를 기준으로 실행하던 명령은 중단된다. 실행은 새 `src/` 기준으로 전환한다. `git clean`, `git reset --hard`, 수동 `rm -rf`는 하지 말고, 비추적 프로젝트 데이터는 명시적으로 보존한다.

## 향후 개발

목표 구체화 문답 → 실제 AI 직원 협업 → 산출물 품질 평가·수정·사용자 피드백 → 경험 데이터 저장·다음 프로젝트 재사용으로 발전시킨다. 핵심 기능 묶음별로 개발 후 통합 검증하며, 사소한 Git 문서/폴더 작업을 이유로 Codex 사용이나 전체 테스트를 반복하지 않는다. 실제 외부 AI 호출은 기존 비용·권한·원장 안전 규칙을 지킨다. 장기 목표는 자율 운영이며 향후 `AI Company OS vs ChatGPT` 동일 조건 비교로 실제 성장을 확인한다.
