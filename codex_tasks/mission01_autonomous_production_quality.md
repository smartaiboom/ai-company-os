# 미션 01 기존 영상·음성 품질 자산 재사용 및 AI 자율 제작 연결 (2026-11-19 KST)
AGENTS.md 준수. 큰 방향 변경 금지. 대표는 승인된 35초 v2로 실제 영상 제작을 원하며, 무음 카드 시안의 품질이 이상하다고 평가했다. 이 시안은 기술 검증용이며 승인하지 않는다. 이전보다 나은 실제 영상·음성 품질이 목표다. 특정 보이스, 장면 연출, 게임 제목, 제작 전략을 개발자가 고정하지 않는다. AI 판단과 기계적 검증/실행을 구분한다.
## 재사용 기준
먼저 실제 코드와 다음 보고서를 확인: VIDEO_QUALITY_ITERATION_RESULT.md, USER_FEEDBACK_QUALITY_UPGRADE_RESULT.md, three_ai_clips_shorts_result.md, real_ai_clip_import_result.md, VIDEO_VOICE_SELECTION_AND_NEXT_SAMPLE_RESULT.md, VIDEO_VOICE_USER_AB_FEEDBACK_RESULT.md, GEMINI_TTS_148_CHAR_REAL_ONE_SHOT_RESULT.md, NO_CARD_TTS_EXECUTION_GATE_RESULT.md, mission01_production_cutroom_integration_result.md. ai_clip_pipeline, editorial_video 및 audience_visual_review가 현재 트리에 있는지 또는 Git 이력에만 있는지 확인(필요한 기존 코드만 재사용, 과거 전체 복원 금지), voice_quality, tts_job/tts_execution, quality_tool_adapters, core/quality_feedback, 기존 컷룸 세로 렌더/대표 검토를 활용한다. 과거 Codespaces 로컬 MP4/WAV/모델/경험 저널이 현재 WSL에 존재한다고 가정하지 말 것. 과거 보고서에서 확인 가능한 평가를 출처/대상/범위와 함께 안전하게 재사용하고 실제 파일이 없으면 명시한다. 기존 7/10 Puck 평가는 한국어 AI 안내 표본이며 게임 음성에 자동 적용되는 점수나 고정 보이스가 아니다. 과거 Codex의 제작 판단은 실제 회사 AI의 판단으로 위장하지 않는다.
## 구현 범위
1. 실제 프로젝트의 승인 v2 및 무음 영상 v1/대표 검토 상태 읽기 전용 확인. 기존 기획 승인 유지, 기술 시안 보존, 대표가 컷룸에서 명시적으로 영상 수정/실제 제작 준비로 진행할 수 있도록 기존 흐름을 사용한다. 승인된 대본을 다시 작성하지 않는다. 무음 시안을 최종 품질 통과로 처리하지 않는다.
2. 실제 AI 관리자 제작 계획 호출을 기존 서명/전송/원장/모델 경계로 연결한다. 입력은 승인된 대본/장면/목표/대상, 실제 가용 도구 목록과 지원 범위/무료 조건, 관련 과거 평가와 검증된 경험(직장인 대상과 게임 콘텐츠 적용 범위 구별), 대표의 이번 시안 평가(기술 시안 이상함, 이전 품질 이상 목표; 미제공 세부 점수 추정 금지), 소스 확보/권리 현황. 관리자가 영상별 음성 도구/후보와 스타일, 장면별 구체적인 영상 소스 요구 및 연출·전환, 음성/자막/실측 타이밍 전략, 검토 기준 및 담당/작업 순서를 결정하게 한다. AI가 선택할 수 있는 범위는 실제 실행 가능 여부와 구분. 동적 지시, 구조화 응답, 원문/승인 해시의 기계적 부착, 허용 도구 검증은 시스템 책임. 관리자 계획 1회 후보를 기본으로 하되 필요한 실제 직원 호출과 별도 승인 상한을 정확히 설명. 불필요한 복사 호출 금지.
3. 실제 승인 내레이션과 AI가 결정한 발화 지시를 일반 서명 TTS 실행기에 결합하여 컷룸에서 신규 음성 요청 준비/동의/실행 및 결과 인계를 연결한다. 기존 고정 표본 예외 게이트를 우회/느슨하게 하지 말고 기존 일반 TTSExecution 재사용. 각 요청 exact payload/모델/보이스/키 결합/원문/한도/요금 미확인/무료만/실패 차감/출력 검증/별도 승인. 장면별 또는 전체 합성 중 무엇이 효율적인지 실제 도구/자막 인계 제약을 기준으로 관리자 판단을 받되 승인된 범위만 실행. 과거 음성 파일이나 합성 시험 신호를 새로운 한국어 음성으로 위장하지 않는다. API 모델/음성 후보의 현재 사용 가능/비용은 확인되지 않았다면 명시. 실제 호출은 이번 0회.
4. 기존 영상 클립 수입/소스 검증/자막 타임라인/렌더 도구와 연결한다. 게임 영상 소스는 실제 적합성/사용권 및 파일 검증 필요; 유튜브 검색 메타데이터가 다운로드 허가나 영상 소스가 아님. 적법한 사용자 제공 자료 또는 사용할 수 있는 검증된 생성 도구 후보를 관리자가 선택하고 필요한 소스 요청을 구체적으로 생성하도록 한다. 현재 자동 영상 생성/취득이 불가능하면 명확한 자산 확보 대기 단계 및 로컬 수입 경로 제공; 무음 카드로 자동 대체하지 않음. 기존 Flow 자료가 다른 콘텐츠라면 재사용 금지. 실측 음성 구간과 자막/영상 타임라인을 정합하고 승인 대본 변경 필요 시 별도 대표 승인. 실제 움직임/다양성/읽기 속도/반복 및 기술 QA를 적용하되 과거 다른 장르에 설정한 수치 기준을 전역 고정하지 않음. 관리자에게 결과의 확인 가능한 근거와 한계를 주고 청취/시청하지 않은 모델에 감각 품질 합격을 주장하지 않음.
5. 목표는 실사용 가능한 호출 준비/제작 연결을 한 묶음으로 구현하는 것. 실제 승인 v2 복제본에서 관리자 계획(모의), TTS 승인/합성응답(모의), 소스 인수(명시적 fixture), 실제 로컬 영상 합성/검증, 대표 영상 검토까지 전체 경로 확인. 운영 원본/시안/기획/기존 원장 보존. 기존 실제 누적 Gemini 텍스트20회/YouTube4회 및 별도 과거 TTS 원장 보존. 자동 재시도, 유료 전환, 무승인 외부 전송, 게시, 외부 도구 설치·다운로드 금지. 새 권한 생성/실행은 대표 조작으로만. 이번 실제 Gemini 텍스트/TTS/YouTube/영상 생성 API 0회. 실제 입력 확보 전 제작 가능하다고 과장하지 말 것. 기존 서버 환경/루트 유지하고 필요 시 직접 재시작 후 실제 localhost 제작 준비 상태 확인. 브라우저 미검증 명시.
