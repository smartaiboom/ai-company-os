## 승인 게이트 — 반드시 준수
**2026-11-11 KST 사용자 승인 확인:** 대표가 이번 첫 번째 게임 쇼츠 미션의 실제 외부 API 호출을 명시적으로 승인했다. 승인 범위는 **Gemini 텍스트 최대 10회(실패 포함), YouTube search 최대 4회 + videos 최대 4회(합계 8회), 무료 서비스만, 자동 재시도·유료 전환·대체 모델 금지, 대표 기획 승인 대기 제출까지만**이다. 이번 목표와 공개 조사 자료 및 AI 직원 결과가 Google 무료 API로 전송되고 서비스 개선·인적 검토에 활용될 수 있음을 이해하고 동의했다. 이 승인은 본 프로젝트의 이 미션에만 유효하며 다른 미션·음성·영상·게시 권한으로 확대하지 않는다.

**실행 방식:** 기존 `prepare`로 구체적인 입력·모델·호출 횟수·무료 조건 및 제안 해시를 확인하고, 기존 시스템의 `approve` 서명 원장에 위 승인 범위를 정확히 기록한 후 `run`을 1회만 실행한다. Codex가 승인 범위를 초과하는 내용 또는 핵심 미검증 유료 위험을 발견하면 호출 전에 해당 사유만 보고하고 멈춘다. 이미 완료한 키 존재/사용자 확인 할당량/결제 미등록의 전체 점검을 반복하지 않는다.

실행 전 Code에서 고정된 모델·엔드포인트가 현재 이용 가능한 무료 범위에 포함된다는 근거와 공급자 쿼터/요금 조건이 부합하는지도 필요 최소한의 게이트로만 평가한다. 이미 확인된 키 존재/YouTube 할당량/결제 미등록은 사용자가 새 오류를 보고하지 않는 한 전체 감사를 재수행하지 않는다. 실제 Gemini 텍스트 모델 무료 접근을 확인할 수 없으면 허위 기재·임의 모델 대체·유료 실행 없이 **그 한 가지 구체적인 차단 사유만** 사용자에게 보고하고 중단한다.

무료 Gemini 텍스트 입력/출력이 제공자 제품 개선이나 인적 검토에 활용될 수 있음을 승인 전에 알리고, 승인한 입력 범위를 지킨다. API 키·사내 자료·개인정보·과거 보류 게임 후보를 모델 입력에 포함하지 않는다. YouTube 공개 메타데이터의 보존·갱신 기한 30일을 기록한다.

## 실제 작업
1. `AGENTS.md`와 위 세 보고서, `companies/video/video_mission_one.py`의 기존 `prepare/approve/run` 계약을 이용한다. 최신 GitHub를 안전하게 동기화하고 미커밋/미추적 파일을 보존한다.
2. **기존 승인 범위를 적용하여** 모의 작업 반복 검증, UI 재설계, 새 프레임워크 개발, API 시험 호출, 키·쿼터 일괄 재점검을 하지 않는다. 중단 사유가 없다면 실제 실행으로 진행한다.
3. 위 사용자 승인을 적용하고 필수 무료 실행 조건을 충족한 경우에 한하여, 기존 CLI의 `prepare`가 만든 정확한 호출 제안 JSON/검토 해시를 검토한다. 제공자·모델·엔드포인트, 실제 전송 입력, 호출 상한과 $0/무료 전용 제한이 승인 범위와 일치할 때만 `approve` 및 `run`을 한 번 실행한다. 예외 시 별도 승인 요청 없이 실행하지 않는다.
4. 실제 조사 직원은 게임·쇼츠 인기 관련 검색어를 자율 생성한다. YouTube 공개 메타데이터로 관측 가능한 조회수·길이·게시일·링크·관측 시각·한계만 기록한다. Shorts 분류, 흥행 인과, 저작권 확보는 자동 확정하지 않는다.
5. AI 관리자가 후보 근거/게임 소재/목표 길이를 결정하고 대본 직원이 전체 한국어 내레이션·장면 구성을 작성한다. 기존 내부 검토·반려/수정 가드를 적용한다. 실제 검증된 결과만 대표 승인 대기에 제출한다.
6. 외부 요청 실패·HTTP 429·불명 timeout·무료 한도/서명/상한 차단 시 자동 재시도 및 다른 모델로 fallback하지 않는다. 사용한 시도는 소모 처리하고 남은 결과 및 차단 사유만 저장한다. 이미 저장된 동일 작업의 중복 요청을 만들지 않는다.
7. 컷룸 기존 디자인을 보존하고 실제 결과 전문/출처/버전/SHA/승인 대기 상태를 확인한다. TTS, WAV, MP4, 플레이 영상 생성, 게시, 대표 승인 클릭은 수행하지 않는다.
