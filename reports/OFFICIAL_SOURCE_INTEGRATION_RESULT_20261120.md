2026-11-20 12:34–12:42 KST. WSL2 Ubuntu와 VS Code 작업 루트는 `/home/jun/projects/ai-company-os`다. 깨끗한 작업 트리에서 GitHub `main`을 `dd87051`에서 기준 커밋 `950028f`로 fast-forward했다. 앞선 조사, 409 진단, 복구, 근거 참조, 재계획 및 감독 보고서의 운영 이력을 유지했다.

## 구현과 승인 범위

- `AGENTS.md`에 대표의 목표·권한 승인, ChatGPT의 구조적 설계·독립 검토, Codex의 구현·로컬 검증 역할을 명시했다. 현 로컬 환경, 같은 기능 내 자율 수정, 외부 실패 재호출 제한, 커밋·푸시·원격 확인 기준을 반영했다.
- `core/research_https.py`와 `core/web_research.py`는 정확히 승인된 페이지의 robots와 HTML 요청을 따로 예약하고 결과를 근거 카탈로그에 전달한다. 기존 공개 DNS/IP·고정 TLS·정적 HTML 추출·요청 제한 시간과 크기 검증을 재사용했다. 리다이렉트를 따라가지 않고, robots가 확인되지 않거나 자동 접근 금지가 확인되면 차단한다. 없는 페이지·차단·빈 관측·전송 실패를 미실행 및 실제 원문과 구분한다. 검색 스니펫은 단서이며 모델이 제시한 새 URL, 인증·유료벽, 미디어 파일 접근은 허용하지 않는다.
- `publisher_discovery.py`는 기존 제작사 서명에서 승인 영상 장면과 연결된 Klei 경로를 검증한다. 현재 새 제안은 `https://www.klei.com/robots.txt`, `https://www.klei.com/creation-guidelines`, `https://www.klei.com/games/dont-starve-together/` 3개로 제한한다. 이전 서명은 경로의 근거로 연결하며 그 승인과 예약을 재사용하지 않는다. CDN의 robots와 미디어 경로를 포함하지 않았다. 다른 승인 장면의 제작사 직접 조회 범위는 현재 확인되지 않았다.
- `research_supervision.py`와 `research_workflow.py`는 별도의 v2 감독 업무에 이전 이력, 제작사 경로 근거, 요청 해시, 현재 키, 24시간 만료, 무료 전용과 $0 상한을 연결한다. 기존 한도인 Gemini 3.5 Flash-Lite 직원 최대 3회와 관리자 최대 2회(최종 독립 검토 포함), Tavily 무료 Researcher 기본 검색 최대 1회에 **공식 GET 최대 3회**를 별도 예약한다. robots 1회와 HTML 2회 모두 상한에 포함된다. Gemini에는 기존 업무 목표·기준·공개 출처와 보완 지시를, Tavily에는 승인 공개 검색어만, 제작사에는 정확한 공개 URL의 GET만 허용한다. 실제 HTML은 발췌·정확한 URL·발행 주체·관측 시각·해시와 연결한다.
- 직원은 도구 순서를 선택한다. 검색 결과에서 공식 URL을 찾더라도 별도 서명 범위 밖 주소는 조회할 수 없다. 관리자 보완과 독립 검토는 기존 감독 루프를 사용한다. 같은 발행사의 페이지 여러 개와 검색 단서만으로 독립 근거 요건을 충족할 수 없으며, 원문을 읽었다는 사실만으로 각 장면의 편집권을 확정할 수 없다. `studio_server.py`와 `studio/studio.js`는 새 공식 경로·GET 한도·응답 상태와 승인 대기를 표시한다.

기존 누적 Gemini 예약 5회와 응답 4,903토큰, Tavily 예약 0회, 이전 결과의 관리자 보류를 읽기 전용으로 확인했다. 이전 제작사 서명은 GET 예약 0회였고 기존·신규 감독 승인 디렉터리는 없었다. 운영 파일 227개의 체크섬이 전후 동일했다. 비밀키와 잠금 파일을 비교 목록에서 제외했으며, 대본 v2, WAV 4개, MP4 1개, 대표 평가, 제작사·Commons 상태와 서명 원장은 그대로 보존했다. 추가 백업은 만들지 않았다.

## 독립 설계 검토로 넘길 항목

현재 정확한 공식 직접 조회 범위는 Klei 한 곳이다. 다른 장면에 대해서는 호스트·경로와 공개 접근 정책을 확인한 뒤 새 범위로 검토할 수 있다. 직원 결정 3회 중 최종 보고가 한 회를 사용하므로 세 도구를 각각 호출하면 같은 범위에서 직원 보고 없이 마지막 관리자 검토로 갈 수 있다. 그 경우 목표 달성으로 승격하지 않는다. 보존 전문 자료를 검증된 읽기 전용 후보로 미리 제공하는 방식과 별도 승인된 조사 단계 분리를 독립 설계 검토 후보로 남겼다. 범용 검색이나 권한을 자동 확대하지 않았다. 운영 재개는 현재 계정과 키·무료 조건·잔량, 3개 경로를 검토하고 새 서명 범위를 승인한 뒤 한 번만 가능하다.
