# M4 미확정 예약 안전 처리 최소 구현 및 모의 검증

## 공통 규칙
codex_tasks/README_KOREAN_LANGUAGE_RULE.md를 적용: 진행 설명·최종 답변·보고서 한국어, 일본어 금지, 코드/식별자 원어 유지. 시간 KST.

## 배경
reports/v01_m4_real_free_ai_acceptance_20261102.md의 최신 '제공자 확인 및 실제 검증' 섹션을 먼저 읽는다. 기존 프로젝트 c85d9853906a, 예약 b4d499324885494f9148ac4d67318075, reserved 1/7, provider ID 없음. 외부 처리 결과 미확정, 실제 호출 재개 불가. 보존된 원본/복제본은 같은 프로젝트의 복제본. 기존 tests/support/m4_runner.py 등 재사용. 중복 개발 금지.

## 목표
기존 예약은 reserved 상태 및 예산 소모 그대로 두고, 별도 명시적 사용자 판단 기록을 통해서만 이후 **새로운 별도 요청**이 안전하게 가능하도록 하는 최소 기능을 구현·모의 검증한다. 이번 작업에서는 실제 API 호출 절대 금지, 새 프로젝트 생성 금지, 실제 기존 프로젝트 기록 변경 금지. 사용자 판단을 자동 생성하거나 과거 승인으로 간주하지 않는다.

## 범위
1. ai_safety.py와 프로젝트 저장/락 경로만 검토해 현재 기본 reserved 차단을 유지하면서 한정적 예외 경로 추가. 판단 기록에는 프로젝트 ID·목표 지문·기존 예약 ID·기존 기록 지문·KST 판단 시각·처리 결과 미확인·중복 가능성 인지·신규 허용 횟수(최대 1회)·전송 범위가 필요하다. 판단은 실제 사용자 명시 승인에서만 생성; 지시서나 과거 승인으로 자동 발급하지 않는다. 판단 없는 기본 경로는 기존처럼 차단.
2. 기존 reserved 항목과 소모 1/7을 수정하지 않으며 새 호출을 '기존 요청 재시도'로 취급하지 않는다. 판단 기록 일회성 소비, 7회 총량 및 재개당 2회 한도, 기존 프로젝트 락·모델 openrouter/free·고정 HTTPS·명시적 전송 동의·요청 스레드 종료 관측을 유지. 동시성/재시작/기록 위변조/목표 변경/복제본 경합/새 미확정 예약은 차단. 실제 외부 처리 결과를 알 수 없다는 사실을 표시한다.
3. 실제 호출 도구의 종료/관측과 안전 검사 통합에 미비점이 있으면 **모의 테스트로만** 검증 가능한 최소 수정. 전체 wall-clock 취소가 불가능하면 그 한계를 명시하고 무리하게 성공으로 판정하지 않는다. 운영 앱 M1~M3 기능 재설계 금지.
4. 집중 모의 테스트: 승인 없는 차단, 기록 불변, 일회성, 예산 7/2, 동시성, 재시작, stale 목표/지문 변조, 미완료 스레드 차단, 새 미확정 예약 차단. 테스트에서 외부 네트워크/실제 API 호출 차단. 필요 최소 테스트만 실행하고 전체 회귀는 관련 변경에 꼭 필요할 때 한 번만.
5. reports/v01_m4_real_free_ai_acceptance_20261102.md에 '미확정 예약 안전 처리 구현' 결과·테스트 수·실제 호출 0·기존 예약 보존·다음 사용자 판단 조건을 한국어로 추가. 비밀/업무 원문/실제 JSON/미추적 파일/백업 커밋 금지. 선택적 커밋·푸시, git diff --check.
