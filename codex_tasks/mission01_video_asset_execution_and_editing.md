# 미션 01 실제 영상 자산 확보·편집 실행 (2026-11-19 KST)
AGENTS.md 및 대표 개인 운영 정책 준수. 대표가 전체 음성을 청취하여 "일단 음성은 이정도면 쓸만한거 같아"라고 평가했고 시간 조정안을 승인했다. 대본은 빈약하지만 이번에는 개선하지 않고 영상에 집중한다. 현재 운영의 실제 승인 조정안/장면별 WAV/음성 길이/청취 평가/자산 직원 결과 및 현재 정책 사용 기록을 읽기 전용으로 확인. 실제 기록과 대표 진술을 구분하고 음성 재생성, 기존 관리자/자산 직원 호출 반복 금지. 기존 작업/데이터 보존.
## 목표
대표가 장면마다 파일을 직접 찾고 편집하는 구조를 탈피한다. AI 직원이 대본·실측 음성에 맞는 소스의 종류/확보 방법/장면별 사용 구간을 판단하고 합법적이고 실행 가능한 도구로 실제 확보·편집하는 연결을 개발한다. 기존 production_sources.py, mission_production.py, ai_clip_pipeline.py, production_operating.py, measured_timeline.py, quality_tool_adapters.py, employee_web_research.py 및 과거 영상 품질 개선 결과를 재사용. 현재는 자산 직원의 계획만 있고 직접 확보 어댑터가 없음을 전제로 구체적인 해결책을 구현한다.
1. 현재 실제 자산 직원 결과(있으면 그대로 활용)와 장면 요구를 분석. 기존 검색 메타데이터는 단서만. 공식 게임 제작사/배포자가 직접 제공하는 다운로드 가능한 영상 및 명시적 사용 조건, 기존 권리 확인 보관함, 적법한 자체 캡처, 권리 확인된 무료 생성 후보를 가용성별로 분리. 공식 문서 근거와 비용 조건을 확인할 수 있는 방법을 개발하되 실제 외부 요청은 이번 작업에서 하지 않는다. 검색 결과/유튜브 URL/공개 게시만으로 다운로드 및 사용권 허용 추정 금지. 유튜브 무단 추출 및 접근제한 우회 금지. 무료 생성 도구가 검증되지 않았다면 실행 가능으로 표시하지 않는다. 
2. 가능한 최소 실제 확보 경로를 구현. 우선 권리가 명시된 공식 직접 제공 파일에 대한 일반화된 검증/다운로드 어댑터 및 기존 로컬 라이브러리 자동 인수 연동을 검토하고, 구현 가능한 경우 허용 호스트/HTTPS, 리다이렉트/SSRF/사설 IP/경로/파일 크기·시간·형식 검증, 신뢰할 수 있는 출처와 권리 근거, 해시/영수증/실패 기록을 적용. 공식 제공처/자료에 명시적 사용 허가 및 직접 다운로드 허가가 없는 경우 차단하고 대안을 제시. 실제 파일이 없는 상태에서 카드/테스트 영상으로 자동 대체하지 않는다. 신규 검색·다운로드·생성은 기존 개인 운영 정책의 허용 범위 밖이므로 필요한 공급자/데이터 유형/요청 및 비용 상한을 한 번의 범위 확장으로 대표 검토 가능하게 준비하고 이번에 승인이나 실제 실행을 생성하지 않는다. 기존 작업 경계의 반복 토큰 입력·장면별 동의 팝업 복구 금지. 유료 전환 금지. 
3. 실제 소스와 승인 조정안 및 실측 WAV에 맞춰 편집 작업을 연결. 기존 ClipJob 재사용, 장면 의미에 맞는 클립/구간/프레이밍/전환/자막 배치를 AI가 결정할 수 있는 도구 계약 마련. 지원되지 않는 효과는 미지원 표시. 시스템은 시간·해시·원문·출처·권리/디코딩 검증과 렌더를 수행. 이전 소스의 반복·카드 위주 지루함 및 음성과 화면 불일치 개선 경험을 적용 범위와 함께 전달. 특정 게임 ID/결과/장면 길이/효과 고정 금지. 이미 생성된 WAV와 승인 타임라인 그대로 사용. 새 시간/대본 변경 및 추가 비용은 별도 대표 승인. 소스가 짧거나 의미/권리 확인이 불가능하면 관리자 보완 경로 또는 차단 사유를 제공. 감각 품질은 실제 증거 없이 합격으로 표시하지 않는다. 영상 샘플 프레임·자막/실측 타이밍·반복 및 구간 적합성 검토 자료 생성, 가능하면 기존 관리자 검토 연결(추가 실제 호출은 별도 승인 범위). 
4. 현재 컷룸 상단 다음 작업을 일관되게 유지. 실제 운영에서 기존 자산 직원 결과 및 승인된 시간 조정안, 모든 음성의 보존 확인. 자산 부족이면 현재 필요한 구체 소스/권리 및 가능한 자동 확보 경로를 한국어로 표시. 개인 운영 정책 내 가능한 작업은 제작 실행 한 번으로 진행하도록 연결. 대표에게 파일 하나씩 준비시키는 경로는 예외/진단으로 남기고 기본 운영 경로가 되지 않도록 노력. 실제 자동 확보 불가능하면 명확히 보고하고 대안을 숨기지 않는다.
