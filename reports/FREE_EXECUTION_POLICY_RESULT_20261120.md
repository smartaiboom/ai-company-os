## 정책 변경과 확인

`AGENTS.md`에 대표가 확인한 무료 등급과 직접 등록한 무료 전용 설정을 서명 승인 근거로 사용할 수 있다고 명시했다. 이전 실행 보류는 실시간 가용량을 운영 절차에서 필수로 판단한 결과였다. 기존 컷룸 엔진은 공급자 잔량을 독립 조회하는 코드 없이 검토용 범위를 만들 수 있었다.

`research_supervision.py`, `owner_operating_policy.py`, `studio/studio.js`를 수정했다. 새 감독 범위에 대표 확인의 근거 유형, Gemini 모델·프로젝트와 Tavily Researcher/PAYG OFF, 유료 대체 금지, 독립 잔량·청구 미확인을 명시한다. 승인 원장은 이 정보에 현재 키 결합, 서명 시점, 유효기간, 정확한 공급자·호스트·경로와 상한을 결합한다. 기존 권한·키·만료·철회·예약 규칙을 유지했다. 공급자 오류, 잔량 부족, 결제 요구 또는 전송 미확정 시 후속 호출을 중단하며 유료 전환 및 자동 재호출을 금지한다. 실제 사용량·비용의 무료 여부는 독립 확인하지 않았다.

기존 `.env`에서 `configured`를 재확인했다. 새 서명 확인 필드와 잔량·청구 미확인 표시를 비네트워크 임시 원장으로 점검했고 JavaScript 문법 검사를 통과했다. 이전 테스트와 운영 서버를 반복 실행하지 않았다.

## 실제 검증 실행 상태

정상 컷룸 승인·실행 경로로 단일 작업을 시작하려 했으나 자동 승인 검토가 도구 실행 자체를 거부했다. 상한 승인은 인정했으나 공급자별 전송 데이터의 구체 범위에 대한 승인이 확인되지 않았다고 판단했다. 따라서 새 승인 기록·예약·실행이 시작되기 전에 멈췄다. 공급자 잔량이 미확인이라는 이유로 중단한 것은 아니다.

읽기 전용으로 새 v3 제안과 첫 실제 요청의 본문 해시가 일치하는 것을 확인했다. 검토 대상 전송 범위는 다음과 같다.

- Gemini 3.5 Flash Lite 최대 5회. 승인 프로젝트의 조사 목표·시청자 조건·승인 장면 설명·단계와 수정 범위 식별자, 이전 보류 및 관리자 지시, 보존 자료 12건의 공개 근거, 실행 중 확보한 조사 결과와 직원·관리자 응답을 감독 흐름에 사용한다.
- Tavily Researcher 최대 1회. 승인된 장면의 공개 검색어 선택지 3개 중 모델이 고른 검색어만 보낸다.
