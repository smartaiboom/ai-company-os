# 컷룸 미션 01 · 기획·대본 대표 검토 연결 — 2026-11-11 KST

**외부 호출 전 준비 완료. 실제 AI 호출 0회.** 실제 기획안·대본은 아직 생성되지 않았다. 대표의 실제 기획 승인, TTS, 영상 렌더, 최종 영상 승인과 게시도 수행하지 않았다.

## 연결한 흐름

컷룸에서 목표를 저장하고 **미션 01 준비**를 누르면 기존 대표 프로젝트가 별도 `QualityProviderStore` 작업을 연결한다. 브라우저에는 외부 전송 승인·실행 버튼이 없다. 승인 전에는 `research_planning`에서 실행 권한 대기를 표시하며 보고서나 승인 버튼이 생기지 않는다.

실행 경로는 기존 Gemini 3.5 서명 동의, 역할별 요청 검증, 시도 원장과 재실행 차단을 재사용한다. 기존 범용 품질 provider의 기본 전송 비활성 설정은 유지된다. 별도 서명 범위가 있는 미션에서만 관리자 계획 → 조사·후보 비교 → 대본 초안 → 내부 검토·필요시 수정 → 편집 인수 → 관리자 최종 검토를 실행할 수 있다. 실행 중 새 웹 검색은 하지 않으며 한국 게임 쇼츠 조회 성과는 `unverified`로 유지하고, 기존 보류 후보를 자동 인수하지 않는다.

대표 제출은 조사·대본·편집 인수의 수락, 목표 길이와 대본·장면 계약, 요청 및 응답 증거를 검증한 뒤 이뤄진다. 이 단계에서 렌더 사양과 미디어 파일은 필요 없다. 컷룸에서 보고서 버전/SHA, 후보와 선택 이유, 전체 한국어 대본·스토리보드, 내부 반려와 수정 이력, HTTP 상태·KST 시각·토큰·요청/응답 해시를 확인할 수 있다. 권리와 최신성은 확인 대기로 표시한다. 요청 입력과 산출물은 로컬 프로젝트에 저장하며 요청·응답 원문 전체 대신 기존 컨텍스트·검증된 역할 결과와 해시를 보존한다.

## 검증

오프라인 테스트 19개 통과. 격리된 네이티브 HTTP 모의 경로에서 조사→대본 반려→수정본 수락→편집 인수→대표 승인 대기까지 10회 응답을 검증했다. 별도 동의 누락, 키 변경, HTTP 429 소모 후 재개, 가짜 실 AI 결과 제출은 차단됐다. 기존 음성·영상·동의·시도 원장은 변경하지 않았다.

Chromium에서 신규 프로젝트와 호출 0건의 권한 대기, 격리 모의 보고서와 전체 대본, 새로고침 후 상태 복원, 피드백 저장을 확인했다. 격리 화면에는 **오프라인 HTTP 검증**을 표시했고 실제 AI 배지나 영상 플레이어가 나타나지 않았다. 화면 캡처는 `data/video_representative_workflow/20261111_mission01_evidence/`의 `mission-review.png`, `mission-permission.png`에 있다.

## 최신 대표 지시 적용 · 게임과 길이는 직원이 직접 조사

작업 중 GitHub에 추가된 대표 지시 `3580489`를 반영했다. 목표는 **“요즘 인기있는 게임에 대한 흥미있는 쇼츠 영상을 만들어봐. 기본적으로 인기있는 쇼츠는 몇초인지도 확인해보고.”**다. Codex가 열람했던 게임 후보·순위·길이 통계·추천 초 수를 실업무 입력에서 제거했다. 그 자료는 이번 모델의 조사 근거와 승인 문서 입력에 사용하지 않는다.

- 새 컷룸 프로젝트 `company-aba553f29cfb454c8c05bad4abb49969`는 목표와 형식 제약만 인수했다. 특정 게임·후보 개수·길이 범위·공개 스냅샷을 입력하지 않았다. 대상은 미정, 한국어 세로형 YouTube Shorts다. 이전 로컬 준비 기록은 보존했고, 이전 입력 계약은 최신 실행 경로에서 거부한다.
- **실제 차단 사유.** 현재 실제 AI 조사 직원이 호출할 웹 검색·조회 도구가 연결되어 있지 않다. 게임 인기도와 개별 쇼츠의 길이·조회수·게시일·관측 시각을 직접 조사할 수 없다. 모델 호출이나 대표 제출로 넘기지 않고 `mission_independent_web_research_unavailable`를 표시한다. 조사 도구의 연결과 별도 접근 승인이 먼저 필요하다.
- **60초 계약 점검.** 게임 작업 준비 시 60초를 자동 삽입하던 부분을 제거했다. 대본 검사에는 명시적으로 결정된 목표 길이를 받을 수 있도록 최소 변경했다. 목표 길이·대본 끝 시각·장면 시간·과밀 발화를 확인하며 기존 호출자의 기본값은 60초다. 기술적으로 최대 180초까지 검사할 수 있지만 이는 목표나 추천 길이 설정이 아니다. 조사 도구가 없으므로 실제 관리자의 길이 결정 및 그 결과를 대본 직원에게 넘기는 게임 업무는 아직 실행할 수 없다.
- **이번 검증.** 오프라인 20개 통과. 입력에 외부 후보·길이 자료가 없고 60초가 강제되지 않는지, 조사 불가 시 승인 제안·호출·대표 제출이 차단되는지 확인했다. 34초 검사 fixture에서 목표와 장면 종료가 맞으면 통과하고 기존 60초 검사와 종료 시각이 다르면 거부한다. 이는 길이 검증 시험이며 AI의 주제·길이 판단 결과가 아니다. 기존 60초 provider 및 대본 회귀를 확인했다. 화면 반복 시험과 미디어 생성은 수행하지 않았다.

## 별도 승인 제안 1건

대상은 위 새 프로젝트의 정확한 대표 목표와 한국어 9:16 YouTube Shorts 제약이다. 대본 작성 전에 조사 직원이 근거를 직접 얻고 관리자가 게임 소재와 길이를 결정해야 한다. 실제 개인·회사 자료, 보류 후보, 이전 음성 입력은 전송 범위에 포함하지 않는다. 정확한 목표·입력 계약·해시를 검토한 뒤 승인한다.

- 모델은 Gemini Developer API `gemini-3.5-flash-lite`, 고정 텍스트 `generateContent` 엔드포인트. 기본 8회(관리자 계획 1, 조사·대본·편집 각각 작성 및 검토 6, 최종 검토 1), 수정 1회가 필요하면 2회 추가해 **실패 포함 최대 10회**. 회당 최대 출력 4,096토큰. 자동 재시도·fallback·검색·미디어·게시 없음.
- **기존 Free Tier, Billing 비활성, 비용 상한 $0**만 허용한다. 환경에서 키 존재와 과거 서명된 프로젝트의 키 일치를 로컬로 확인했다. 과거 증거는 만료됐고, 현재 프로젝트의 해당 텍스트 모델 접근, Billing과 모델별 잔여 10회 및 RPM/TPM은 확인되지 않았다. 고정 모델·엔드포인트·실행 플래그도 현재 미설정이다. 공급자의 무료 단가는 이 계정의 할당량이나 실제 청구 확인과 별개다. [공식 가격](https://ai.google.dev/gemini-api/docs/pricing#gemini-3.5-flash-lite) · [할당량](https://ai.google.dev/gemini-api/docs/rate-limits)
- 무료 서비스 입력·출력이 Google 제품 개선과 인적 검토에 쓰일 수 있다는 점에 별도 동의가 필요하다. 전송 대상은 검토한 목표·제약·역할 지시 및 해당 실행의 선행 작업 결과·수정 피드백이다. 비밀키는 인증 헤더에서만 사용한다. [무료 서비스 약관](https://ai.google.dev/gemini-api/terms)

컷룸 실행은 `PYTHONPATH=core:companies/video python -B -m studio_server --host 0.0.0.0 --port 8000`이며 Ports에서 8000을 Private으로 유지한다. 승인 범위가 확인되면 동일한 PYTHONPATH에서 `python -B -m video_mission_one prepare <컷룸 프로젝트 ID>`에 `--confirm-free-account --account-project --remaining-requests --quota-note`를 지정해 제안을 검토한다. 대표 동의 후 `approve <ID> --proposal <로컬 제안 파일> --review-hash <해시> --confirm-free-data-policy`로 기존 서명 승인을 저장하고, `run <ID>`를 한 번 실행한다. 이 명령은 이미 수락된 결과가 있다면 재호출 없이 대표 제출만 마칠 수 있다. 현재 게임 미션은 조사 도구 미연결로 prepare·approve·run이 모두 차단된다. 다음 단계는 **직원용 웹 조사 경로의 구현·접근 범위를 정하고, 그 도구 요청을 포함한 정확한 호출 상한과 무료 조건을 다시 승인받는 것**이다. 아래 텍스트 호출 상한 10회만으로 전체 조사 업무의 비용·요청 수가 확정되지는 않는다.
