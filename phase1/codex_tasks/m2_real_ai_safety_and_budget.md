# v0.1 M2 통합 작업 — 실제 무료 AI 실행 안전 경계와 예산

## 목표
M1에서 만든 mock 통합 흐름을 재사용하여 실제 무료 AI로 진행할 준비를 끝낸다. **이번 작업은 구현·테스트·보고를 한 번에** 수행하며, 실제 외부 AI API 호출은 금지한다. 신규 독립 아키텍처나 기존 기능 재개발을 피한다.

- AGENTS.md, reports/ai_company_os_v01_completion_roadmap_20261102.md의 M2, reports/v01_m1_mock_end_to_end_20261102.md

- git status/diff와 origin/main 동기화 확인. 기존 사용자 JSON, 스냅샷, 백업, 추적/미추적 변경 보존. reset/clean/force push 금지.

## 이번에 구현할 기능
1. 기존 단일 실제 AI 계획/직원 호출 경로를 보존·재사용하며 요청 **직전** 공통 안전 검사: 정확히 openrouter/free, 허용된 OpenRouter HTTPS API 호스트와 /chat/completions, 명시적인 해당 프로젝트 외부 전송 동의 및 활성화 여부. 다른 모델·URL·유료 fallback 없음. 모든 실제 호출 경로(계획, 수동 직원 실행, 향후 검토/수정)의 우회 가능성 점검.
2. 프로젝트별 영속 API 요청 예산: 기본 상한은 대표 시연 프로젝트 기준 최대 7회, 개별 시작/재개 당 최대 2회. 계획 호출도 포함하며 전송 전에 시도 예약·KST 기록, 실패/타임아웃도 횟수 차감. 승인 대기, 한도 소진, 중단 예약, 요청 오류에서 자동 재전송 금지. 여러 탭·재시작에서 초기화하지 않음.
3. 기존 mock 전용 /workflow/run은 유지한다. 별도 실제 모델용 명시적 시작·재개 경로를 최소 구현하되 사용자 승인 전에는 실제 네트워크 호출 불가능하도록 보수적으로 차단한다. 목표/입력/선행 결과/의견이 전송될 수 있음을 안내하고 예산·남은 횟수·정지 원인을 UI에 표시한다. 실행할 업무 선택과 승인 경계는 기존 로직 재사용.
4. 입력 크기/출력 토큰 상한, API 오류 데이터에 포함된 민감 정보의 화면·로그 노출 억제. 기존 결과 보존 및 프로젝트 잠금/409, 최종 확정 무효화, KST 동작 유지.
5. 실제 호출 동의 설계: 향후 M4에서 구체적 데이터/횟수를 사용자가 별도 승인해야 함. 이번에는 사용자 승인 없는 동의 활성화·실제 호출 금지. 테스트 중에는 승인 상태도 모의 주입하고 외부 요청은 실패 mock으로 차단한다.
6. 변경 폭이 큰 경우 우선 M2 완료 기준에 필수인 경계와 예산만 구현하고 미구현 범위는 정확히 기록한다. 기존 실제 수동 경로를 잘못 차단하거나 안전하지 않게 우회시키지 않는다.

## 완료 기준/검증
- 프로젝트/아티팩트 TemporaryDirectory와 네트워크 차단 mock으로 계획→여러 역할 실행→승인 대기→재개 흐름에 공통 호출 예산 적용을 증명한다.
- 비무료/누락 모델, 다른 호스트·HTTP, 동의 없음, 예산 소진, 중복·미완료 예약·재시작, 실패/타임아웃, 입력 초과 시 외부 요청 0회 또는 허용된 1회만 시도하고 정상 정지하며 기존 결과 보존.
- 기존 M1/무료 모델/검토/최종 보관 테스트 재사용 및 전체 안전 회귀 1회. 반복 테스트는 오류 수정 때만 한다. 격리되지 않은 실제 업무 smoke는 실행하지 않는다. git diff --check 확인.
- **어떠한 실제 OpenRouter/OpenAI API 요청도 보내지 않는다.**
