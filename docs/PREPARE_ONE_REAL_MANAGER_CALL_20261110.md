# 실제 AI 관리자 1회 인수 테스트 — 준비·검토·승인 게이트
기준일: 2026-11-10 KST

## 이번 작업의 확정된 사용자 방향
사용자는 무료 계정·추가 비용 0원·엄격한 호출 횟수 제한으로 **단계적인 실제 AI 관리자/직원 테스트 진행**에 동의했다. 이는 전체 AI 회사의 자유로운 외부 호출 승인도 아니고, 아직 정확한 모델/전송 payload/무료 계정 상태를 본 최종 실행 승인도 아니다.

목적: 지금까지 검증한 것은 mock/fixture 기반 품질 및 Gemini native 요청·응답 경로이다. 다음에 실제 모델의 **새 관리자 계획 1회**만 시험하고, 실제 판단 결과의 유용성을 평가할 수 있도록 별도의 좁은 승인·기록 장치를 준비한다.

**이 문서는 실제 개발 실행 지시서다. 읽고 끝내지 말고 구현·검증·결과 저장까지 수행한다. 다만 이번 작업에서 실제 모델 요청은 절대로 발송하지 않는다.**

## 실행 전 확인
- `AGENTS.md`, `docs/OPERATIONS_READINESS_GATE.md`, `docs/NEXT_REAL_MANAGER_STAFF_PROVIDER.md`, `reports/manager_staff_provider_readiness_result.md`, `reports/CURRENT_PROGRESS.md`, `reports/QUALITY_REVIEW.md`부터 확인.

- 현재 개발 작업 트리의 미커밋 변경과 원격 최신 버전 확인, 안전한 동기화. 강제 reset/clean/자료 삭제 금지.

## 1. 정확한 1회만 허용하는 실AI 인수 스코프 구현
- 새로운 전용 저장소/모드에 **새 테스트 프로젝트** 생성. 기존 Gemini 단일 인수 `dialogue-f4eb...`와 그 1/1 원장, 이전 사용자 프로젝트를 재호출하거나 실행 승인으로 재사용하지 말 것.
- 신규 목표 예시: 'AI 초보자 대상 60초 세로 쇼츠: ChatGPT 질문을 구체적으로 만드는 실제 사례 하나를 설명하라.' 대상·규격·미디어/음성 제약·소스 미확보 등을 정직하게 전달한다. 기존 원본 파일/원장/키/민감한 사용자 피드백 원문·프로젝트 전체는 전송 금지.
- 관리자 **plan 단계 1개 요청만**. 직원 실행, review, finalize, 피드백 처리, 영상 생성, 외부 게시, 두 번째 요청은 무조건 차단. 성공·실패·429·타임아웃·모호한 종료 모두 1회 소모, 자동 재시도/유료 대체/fallback 금지.
- 선택된 provider/model/endpoint와 정확한 system/user payload, 응답 스키마, 모델이 받을 데이터, 최대 output tokens, 추정 상한(비용 정책 0원), 호출 횟수 1, Google 무료 데이터 처리 경고, 현재 승인이 필요한 항목을 **실제 키를 공개하지 않고** 파일로 준비할 것.
- 실전 전송 스위치는 단순 환경변수나 KEY 존재/서명만으로 열리지 않도록 **별도 인수 전용** 정책을 추가한다. 정확한 새로운 스코프 해시 + 요청 해시 + 승인 유효기간 + 프로젝트/키·무료 계정 증거를 묶고 안전하게 실패하도록 한다. 과거 `QUALITY_TRANSPORT_ENABLED=False` 전역 차단 정책은 유지. 기존 호출 보호정책을 약화시키지 않는다.
- 실제 프리티어 여부/키 연결/청구 및 쿼터 상태는 API 키 존재 여부만으로 입증할 수 없다. Codex가 사용자 Google 계정 내 Billing을 보거나 검증했다고 주장하지 말 것. 실제 화면에서만 확인 가능한 항목은 사용자 확인 대기 상태로 남긴다.
- 현재 무료 등급/정책/모델 지원 여부가 미확인이라면 진행 가능하다고 추정하지 말고 실제 호출 없이 보류. 현재 도구가 공식 웹 확인을 못하면 그 상태 명시.

## 2. 실제 입력/응답 검증과 샘플 품질 평가
- 기획 모델이 질문을 할지, 직접 전략을 수립할지 판단하도록 만든다. 출력 계약은 시청 대상, 핵심 메시지1개, 초반3초 후크 기획, 시연 사례, 60초 구성/장면 수요·실제 클립 필요량, 대본/목소리 방향, 직원 역할·완료 기준, 불확실성, 사용자에게 꼭 필요한 추가 질문과 이유.
- 출력은 검증 가능한 JSON schema 및 역할별 계약으로 검사. 허위로 실제 소스/영상/권리 확인됨을 주장하면 수용 금지.
- **이번에는 실제 모델 호출 없음**. HTTP mock으로 1회 소모/만료/서명/입력 변경/키 변경/모드 혼합/추가 호출 차단 테스트만 수행하며 이를 실 모델 평가로 주장하지 않는다.
- 예산/안전 검증과 품질 평가를 분리. 기존 10점 영상 기준은 실제 시청/청취할 때만 점수 부여, 관리자 전략은 별도 **전략 평가표**로 다음 단계에서 사람이 검토.

## 3. 결과와 진행 상태를 파일로 저장
- 현 상태와 다음 사용자 확인 항목을 `reports/CURRENT_PROGRESS.md`에 갱신.
- 신규 `reports/REAL_MANAGER_CALL_REVIEW.md`: 사용자 검토용 **정확한 모델명, 모델/endpoint, 프로젝트 목적, 전송 본문에 포함되는 정보, 전체 호출 예산 1회, 예상 무료/과금 불확실성, 0원 정책, Google 데이터 사용 경고, 승인 전 위험/차단 현황, 정식 실행 여부**를 간결하게 작성. 공개 GitHub에는 개인정보·API 키·인증 정보·실제 전송 전체를 노출하지 말 것. 전체 정확 payload와 확인용 hash는 **별도 로컬 보호 경로**에 저장하고 보고서에 그 경로/해시만 표시한다.
- `reports/real_manager_one_call_prepare_result.md`에 코드 파일/커밋/통합 모의 테스트 결과, 실제 외부 호출0회·비용0원, 이전 자산 보존, 미완료 게이트·사용자가 할 다음 확인·최소 실제 실행 명령(아직 실행 금지)을 명시.
- 제품 소스/테스트/위 결과 파일만 GitHub에 커밋·푸시. `data/`, 원장, payload 원문/민감정보, 새 모델 실행 응답 원문, 미디어/임시자료는 GitHub 반영 금지. 사용자에게 긴 콘솔 로그 대신 결과 파일 경로만 알린다.

## 4. 성공 조건과 중단 조건
- **성공:** 새 plan 1회 인수 요청을 안전하게 준비하고, 현재 차단 상태와 최종 사용자 승인 항목이 명확하고, mock HTTP 기반 안전 시험 통과. 실제 호출은 0회.
- **중단:** 모델/계정 무료 요금 불확실, 정책/키 연결 불명확, payload에 민감정보, 기존 원장 변경 위험, 미검증 활성화 또는 비용 발생 여지.
- 내부/데이터 보호: KST UTC+09:00, 원장/영상/입력 Flow 클립/TTS/백업/아카이브 불변, 불확실한 호출 재시도 금지. UI/GUI 개발 금지.

## 이 작업 뒤 다음 결정
ChatGPT가 결과 파일을 직접 확인한 뒤 사용자에게 **실제 전송 상세·무료 등급 확인방법·1회 호출의 개별 실행 승인**을 안내한다. 승인받기 전에는 실제 모델에 데이터 전송하거나 1회를 소모하지 않는다.

사용자의 최종 목표는 여전히 **AI 관리자와 직원의 실제 능력 향상 및 사용자가 유튜브에 올려도 되겠다고 느끼는 실물 영상**이며, 테스트 통과/구조 개발 자체가 최종 목표가 아님.
