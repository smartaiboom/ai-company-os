## 실행과 구현
- collaboration_handoff.py의 HandoffCompany/HandoffStore/publish_plan, representative_workflow.py의 decide/mission_production_spec/produce/_verify_video, mission_production.py/production_operating.py 및 studio_server/studio.js의 제작·검토 경로를 확인한다. 기존 구현을 재사용하고 새 병렬 엔진을 만들지 않는다. 기획·대본 승인 해시와 작가 내레이션/편집 장면표가 실제 제작 입력으로 전달되는지 검증한다.
- 직전 보고서에 기록된 격리 프로젝트 실제 기획·대본 검증 명시 승인의 원문/목적/전송 데이터/공급자/모델/프로젝트/유효기간/무료 비용0 및 키를 확인한다. 기존 연구 승인과 구분한다. 현재 동일 모델·프로젝트의 이전 503은 다른 조사 작업에 기록되어 있으므로, 신규 기획 업무의 독립적인 승인된 요청과 실패 본문 재전송을 구분하여 기존 안전 정책으로 실행 가능성을 판단한다. 공급자 상태를 추측하지 않는다. 기존 승인 및 정책에서 명시적으로 허용하는 정상 신규 기획 요청 또는 정식 복구 확인만 수행하고 실패/미확정 요청 자동 재전송, 차단 우회, 무승인 공급자/모델 변경 금지. 유효 승인 범위가 없다면 실제 필요한 기획/대본 및 수정 검증 범위를 한 번 제시하고 대표 명시 승인 요청. 공급자 장애가 확인되거나 권한/복구 조건이 불명확하면 외부 실행 중단; 로컬 제작 연결은 별도로 수행. 임의 전체 호출 수 제한 금지. 무료 잔량/청구 미확인 기록.
- 실제 AI 가능 시 기존 승인된 격리 프로젝트/테스트 입력으로 관리자 업무 배정, 작가 대본, 편집 장면표, 관리자 검토, 테스트 대표 의견 반영 후 새 기획 및 승인 인계를 실제 실행한다. 가상 대표 입력은 테스트용으로 명확히 표시하며 운영 v8을 대신 선택/승인하지 않는다. 역할별 실제 산출물, 수정 전후 차이, 근거 한계와 출처를 기록. 실제 결과가 부족하면 대표 검토 가능하게 보고하고 완전 자율 성공을 강제하지 않는다. 핵심 계약 오류는 유효 승인 내에서 새 요청으로 필요한 단계만 검증. 최근 근거 판단은 적용되는 경로에서 확인하고 별도 게임 조사 재실행은 필수로 만들지 않는다.
- 실제 AI가 차단되면 기존 격리 모의 승인 대본을 명시적으로 테스트 입력으로 써서 로컬 렌더/제작·재생·검토 연결을 확인한다. 기존 무료 로컬 렌더/음성·자막 도구 및 설치된 MeloTTS/FFmpeg 등 확인 후 활용. 외부 영상/음성 API나 새로운 다운로드/비용/권리 확대는 별도 승인 필요. 실제 재생 가능한 MP4, 음성/자막/장면 동기화와 규격/길이/해시 확인, 컷룸 재생과 대표 평가·수정 요청 경로를 확인한다. 모의 대본 기반 실제 기술 시안, AI 실대본 기반 영상, 실제 AI 생성 클립, 게시 가능한 완성 영상을 엄격히 구분한다. 권리 없는 원본 사용/게시 금지. 합법적인 자체 그래픽 등 기존 기술 시안 경로 허용하되 품질 한계를 기록. 빈 영상/fixture를 실제 AI 완성품으로 표시 금지.
- 대표 평가와 수정 지시가 실제 제작 결과/버전/승인된 기획과 연결되는지 기존 기능에서 확인하고 필요 최소 수정. 결과 피드백은 기존 저장 구조에 남긴다. 새로운 경험 학습 엔진 개발은 이번 범위 아님. 이후 실제 경험 재사용 연결에 필요한 정보를 보존한다.
