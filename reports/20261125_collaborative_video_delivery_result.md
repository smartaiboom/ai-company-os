# 협업 기획·대본에서 로컬 영상 제작과 검토까지

2026-11-25 KST · 시작 기준 `7cbe247`

## 연결과 수정

기획 승인 후 기존 세로 렌더러를 통해 컷룸 영상 검토로 제출된다. 협업 프로젝트에서 기술 시안 수정 의견이 있으면 기존 제작 단계에서 화면 이동을 선택하고 새 버전을 렌더할 수 있다. 최신 영상 해시, 대표 수정 결정, 승인 기획 해시를 대조해 오래된 수정 요청이나 변경된 미디어를 차단한다. 새 영상에는 이전 영상 해시, 실제 수정 의견과 적용한 화면 설정을 보존한다. 자체 카드 기술 시안의 최종 영상 승인 제한을 유지했다.

## 검증

| 구분 | 결과 |
| --- | --- |
| 관련 회귀 | Python 17건과 컷룸 Node 검증 통과. 수정 의견·영상 해시에 연결한 추가 제작 검증도 통과했다. 기존 합성 테스트 음원은 음성 트랙 구성 검증용이며 실제 음성 품질 평가에 사용하지 않았다. |
| 격리 컷룸 | localhost HTTP로 조사 후보 선택, 관리자·작가·편집의 역할별 모의 응답, 기획 v1과 수정 대본 v2, 대표 기획 승인과 기술 시안 제작을 실행했다. 가상 영상 수정 의견과 선택한 확대 효과로 영상 v2를 만들었다. 최초 승인 대본과 영상 v1을 보존했다. |
| 실제 미디어 | 두 MP4를 실제로 렌더하고 FFmpeg 전체 디코딩과 FFprobe 규격을 확인했다. 컷룸에서 전체 GET 200, 탐색용 Range 206, 썸네일 200을 양쪽 버전에서 확인했다. 수정본 FFplay 재생은 끝까지 완료됐다. 한글 자막의 실제 프레임을 확인했다. 브라우저에서 사람이 시청·평가하는 단계는 미실행이다. |
| 운영 상태 | 운영 컷룸 GET 200, v8 대표 검토 대기와 v9 공급자 중단 기록 유지. 운영 파일 1,442개의 SHA-256이 일치했다. |
