# 실제 AI 클립 수입 이후 코드 동기화 및 다음 제작 준비

작성: 2026-11-09 KST

## 수행 목적
사용자가 업로드한 Google Flow 클립을 수입해 만든 혼합 영상(실제 AI 클립 1개+비AI 테스트 패턴 2개)은 기술적으로 성공. `reports/real_ai_clip_import_result.md`에는 관련 코드 수정/회귀 테스트가 **Codespaces 로컬에만 있고 GitHub에 푸시되지 않았다**고 적혀 있음. 이 수정의 안전한 반영이 우선. 사용자 평가를 받기 전 영상 품질 개선이나 새로운 API 연결을 임의 진행하지 않는다.

## 실행 지시
1. `AGENTS.md`, `reports/real_ai_clip_import_result.md`, `docs/RUN_REAL_AI_CLIP_IMPORT.md`를 먼저 읽고 `git status`, diff 및 원격 상태를 확인한다. 사용자가 만든 미커밋 코드와 기존 데이터는 절대로 버리지 않는다. `git reset --hard`, `git clean` 금지.
2. 혼합 영상 출처와 AI 클립 수를 올바르게 구분하도록 이미 수정된 `companies/video/ai_clip_pipeline.py` 및 해당 회귀 테스트를 검토한다. 데이터/권리 정보 `generated_at=null` 지원은 검증 가능해야 하며 기존 필수 계약을 불필요하게 약화하지 말 것. 기존 인수 동의·AI API 비용/호출·백업 원장은 수정 금지.
3. 지금 로컬에서 **이미 성공한 테스트는 불필요하게 반복하지 않는다.** 변경 diff와 기존 `reports/real_ai_clip_import_integration.log`의 25개 통과 기록을 확인하고, 검증이 부족한 변경이 추가로 발생했을 때만 최소 범위로 테스트한다.
4. 검증된 코드/테스트 변경을 GitHub `main`에 안전하게 커밋·푸시한다. `data/`/원본 입력 mp4/생성 mp4/기존 비밀키/런타임/원장/로컬 아카이브 절대 업로드하지 말 것.
5. 외부 Google Flow 클립의 실제 사용 권한/상업 이용/워터마크 조건은 미확인. `publish_ready=false` 유지. 원래의 60초 파일은 건드리지 않는다.
6. 결과는 `reports/real_ai_clip_sync_result.md`에 간결히 저장: commit SHA, 변경 파일, 기존 테스트 근거, 입력·산출물 보존, 원격 반영 여부, 새 외부 AI 호출 0회, 비용 0원, 다음 남은 일.
7. 위 결과 파일도 GitHub에 커밋·푸시한다. 실행 결과는 긴 채팅 로그 대신 파일로 저장하고 사용자에게는 완료 여부만 알린다.

## 다음 사용자 평가 이후에만
사용자가 실제 혼합 영상을 보고 만족/수정 의견을 주면, scene-2 및 scene-3용 AI 클립을 무료 서비스에서 생성·가져오는 절차를 지원하되 각각의 생성 비용, 다운로드, 권리 조건, 출처를 기록한다. 사용자가 매번 음성·영상 스타일을 고르는 작업으로 만들지 말 것. 최종적으로 AI 관리자가 피드백을 누적하여 다음 작품에서 도구/스타일을 자율 결정하도록 발전.
