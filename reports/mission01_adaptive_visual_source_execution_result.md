# 미션 01 영상 확보 대안 실행 · 2026-11-19 KST

## 운영에서 확인한 결과

서명된 첫 Commons 검색 원장은 검색 4회와 Gemini 대안 판단 1회 모두 완료로 기록한다. 장면별 메타데이터 기록에서 후보와 안전·형식 제외 건수를 확인했다.

| 장면 | 실제 검색어 | 후보 | 안전·형식 제외 |
| --- | --- | ---: | ---: |
| scene-1 | montage trending mobile PC games | 0 | 0 |
| scene-2 | Don't Starve Together night gameplay gathering | 0 | 0 |
| scene-3 | World Warcraft Forever gameplay community discussion | 0 | 0 |
| scene-4 | Hogwarts Legacy magical combat visual rendering | 0 | 0 |

코드는 직원의 긴 요청 문장에서 단어를 제거한 뒤 모두 `filetype:video`로 검색했다. 저장된 scene-3 검색어에서 제목의 “of”도 빠졌다. 이런 조건은 검색 범위를 좁힐 수 있다. 현재 기록만으로 어떤 조건이 무결과를 일으켰는지, Commons에 해당 게임 자료가 있는지는 확인할 수 없다.

기존 대안은 장면 순서대로 설명 영상, 라이선스 확인 이미지 모션, 담당자 자체 캡처, 생성 실행기 확인이다. 승인 대본 v2, 기술 시안 v1, 840프레임·35초 조정안, 실제 WAV 4건(3.68 / 7.36 / 5.16 / 6.40초), 청취 기록과 관리자·직원·정책 원장은 유지했다. 운영에는 현재 인수된 영상이 없다.

## 연결한 경로

- **대안 영상·이미지 탐색**은 이미 완료된 첫 작업과 다른 서명 범위를 사용한다. 기존 직원의 장면 요구와 대안에서 짧은 고유명, 주제어·축약어, 파일 유형을 분리하고, 동일 검색어·유형 및 첫 검색의 동일 요청을 반복하지 않는다. scene-2는 기존 이미지 대안을 우선한다. 1차 후보가 해당 2차 요청의 장면을 이미 충족하면 추가 요청을 건너뛴다. 현재 상한 **Commons 검색·메타데이터 8회**, 호출당 후보 최대 5개, 비용 $0, 신규 검색 전략/대안 Gemini **0회**다. 전송 데이터는 승인 화면에 표시된 검색어와 파일 유형이다. 결과가 비면 대기하며 기존 검색 또는 대안 판단을 반복 실행하지 않는다. [Commons 검색 연산자](https://www.mediawiki.org/wiki/Help:CirrusSearch#File_properties_search), [MediaWiki 원본 메타데이터](https://www.mediawiki.org/wiki/API:Imageinfo/en)
- 검색으로 얻은 PNG/JPEG과 MP4/WebM은 원본 페이지·저작자·라이선스·편집 및 표시 의무·체크섬을 기존 권리 검토 UI에 전달한다. 표시 의무, 동일조건변경허락 및 게임 IP·제3자 영상·음원은 확인이 필요하다. 이미지는 검토된 HTTPS 원본만 내려받으며 고정 공개 주소, TLS 인증서, 경로·형식·체크섬 검증을 재사용한다. 이미지당 최대 8MiB, 최대 변 4096픽셀과 1200만 픽셀, 단일 프레임 조건을 FFmpeg 디코딩 전에 검사한다. SVG와 애니메이션 PNG는 차단한다.
- 기존 편집 계약의 확장으로 장면당 권리를 확인한 이미지 1~3장, 팬·줌·컷, 설명 또는 참고 라벨을 AI가 선택할 수 있다. 원래 승인 목적과 장면 연결이 검토된 후보만 인수한다. 이미지 연출에는 **실제 플레이 영상 아님**을 영상 자체와 검토 자료에 표시한다. 소스 체크섬·권리 및 표시는 영수증에 남고, 편집기는 기존 `ClipJob`과 `editorial_video`의 음성 검증을 사용해 영상과 이미지 연출을 섞어도 WAV·자막·승인 타임라인을 유지한다.
- 후보 권리를 한 번에 검토한 뒤 별도 확정된 자산·편집 범위를 한 번 승인한다. 편집 Gemini 최대 1회, 원본 다운로드는 승인 후보 및 미인수 장면당 최대 3개를 기준으로 **현재 미션 최대 12회**이며 실제 상한은 선택된 권리 후보가 더 적으면 낮아진다. 로컬 합성은 외부 호출 0회다. 검색과 다운로드의 승인 범위는 각각 승인 화면에 표시된다. 횟수·토큰 잔량 수동 입력, 개별 다운로드 동의, 유료 전환, 자동 재시도와 게시 기능은 추가하지 않았다.
- 자체 캡처는 권리를 확인한 담당자가 캡처해 기존 로컬 보관함에서 인수할 수 있다. 공식 게임사 문서가 촬영을 허용하더라도 제3자 자료 다운로드 허가는 별도로 확인한다. 명시적 제공 조건이 있는 공식 직접 파일은 기존 어댑터를 쓴다. 공식 사이트 자동 발견, 자동 게임 캡처, 권리와 비용이 입증된 무료 생성 실행기는 미지원이다.

## 다음 조작과 검증

컷룸의 **현재 상태 / 다음 작업 → 대안 영상·이미지 탐색 범위 검토·승인 → 영상 자동 탐색 실행**에서 실제 실행할 검색 범위를 선택한다. 결과가 있으면 **영상 후보 권리 검토**에서 장면 적합성 및 권리를 확인하고, 후보가 충분하면 **자산·편집 범위 검토·승인 → 제작 실행**을 선택한다. 이번에 운영 승인, 다운로드 또는 영상 파일을 생성하지 않았다.

- 기존 운영 환경과 루트로 재시작했다. localhost의 실제 새 탐색 승인 대기 UI, 최초 검색·대안 원장, WAV 응답 및 승인 조정안·운영 파일 해시 보존을 확인했다. 브라우저 실조작은 미검증이다.
- 복제본은 기존 장문 검색 4회에 빈 모의 응답을 반환했다. 별도 짧은 검색의 첫 단계에서 후보를 받아 2차 4회를 생략했다. 권리 검토 후 모의 영상 3개와 PNG 2개, 운영 WAV 4건의 바이트 복사본을 실제 FFmpeg로 합성해 840프레임 영상 검토에 제출했다. PNG·JPEG 혼합과 줌도 로컬에서 확인했다. 잘못된 장면·중복·과대 이미지·애니메이션 PNG·SVG, 위험 URL, 불충분 권리 및 예산 소진 후 재요청을 차단했다.
- Python 회귀 30건 중 29건 통과·1건 건너뜀. JavaScript 구문·상태와 Git diff 검사 통과. 실제 미션 Gemini·TTS·Commons 검색·다운로드·YouTube·영상 생성은 각각 **0회**다. 운영 게임 자료 가용성과 실제 시청 품질은 미검증이다.
