# 미션 01 승인 기획과 세로 테스트 제작 연결 (2026-11-19 KST)

## 운영 확인 및 변경

운영 컷룸은 **제작 중**이고, 35초 기획 **v2**의 보고서 해시와 대표 승인 연결이 일치했다. 승인 스토리보드는 네 장면이며 소스 상태가 모두 미확보다. 기획의 `render_spec`은 비어 있었고 제작 경로는 기존 16:9 사양만 받았다. 그래서 준비 안내만 표시되고 제작 버튼은 없었다.

- 승인 해시, 대본 원문과 스토리보드의 일치를 다시 확인한 다음, 장면·내레이션·자막 시간을 720×1280 기술 시안 입력으로 투영한다. 승인 보고서에 제작 사양을 덮어쓰지 않는다.
- 기존 FFmpeg 렌더·ffprobe·전체 디코딩 검사, 산출물 해시 원장, 컷룸 영상과 썸네일 및 대표 2차 검토를 재사용한다. 실제 게임 화면 대신 자체 생성 카드로 표시한다. 화면 속 자막은 장면 단위로만 맞추며 단어별 싱크와 시청 품질은 미검증이다.
- MeloTTS 런타임과 모델이 이미 설치된 환경은 명시적으로 선택한 경우에만 장면별 로컬 음성을 결합한다. 기존 음성 영수증 검사가 원문과 WAV 해시를 대조한다. 음성이 장면보다 길면 자동으로 자르거나 시간을 늘리지 않는다. 운영 PC에는 해당 런타임과 모델이 없어 **현재 운영 시안은 무음**이다. FFmpeg, ffprobe, 로컬 한글 글꼴을 확인했다. eSpeak는 이 경로에 필요하지 않아 설치하지 않았다.

## 제작 지시와 외부 요청 범위

제작 준비 데이터는 기존 목표, 대본의 제안 시청자, 승인된 장면별 내레이션·자막·화면·소스 상태, 조회 자료와 그 한계, 기존 제작 도구 능력 및 음성 경험의 적용 범위를 이어받는다. 전달 방식과 장면 연출은 향후 관리자 판단 대상으로 표시한다. 이번 작업에서 AI가 창작 지시를 생성하지는 않았다.

| 항목 | 후보 범위 | 현재 상태 |
| --- | --- | --- |
| 제작 방향 | 기존 고정 무료 텍스트 모델 `gemini-3.5-flash-lite` 후보 1회. 목표·대상·승인 장면·근거·경험과 도구 한계를 전달 | 새 서명 실행 범위 미구현·미승인 |
| 장면 음성 | `gemini-3.8-flash-tts` / Puck 후보, 승인 내레이션과 검토한 발화 지시로 장면당 1회, 현재 네 장면 | 기존 서명 실행기는 지정 표본에 결합되므로 이 대본에는 확장하지 않았다. 새 서명 실행 범위 미구현·미승인 |
| 로컬 기술 시안 | 승인 대본 투영과 기존 인코더, 설치 시 로컬 MeloTTS | 외부 API 요청 및 외부 비용 0 |

이전 Gemini/Puck의 자연스러움 7/10은 한국어 안내 영상 표본의 대표 청취 평가다. 이번 게임의 목소리 선택과 품질은 미평가다. 두 외부 후보의 현재 계정 무료 적용·할당량·실제 청구는 미확인이다. 화면에서 후보 범위는 읽을 수 있으나 새 외부 동의와 외부 실행 버튼은 비활성이다. [기존 표본 평가](VIDEO_VOICE_USER_AB_FEEDBACK_RESULT.md), [지정 표본 실행 경계](NO_CARD_TTS_EXECUTION_GATE_RESULT.md)

## 대표 다음 조작

컷룸을 새로고침하고 기존 프로젝트에서 **세로 기술 시안 제작 → 로컬 제작 시작**을 누른다. 무음 카드·자막 시안이 기존 **영상 검토** 단계로 제출된다. 이후 실제 게임 화면과 배포용 음성을 붙이려면 소스 사용권과 음성 후보를 별도로 확인해야 한다. Gemini 음성을 선택하는 경우 최소 추가 작업은 승인 장면 원문·발화 지시·요청별 한도에 결합된 별도 서명 실행 범위를 구현하는 것이다.

## 검증

- 핵심 미션·컷룸·TTS·음성 테스트 **124개 통과**. 최종 한글 자막 제한 적용 후 관련 컷룸·TTS·음성 테스트 **29개 통과**. 두 실행은 일부 테스트가 겹치며, 두 번째에는 신규 세로 제작 회귀 테스트가 포함됐다. JavaScript 문법 검사와 `git diff --check`가 통과했다.
- 실제 승인 v2의 임시 복제본에서 잘못된 해시를 차단했다. 승인한 네 장면과 내레이션·자막 원문, 0–3·3–14·14–24·24–35초 구간을 보존했다.
- 복제본에서 무음 35.000초와 장면별 합성 테스트 신호를 결합한 35.023초 두 시안을 실제 FFmpeg로 생성했다. 양쪽 H.264 720×1280, 전체 디코딩, 썸네일 및 영상 조회, 중복 제작 차단, 대표 2차 검토 대기 전환을 확인했다. 음성 결합 경로의 AAC는 합성 신호로 검증했으며 실제 한국어 음성·게임 영상·시청 품질은 미검증이다.
- 실행 중 작업이 없음을 확인한 뒤 운영 컷룸을 기존 환경과 작업 루트로 재시작했다. localhost 상세 응답과 최신 JavaScript에서 무음 시안 준비 상태와 외부 요청 승인 0회를 확인했다. 운영 JSON은 바이트 단위로 일치했다. 브라우저 클릭은 검증하지 않았다.
- 운영 v2, 기존 대표 결정과 전체 사용 기록을 보존했다. 실제 Gemini 텍스트 **20회**, YouTube **4회**의 기존 원장에 변화가 없다. 이번 작업의 실제 Gemini 텍스트·TTS·YouTube 요청, 운영 동의 생성 및 실제 운영 제작은 모두 **0회**였다.
