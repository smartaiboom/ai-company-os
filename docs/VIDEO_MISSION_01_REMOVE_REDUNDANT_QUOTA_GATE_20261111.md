# 미션 01 — 반복 중단 원인 수정 및 실제 실행 연결
작성일: 2026-11-11 KST

## 목적
대표가 이미 승인한 첫 게임 쇼츠 미션을 실행하려는데 기존 `prepare`가 계정별 잔여 요청 수치를 필수 정수로 받아 계속 중단된다. 이미 완료한 API 키·사용자 확인 할당량·결제 미등록 점검을 반복하지 않는다. **증명되지 않은 잔여 숫자를 입력하게 하지 않으면서** 실제 요청 횟수/무료 이용/승인 및 비용 안전 경계가 유지되도록 기존 흐름의 최소 수정을 수행한다.

이번 목표는 `prepare → approve → run`이 안전하게 이어지도록 불필요한 수치 증명 의존성을 없애고, 조건이 충족되면 실제 AI 조사·기획·대본을 대표 승인 대기까지 올리는 것이다.

## 기존 진행 및 승인
먼저 `AGENTS.md`, `reports/VIDEO_MISSION_01_SINGLE_ATTEMPT_REAL_RESULT_20261111.md` (존재하지 않으면 이번 Codex 중단 출력), `reports/VIDEO_MISSION_01_REAL_EXECUTION_RESULT_20261111.md`, `reports/VIDEO_MISSION_01_FREE_API_EXECUTION_READINESS_RESULT_20261111.md`, `reports/VIDEO_MISSION_01_EMPLOYEE_WEB_RESEARCH_RESULT.md`를 읽는다.
실제 차단은 `companies/video/video_mission_one.py`의 `_check_mission_account`에서 `remaining_requests >= MAX_CALLS`를 요구하는 점과 웹의 `search_remaining >=4` / `units_remaining >=4`이다. 이것은 사용자의 호출 *상한*과 계정의 실제 *잔여량*을 혼동시키는 문제다. `prepare`에 임의의 숫자를 입력하거나 확인 없는 값을 '검증 완료'로 기록하지 말 것.

대표가 2026-11-11 KST에 승인한 실제 외부 호출 상한:

- 무료 계정/무료 서비스만, 자동 재시도·대체 모델·유료 전환·게시·TTS·MP4 금지

- 기존 개별 프로젝트의 제안 해시·서명 동의 및 시도 원장을 통한 엄격한 관리 필수

## 코드 수정 요청
1. 기존 `video_mission_one.py`과 `core/` 승인·사용량 가드를 분석하여 현재 구조를 재사용한다. 새 회사 엔진·UI·중복 승인 체계 만들지 않는다.
2. '공급자 계정의 현재 잔여 호출 수'가 로컬에서 검증되지 않았다는 이유만으로 사용자 승인 상한을 무한히 재점검하지 않도록 데이터 모델과 `prepare` 계약을 최소 수정한다. 계정 잔여량이 미확인이라면 `unknown/not_verified`로 정직하게 기록하고, **별도의 확정된 사용자 승인 상한 10/4/4**를 엄격히 강제한다. '잔여 10'처럼 임의의 값을 만든 뒤 통과시키는 방식은 금지.
3. 단, 잔여량 숫자 요구를 제거하는 것과 무료 이용 확인은 다른 문제다. 확인되지 않은 요금 청구 가능성을 코드가 무시하거나, `billing_disabled=True`라는 자체 입력만으로 무료가 보장된다고 주장하지 않는다. 실행 환경의 정확한 모델/엔드포인트가 무료로 제공되고 해당 프로젝트에 과금 노출이 없다는 합리적 근거가 없으면 실제 요청 전에 중단한다. Google 공급자가 무료 접근을 거절하면 단일 업무 요청 1회가 승인 상한 안에서 실패로 기록되고 중단; 재시도와 대체 모델은 금지.
4. 기존 승인 서명/제안 해시/만료/중복 실행 방지/시도 소모 규칙을 보존한다. 이미 시도한 업무에 다시 요청하지 않는다. 현장에 존재하는 키·로컬 원장·기타 프로젝트·음성 실험을 보존한다.
5. 변경된 계약의 회귀 테스트를 한 묶음만 실행한다. 승인 상한 초과, unknown 잔여, 의심스러운 유료 환경, 서명 불일치, 중복 요청, 429/타임아웃 재시도 금지, Gemini와 YouTube 각각 호출 상한을 검증한다. 테스트의 mock 성공을 실제 미션 완료라고 기록하지 않는다.
6. 안전 조건이 충족되면 프로젝트별 `prepare → approve → run`을 기존 동의 범위에 따라 수행한다. AI 조사 직원이 검색어와 후보를 정하고 관리자가 게임 및 영상 길이를 선정, 실제 AI 직원이 전체 한국어 대본·장면 구성을 작성해 컷룸 대표 승인 대기에 올린다. 실제 요청 횟수를 원장에 정확히 보존한다. 안전 조건이 충족되지 않으면 실호출 없이 **불충족 조건 한 가지와 이를 해결할 정확한 방법만** 보고하고 중단한다.
