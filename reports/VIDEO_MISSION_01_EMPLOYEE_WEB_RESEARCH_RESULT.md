조사 직원이 스스로 검색 질의를 JSON으로 작성하면 기존 미션이 YouTube Data API v3의 `search.list`와 `videos.list`를 호출한다. 질의에 미리 정한 게임·순위·길이 통계는 넣지 않는다. 질의별 게임 카테고리 결과 최대 5개에서 원본 URL, 수집 KST 시각, 게시일, 실제 길이·조회수, 지역 필터·표본 범위·한계와 최소 근거 해시를 받아 기존 프로젝트에 저장한다. 메타데이터를 읽는 공식 API이며 영상·음원 다운로드나 사이트 스크래핑은 수행하지 않는다. [검색 API](https://developers.google.com/youtube/v3/docs/search/list) · [영상 메타데이터 API](https://developers.google.com/youtube/v3/docs/videos/list)

관리자는 실제 도구 영수증을 보고 게임·소재와 예상 길이를 선택한다. 대본 직원은 선택된 주제·길이를 그대로 받아 한국어 대본과 장면을 만들고, 편집 직원이 수락된 버전의 해시를 인수한다. 시도·응답·영수증·선정 근거를 기존 서명 승인과 프로젝트 원장에 연결했다. 텍스트 모델 최대 10회와 웹 GET 최대 8회를 각각 기록하고, 웹 요청도 송신 전에 소비 상태를 저장한다. 실패·시간 초과·중단 상태의 배치를 자동 반복하지 않는다.

## 확인 가능한 범위와 한계

- 검색의 KR은 한국에서 시청 가능한 영상 필터이고 한국 시청자 집계가 아니다. 한국어는 검색 관련성 힌트다. 게임 카테고리·최근 게시일·조회수·길이를 확인하되, 게임 이름과 영상의 실제 내용 일치는 관리자가 검토해야 한다.
- `videoDuration=short`는 Shorts의 세로 형식이나 공식 분류를 보증하지 않는다. 메타데이터 표본의 `shorts_classification`은 항상 `unverified`로 유지한다. 게임 외 분류·기간 밖 게시·조회수 비공개·길이 초과·누락 영상은 선정 근거에서 제외한다. 실제 조회 증가율·채널 구독자 대비 성과·게임사 사용권도 미확인이다. 원본 관측값을 게임 전체 인기나 길이 효과로 일반화하지 않도록 모델 지시와 검증을 연결했다. [검색 필터 정의](https://developers.google.com/youtube/v3/docs/search/list)
- API 데이터에는 30일 사용 기한을 기록하고 기한이 지난 근거로 선정·보고할 수 없게 했다. 공개 메타데이터의 장기 보존에는 삭제 또는 갱신이 필요하다. 자동 삭제·갱신 작업은 이번 연결에 포함되지 않았으며, 실제 실행 시 운영자가 보고서 사본과 모델 결과에 전달된 값까지 포함해 30일 내 정리해야 한다. 기존 사용자 자료에는 이 정리를 적용하지 않는다. [YouTube 데이터 보존 정책](https://developers.google.com/youtube/terms/developer-policies)

## 무료 조건과 승인 제안 1건

현재 `GEMINI_API_KEY`는 존재하고 `YOUTUBE_DATA_API_KEY`는 없다. 따라서 YouTube API 활성화·프로젝트별 무료 할당량과 실제 잔여량은 **not_verified**다. YouTube 계정 로그인/OAuth 없이 공개 데이터용 API 키를 사용하는 연결이다. 별도 유료 검색 서비스나 Gemini 검색 grounding으로 자동 전환하지 않는다.

공식 문서에서 현재 기본 할당량은 `search.list` 전용 일 100회(호출당 해당 버킷 1), 그 외 메서드 합계 일 10,000단위이며 `videos.list`는 호출당 1단위다. 실제 계정의 활성화·할당량은 Cloud Console에서 확인해야 한다. 실패 요청도 비용성 시도로 소비한다. [현재 YouTube 할당량](https://developers.google.com/youtube/v3/determine_quota_cost)

제안하는 한 건은 대표의 정확한 게임 쇼츠 목표에 대해 **Gemini 3.5 Flash-Lite 텍스트 최대 10회 + YouTube 공개 검색 최대 4회 및 영상 메타데이터 최대 4회(합계 GET 8회)**다. 직원이 질의와 최근 1~30일 범위·정렬을 선택한다. 유료 Billing·추가 할당량 구매·재시도·fallback·미디어 제작·게시 없이 총 $0 상한으로 진행한다. 검색 API에는 직원 질의·기간·공개 영상 ID를 전송하고, Gemini에는 목표·제약·검색 메타데이터·해당 실행의 선행 작업 결과와 수정 피드백을 전송한다. Google 무료 AI 입력·출력의 제품 개선·인적 검토 가능성과 YouTube 데이터 보존 정책을 확인해야 한다. **같은 실행 범위에 대해 두 서비스의 키·무료 계정·잔여 할당량 및 정책을 확인한 뒤 별도 서명 승인을 받는 것**이 다음 단계다. [Gemini 무료 약관](https://ai.google.dev/gemini-api/terms)

CLI에서 `video_mission_one connect-web <컷룸 ID>`는 연결 준비만 한다. `prepare`에 기존 무료 계정 인수와 `--youtube-project --youtube-searches-remaining --youtube-units-remaining --confirm-youtube-policy`를 추가해 제안 해시를 검토한다. 승인된 새 범위만 기존 `approve`·`run` 경로로 집행한다. 현재 키·계정 확인과 사용자 승인이 없어 실행 전에 멈췄다.
