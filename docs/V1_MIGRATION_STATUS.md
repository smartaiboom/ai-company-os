# AI Company OS v1.0 — 새 작업 영역과 안전한 이전 절차

작성: 2026-11-09 (KST). 이 문서는 **실제 수행한 복사와 앞으로 필요한 검증을 구분**한다.

## 현재 구성
- `src/`: 기존 Phase 1의 실제 Gemini 3.5 / AI 관리자·직원 협업 엔진을 구성하는 **16개의 기존 Python 모듈을 동일 Git blob SHA로 복사**. 코드를 재작성하거나 기능을 개선한 것이 아니다.
- `phase1/`: Git 추적 대상 과거 소스·테스트·기록의 완전 보관본.
- `ai-company-os-phase1/`: 현재 Codespaces의 미추적 data/와 이전 실행 경로를 보호하기 위해 임시 유지하는 구 폴더.
- `docs/`: 현재 v1.0 개발 방향과 이전/정리 기준. `tests/`는 아직 기존 테스트 의존성을 전수 확인하지 못해 루트로 옮기지 않았다.

## 새 코드의 성격 및 실행주의
- 진입점 후보: `src/video_production_company.py`의 VideoProductionCompany, `src/autonomous_gemini35.py`의 Gemini35Company.
- 기본 import들이 같은 폴더의 모듈을 참조하므로 향후 실행 시 `PYTHONPATH=src`(또는 `src/`에서 실행) 필요. **현재 v1.0 실제 실행 테스트 전이며 정상 동작을 보증하지 않음**.
- `src/`는 일단 필요한 범위의 보수적인 복사본이다. `gemini_connection_once.py`, `groq_provider.py` 등 이름이 초기 실험처럼 보이는 파일도 다른 모듈의 코드 import 의존성을 확인했으므로 일단 유지.
- 실제 AI 호출, 기존 계정 동의, 과금, 운용 원장, 과거 프로젝트 재실행은 하지 않는다.

## v1.0 목표
사용자와 AI 관리자가 필요한 질문을 주고받아 목표를 명확히 함 → 전문 AI 직원 협업으로 실제 결과 제작 → 실제 산출물 품질 평가와 사용자 피드백 → 수정 결과 및 근거 저장 → **다음 작업에서 관련 경험 조회·적용을 증명**. 초기 사용자 참여는 허용, 장기적 자율 운영 방향 유지.

## 개발 중 파일 정리 규칙
1. 운영 루트에는 실제 소스·공용 설정·핵심 자동 테스트·현재 문서만 보존.
2. 일회성 실제 AI 연결 확인 스크립트, 한 번 사용한 진단 도구, 옛 개발 보고서/작업 지시서는 phase1에서 보관.
3. 활성 코드로 다른 모듈이 import하는 파일은 이름만 보고 제거하지 않는다.
4. 기능 교체 때마다 구 파일 참조 확인과 회귀 테스트 통과 후, 명확한 삭제 목록을 사용자에게 설명하고 정리한다.
5. Git 추적 외 `data/`, `backups/`, `artifacts/`, API 비밀·비추적 파일은 삭제·덮어쓰기·복사하지 않는다. 기존 원장 해시와 소진된 호출 권한·미확정 시도도 유지.
6. GPT(ChatGPT)는 GitHub 구조 확인·문서·이전 계획·안전한 Git 파일 정리를 우선 담당, Codex는 필요한 실제 코드 변경 및 로컬 실행·검증에 집중.

## 아직 미완료 — 안전상 남긴 항목
- Codespaces 실제 프로젝트 파일, 데이터 위치, 비추적 파일, 모듈 간 동적 import, 실행 환경 검증.
- 핵심 회귀 테스트를 새 작업 폴더에서 작동하게 선별/수정.
- root v1.0 진입점/CLI/UI, 목표 문답 및 경험 저장·검색·품질 개선 신규 기능.
- `ai-company-os-phase1/` Git 추적 원본 제거. **새 src 검증 전에는 삭제 금지**.

## 다음 Codex 작업 (개발 시간을 아끼도록 최소화)
Codespaces에서 `git pull` 후 `git status --short`로 로컬 소스·비추적 data 보호 상태 확인. 실제 외부 AI 호출을 **0회**로 유지하면서 `src/`의 로컬 import·offline smoke test 및 기존 핵심 회귀 테스트의 최소 실행가능성만 점검. 필요한 코드 수정/테스트 선별이 있으면 범위를 먼저 보고. 절대로 old data와 역사 원장 이동/삭제, `git clean -fd`, `git reset --hard`, 프로젝트 replay를 하지 않음.
