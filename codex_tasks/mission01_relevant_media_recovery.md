## 목표
이번에는 별도 진단 반복 대신 수정된 파서로 남은 장면의 적절한 소스를 실제 확보할 수 있도록 연결. 권리와 기술 통과만으로 장면 적합성 확정하는 문제 해결. 기존 코드 commons_discovery.py, asset_editing.py, audience_visual_review.py, production_sources.py, ClipJob 재사용. 
- 실제 운영 검색/진단 결과 및 정확한 신규 상태 확인. 기존 검색 결과 및 진단 후보를 재사용하고 소비한 동일 요청을 무조건 반복하지 않음. 기존 장문/비인용 검색이 넓은 단어 매칭으로 무관 사진을 가져올 가능성을 고려. 새로운 제한된 검색 전략은 고유명/정확 구문(공식 API 문법 검증), 파일명/관련 카테고리/설명 등에서 적합성 높은 후보를 찾도록 하며 generic 주제는 실제 의미 기준. 게임명·ID 특화 하드코딩 금지. 승인 장면/기존 직원 판단 활용. 검색 API에서 가능하면 원본 설명/카테고리/키워드 등 정제 메타데이터 추가 수집. 메타데이터는 직접 시청이 아님을 명시. 검색 결과의 관련도를 높이는 검색 전략 및 무관 후보 제외 근거 기록. 정확한 제목/관련성 불명확 시 자동 합격 금지. 
- 기존 진단 후보 및 신규 검색 결과에 대한 장면별 AI 적합성 판단을 한 번 묶어서 처리하는 경로(무료 Gemini 최대 1회)를 실제 실행 가능하게 연결. 실제 가용 후보/권리 제한/제목·설명·장면 목적·기존 대안 및 도구 능력을 전달, 적합/불명확/무관 분리, 게임플레이/설명 연출 구분, 후보 ID와 근거 명시. 명백히 무관/권리 부적격 후보는 불필요한 AI 요청에서 제외. AI가 파일/권리를 보지 않은 것은 보지 않았다고 기록. 필요 시 실제 다운받은 검토 허용 파일의 프레임/이미지 내용 확인을 기존 검토 도구와 연결할 수 있는지 검토하되 미지원이면 명확히 표시. 사람이 권리/장면 최종 검토하는 기존 일괄 승인 유지.
